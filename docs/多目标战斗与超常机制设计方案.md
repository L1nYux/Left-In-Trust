## 一、 设计哲学：从数值对抗到“系统现实主义”

在传统的卡牌游戏中，战斗往往局限于“出牌扣费、造成数值伤害、堆叠防御护甲、施加 Buff/Debuff”。但在《未尽之托》的语境中，敌人是**“屏幕另一端具体生活与工作中让人抓狂的故障、矛盾与混乱”**。

现实中遭遇的电脑与工作危机，从来不只是“扣血”这么单调：
*   它是**系统突然卡死、光标不受控制地反向漂移**；
*   它是**弹出一个怎么也点不掉的强制更新窗口，死死挡住正在编辑的文件**；
*   它是**离交付只剩 25 秒的死线倒计时，手心冒汗连连点错按钮**；
*   它是**敏感信息被领导随手涂抹成黑条，你必须凭借记忆去猜缺失的参数**；
*   它是**本来只有一个小 Bug，修完却由于缓冲区溢出（Buffer Overflow）瞬间炸裂成三个小碎片**；
*   它甚至是**现代系统底层崩溃后，突然降维砸入一段上世纪 90 年代老程序员遗留的粗糙 8-bit 像素测试小游戏**！

```text
 ┌────────────────────────────────────────────────────────────────────────┐
 │                    《未尽之托》超常战斗交互五大维度                     │
 ├───────────────────┬────────────────────────────────────────────────────┤
 │ 1. UI 侵入与遮蔽  │ 绝密黑条涂抹卡牌、弹窗劫持焦点、幽灵按钮、Token 乱码│
 │ 2. 物理与输入篡改 │ 鼠标反转漂移、胶带粘滞阻尼、长按重压盖章、拖拽回弹  │
 │ 3. 真实时限与节奏 │ 25秒死线熔断、编译中断 QTE 校对、高频抢单敲击      │
 │ 4. 卡牌元规则破坏 │ 语法报错卡、FIFO 队列强制出牌、两卡强行编译合并    │
 │ 5. 异维降维劫持   │ 强制陷入 8-bit 复古像素横版小游戏，限时逃逸破局    │
 └───────────────────┴────────────────────────────────────────────────────┘
```

> **特别核心原则：克制、低频与惊喜感**  
> 所有超常机制与小游戏**绝非常规家常便饭**！若每场战斗都反转鼠标或强制跳平台，将严重破坏肉鸽卡牌的核心构筑心流与操作舒适度。本文第五章特设**“三层低频门禁与防疲劳保护网”**，严格将超常机制限定于特殊条件、低概率与高光时刻。

## 二、 多目标战斗架构与阵型演化体系

### 2.1 战场 1~3 敌方槽位镜像对峙布局（1280 × 720）

战场右侧由原本的单个巨大容器，升级为支持 **1~3 个动态槽位** 的弹性阵列。左侧友方 3 人（GPT、Claude、DeepSeek）与右侧敌方 1~3 个槽位形成工整的对峙结构：

```text
┌────────────────────────────────────────────────────────────────────────┐
│ [顶部信息栏：委托名 · 回合数 · 场景阶段 · 全局倒计时]                 │  Y=0~54
├────────────────────────────────────────────────────────────────────────┤
│                                                                        │
│   友方三槽位 (X=42~404, Y=108)           敌方三槽位 (X=720~1180, Y=108) │
│                                                                        │
│   [ Claude ]    [ GPT ]    [DeepSeek]      [ 敌方1 ]  [ 敌方2 ]  [ 敌方3 ] │
│    (左后卫)    (左中锋)     (左前锋)       (前锋位)   (中坚位)   (游弋位)│
│                                                                        │
├────────────────────────────────────────────────────────────────────────┤
│ [下半屏：混合共享手牌区 · 基础指令 · 结束回合按钮]                      │  Y=438~720
└────────────────────────────────────────────────────────────────────────┘
```

*   **单体大怪/Boss**：居中独占 `EnemySlot_Center`，占宽约 400~460 px；
*   **双体组合**：分布于 `EnemySlot_Front (X=760)` 与 `EnemySlot_Back (X=1020)`，形成前后掩护；
*   **三体重群**：分别占位 `Front (X=720)`、`Mid (X=920)`、`Back (X=1120)`，单体净宽约 180~220 px。

### 2.2 动态多怪演化典型形态

```text
       ┌───────────┐         ┌───────────┐         ┌───────────┐
       │   群 集   │         │   分 裂   │         │   合 体   │
       │ (Swarm)   │         │ (Splitting│         │ (Merge)   │
       └─────┬─────┘         └─────┬─────┘         └─────┬─────┘
             ▼                     ▼                     ▼
      多体并存/协同意图      过量伤害炸裂子体      回合末未清理则合体强化
```

#### 1. 「乱码字符串三联阵」与「缓冲区溢出分裂 / 字符拼接合体」
*   **出场形态**：开局右侧同时刷新 3 根独立的「乱码字符串」（编号 A、B、C），分别具有 8 HP、10 HP、8 HP。
*   **动态分裂【Buffer Overflow】**：当任意「乱码字符串」受到单次高于 6 点的过量伤害但未致死时，发生**缓冲区溢出**，瞬间分裂为两枚 4 HP 的微型「碎字符方块」填入空闲槽位！
*   **动态聚合【String Concatenation】**：若玩家在 2 个回合内没有击杀任意字符串，在第 3 回合初，相邻的两个字符串会发出刺耳的磁吸声，**强行拼接合体**为一个 22 HP 的精英级「格式化乱码巨蟒」，攻击力永久翻倍！

#### 2. 「未保存草稿·雀群编队」与「共享未存区 / 报复性继承」
*   **出场形态**：2 只轻盈的「未保存草稿纸燕」（左燕 12 HP，右燕 12 HP）。
*   **报复机制【遗作同步（Sync on Death）】**：当其中一只纸燕被击败消散时，它未提交的全部草稿修改项会被另一只活着的纸燕**全量同步吸收**！存活纸燕体型膨胀 1.3 倍，立刻继承死者的全部技能与攻击力，并为自身套上一层 6 点的硬质牛皮纸保护封皮。

#### 3. 「权限锁死」伴生「只读防护锚点」(Boss/精英与伴生体)
*   **出场形态**：中央为 38 HP 的「权限锁死」主保险柜，左右两侧悬浮着两枚 12 HP 的「只读防护锚点」。
*   **机制【绝对所有权屏障】**：只要场上存在至少一枚「只读防护锚点」，主保险柜处于 `chmod 444` 无敌锁止状态，受到的所有直接伤害强制降为 0！必须优先拆除两枚锚点。

## 三、 超常机制与元交互（Meta-Game）深度设计

---

### 3.1 UI 侵入与信息遮蔽（Information Obfuscation）

#### 机制 1：【黑条涂抹 / 绝密审查】(Redaction Tape)
*   **交互表现**：敌人抬手掷出漆黑的审查墨水条，直接狠狠贴在玩家下方的**共享手牌**上，将卡面费用、伤害和说明死死遮蔽，悬停时亦无法透视。
*   **破除解法**：
    *   *方案 A（盲打记忆）*：玩家凭卡牌的边框归属色（GPT 紫、Claude 橙、DeepSeek 蓝）与中央插画轮廓，凭借记忆推测其效果盲打出牌！
    *   *方案 B（物理撕胶带）*：玩家可以用鼠标在黑色胶带上**横向快速刮擦 3 次**（类似刮刮乐手势），伴随清脆的撕纸声将黑条揭除！

#### 机制 2：【系统弹窗劫持焦点】(Modal Dialog Trap)
*   **交互表现**：在玩家出牌长考时，屏幕中央突然弹出一扇高保真的伪操作系统报错对话框：`Critical merge conflict: 是否强行终止进程？`。
*   整片手牌区与角色区全部被一层 60% 半透明暗色蒙版遮罩，卡牌无法点击！
*   **解脱操作**：玩家必须迅速用鼠标点击右上角的微小 `×` 或者准确点击“强行忽略”才能关闭弹窗，解除出牌锁；误点“终止进程”全队扣除 1 点 Token。

---

### 3.2 物理交互与输入篡改（Input Distortion）

#### 机制 1：【鼠标光标重力漂移与反转】(Cursor Inversion & Drift)
*   **交互表现**：当特定怪物（如「循环依赖」）启动空间扭曲时，鼠标移动轴向瞬间颠倒（鼠标向左移，光标向右跑；鼠标向上移，光标向下跑）；或在并发洪峰时产生向左强风阻力，鼠标持续向左自动漂移，必须“顶风拖拽”出牌。
*   **体验限定**：严格限制在单个回合的出牌阶段发生，回合结束立刻恢复正常，绝不持久折磨玩家。

#### 机制 2：【光标粘连与强力胶带阻尼】(Sticky Cursor Drag)
*   **交互表现**：从手牌区抓取卡牌时粘上一截黄色 3M 胶带，拖动速度被平滑衰减 70%，若拖到一半中途松手，卡牌会被胶带的弹性瞬间抽回手牌槽！玩家必须坚决拖过屏幕中线方可释放成功。

#### 机制 3：【长按重压盖章执行】(Hold-to-Stamp)
*   **交互表现**：对抗公章类 Boss 时，常规单点出牌失效，必须将卡牌拉至目标上方后**长按鼠标左键整整 0.8 秒**，伴随手柄/屏幕微震与公章充能蜂鸣，进度条蓄满后松手，伴随沉重的“咚！（Thump!）”盖章生效。

---

### 3.3 真实时限与高压倒数（Real-Time Countdown & QTE）

#### 机制 1：【25秒死线熔断】(Deadline Rush)
*   **交互表现**：屏幕顶端弹出鲜红发烫的 25 秒倒计时读条，耳边响起急促如秒表的老式座钟嘀嗒声（`Tick-tick-tick...`），音乐加速至 160 BPM。
*   **超时惩罚**：倒计时归零时若未点击“结束回合”，未打出的手牌被全部强制销毁送入弃牌堆，且全队扣除 2 点 Token。

#### 机制 2：【代码语法错字 QTE 校对】(Syntax Proofreading Strike)
*   **交互表现**：Boss 读条团灭级大招时，头顶浮现一行带红色波浪线的报错代码（如 `excute_task`），玩家在出牌阶段内点击错别字并快速纠错（修改为 `execute`），可当场打断蓄力使 Boss 瘫痪！

## 四、 异维降维劫持：8-Bit 复古横版小游戏机制精细化

这是本作最具戏剧张力的超级元机制——**“当现代 AI 运行时发生严重栈溢出或底层崩溃时，游戏被暴力拖入一个粗糙低劣的 8-bit 像素复古横版过关沙盒”**！

```text
┌────────────────────────────────────────────────────────────────────────┐
│                        【异维小游戏降维演出时序】                       │
├────────────────────────────────────────────────────────────────────────┤
│ 1. 故障撕裂 (0.4s) ：现代 UI 剧烈抖动，整屏画面伴随蜂鸣发生 CRT 水平收缩│
│ 2. 降维重构 (0.3s) ：画面瞬间褪色为 Game Boy 墨绿 4 阶低分辨率点阵    │
│ 3. 限时逃逸 (15~20s)：玩家操控 16×16 像素小人，键盘 A/D+空格躲避尖刺跳跃│
│ 4. 终端重载 (0.5s) ：成功触碰终点，CRT 展开，瞬间切回现代 2D 优雅战场  │
└────────────────────────────────────────────────────────────────────────┘
```

### 4.1 剧情设定与世界观自洽

*   **世界观隐喻【古董级测试沙盒 (Legacy Sandbox)】**：
    在任务世界的层层代码深处，依然残存着初代程序员三十年前用 C 语言写的脱机自检小游戏（类似 Chrome 离线时的断网小恐龙跳跃，或是嵌入在编译器底层的 Easter Egg）。当怪物生命过低濒临崩溃或施放底层死锁时，整个会话被意外甩入这片未妥善封装的“数字荒原”中。
*   **承载怪物**：
    *   稀有精英怪：**「古董级运行时」(Archaic Runtime / DOS 引导残灵)**
    *   阶段关底 Boss 罕见绝境态：**「全量发布门禁·内核崩溃态」**（仅在生命低于 20% 且触发概率检定时发动一次）。

### 4.2 极端的画风视听反差（The Visual & Acoustic Disconnect）

为了实现强烈的“画风出轨与跨越次元”的冲击力，小游戏的视听语言**严禁沿用《未尽之托》典雅的特种纸张、水彩渐变与离散墨蓝黑**，而是进行彻底的低清复古重构：

```text
┌──────────────────────────────────────────────┐
│ [ TIME: 15s ]             [ SCORE: 00420 ]   │ ── 8-bit 等宽像素 HUD
├──────────────────────────────────────────────┤
│                                              │
│               [ 悬浮报错方块 ? ]             │
│   (跳跃)            │                        │
│    ▲                ▼                        │
│   [ o ] -> -> ->   [ 红色 NullPointer 尖刺 ]  │ ── 像素平台跳跃跑酷
│  (8-bit小人)        ██████████████           │
├──────────────────────────────────────────────┤
│ ░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░ │ ── 墨绿 4 阶点阵地面
└──────────────────────────────────────────────┘
```

1.  **美术画风（Game Boy / NES 粗糙像素）**：
    *   **调色板**：瞬间锁定为经典的**Game Boy 墨绿色四阶点阵**（`#0F380F` 最深墨绿、`#306230` 深绿、`#8BAC0F` 浅草绿、`#9BBC0F` 亮绿底色），或者是刺眼的 16 色 NES 街机红蓝原色；
    *   **分辨率与着色器**：整个画面经由 `retro_crt_gb.gdshader` 进行强力下采样（模拟 160 × 144 原始分辨率放大），边缘带有微微外凸的 CRT 弧度扫描线与荧光残影；
    *   **主角像素化**：当前上场的主视角 AI 少女（如 GPT）被降解为一个只有 16 × 16 像素的蹦跳小精灵，身穿三色像素块裙子。
2.  **音效与音乐（8-bit Chiptune 方波乐）**：
    *   原本舒缓深沉的弦乐与环境声瞬间掐断，切换为纯正的双通道 8-bit 方波芯片音乐（BGM 充满滑稽又急促的 `Beep-boop-beep-boop` 旋律）；
    *   起跳音效为清脆的高频滑音 `Boing!`，触碰金币/补丁为 `Ding-ring!`，踩中怪物为 `Squish!`。

### 4.3 关卡设计与极速跑酷规则

小游戏必须**极短、极清晰、极易上手**，绝对不能做成折磨人的硬核跳跃游戏：
*   **游玩时长**：固定 **15 秒倒计时**，仅需横向跑过 1~2 个小屏幕距离。
*   **操作模式**：
    *   键盘 `A` / `D`（或方向键 `←` / `→`）控制水平左右跑动；
    *   键盘 `空格键`（或 `W` / `↑`）控制起跳（支持两段短跳，手感清脆灵敏）。
*   **三处固定经典障碍**：
    1.  *障碍一（陷阱坑）*：跳过一个宽 32 像素的「`NullPointerException` 虚无断崖」；
    2.  *障碍二（巡逻怪）*：原地踩碎一只慢吞吞左右挪动的 8-bit 绿色小臭虫「Bug.exe」；
    3.  *终点目标*：在时间耗尽前，起跳撞击悬在空中的一枚闪烁金色光芒的「`return 0;` 软盘图标」或跳上插有旗帜的通关终点线！

### 4.4 胜负反馈与深远后果

```text
                         ┌────────────────────┐
                         │   15秒横版小游戏   │
                         └─────────┬──────────┘
                 ┌─────────────────┴─────────────────┐
                 ▼                                   ▼
        【成功触碰终点软盘】                 【超时归零 / 坠入虚空】
                 │                                   │
                 ▼                                   ▼
     * 8-bit 欢快通关和弦喇叭            * 刺耳死机警报声 (Buzz Crash!)
     * 瞬间切回现代 2D 优雅战场          * 画面收缩为白点，暴力切回战场
     * Boss 受到 8 点反冲伤害            * 全队遭受 3 点穿甲真实伤害
     * Boss 护甲清零并瘫痪 1 回合        * 当前角色下回合手牌被锁 1 回合
```

*   **通关成功收益（System Reboot Override）**：
    *   伴随一声极其滑稽又欢快的 8-bit 胜利号角，画面瞬间如同洗去铅华般恢复现代优雅的纸页旷野/高架桥战场！
    *   怪物头顶爆出金色报错代码，当场受到 **8 点真实反冲伤害**，本回合所有护甲强制剥除，并陷入 **1 回合瘫痪（Stun）**，任由小队倾泻爆发！
*   **通关失败惩罚（Stack Overflow Panic）**：
    *   若 15 秒耗尽或小人掉入尖刺坑，小游戏画面突然定格并发出刺耳的死机蜂鸣（`BZZZZZZ-KLUNK!`），像老旧显像管电视断电一样在中央收缩为一个微弱白点后消散。
    *   切回战场后，全队因系统级溢出震荡，受到 **3 点无视护盾的穿甲 Token 真实扣除**；且触发该事件的 AI 少女下回合手牌被强制加上一圈“过载锁”，无法行动一回合！

## 五、 超常机制低频控制与防疲劳保护体系（Pacing & Fatigue Gating）

为了彻底杜绝此类搞怪、高交互机制喧宾夺主，导致玩家产生操作疲劳或厌恶情绪，游戏底层设立严格的**“四层递进式门禁控制网”**：

```text
 ┌────────────────────────────────────────────────────────────────────────┐
```

### 5.1 遭遇阶梯与概率权重

| 战斗遭遇类别 | 触发概率 | 允许出现的超常机制类型 | 触发先决条件 |
| --- | --- | --- | --- |
| **常规普通小怪战** | **0% (绝对禁止)** | 无（维持 100% 纯粹卡牌策略） | 无 |
| **普通精英怪战** | **15% ~ 20%** | 黑条涂抹 / 胶带阻尼 / 弹窗 | 节点带有 `[异常残留]` 或 `[死锁]` 词缀预告 |
| **特殊古董精英战** | **10% (单局限1次)**| **8-Bit 像素横版小游戏** | 仅限特定支线事件「古董级运行时」 |
| **章节交付 Boss 战**| **30% 概率触发一次**| 鼠标反转 / 25s死线 / 长按盖章 | **仅在 Boss 生命值低于 25% 的绝境爆发阶段** |

### 5.2 局内硬配额与防连击冷却（Hard Cap & Cooldown）

1.  **单局 Run 严格配额（Hard Cap）**：
    *   整局游戏（从开局到通关）中，**“8-bit 异维横版小游戏”至多触发 0~1 次**！一旦触发过一次，该 Run 的全局变量 `has_triggered_retro_minigame` 永久锁死为 `true`，后续绝不重现，保留极高的新鲜感与惊喜感。
    *   全场包含鼠标反转、黑条遮蔽等输入干扰机制，整局 Run 触发上限为 2 次。
2.  **战斗后强制冷却（Anti-Spam CD）**：
    *   若玩家在某场战斗遭遇了任何一种超常机制（如第一回合遭遇了鼠标反转），系统自动赋予队伍持续 **2 场战斗的「系统稳定性光环」**。在接下来的两场战斗中，所有超常机制判定直接绕过，触发率强制降为 0%！

### 5.3 视听预警与玩家心理预期（Telegraphing）

游戏绝对不搞无预警的“偷袭恶心玩家”：
*   **地图节点预告**：在选路界面，凡是可能遭遇超常机制的节点，图标右上方均附带一个黄黑相间的微型警示标 `[!] 物理干扰异常`；
*   **战前 2 秒大字警告**：在机制生效前，屏幕中央会闪过醒目但不刺眼的系统提示：`>> 警告：底层时钟紊乱 / 物理层漂移发生 <<`，给玩家足够的心理准备。

### 5.4 辅助功能开关（Accessibility & Agency）

在游戏系统的「设置 - 玩法偏好」中，常驻提供**【超常交互简化模式】**开关：
*   若玩家开启该模式：
    *   **鼠标反转/漂移**：自动关闭，替换为“本回合打出的第一张牌费用 +1”的等价卡牌策略 Debuff；
    *   **8-bit 横版过关**：跳过实际键盘跑酷操作，替换为一个“全队在 5 秒内打出任意 1 张防护牌即可自动判为通关”的策略检定通道。
*   此项设计确保动作障碍玩家、触控板玩家或只想要纯正卡牌构筑体验的玩家，依然能畅享游戏的核心乐趣。

## 六、 Godot 4.7.2 核心技术落地原型

### 6.1 8-Bit 像素着色器 (retro_crt_gb.gdshader)

用于将画面强行降级为 Game Boy 墨绿四阶与微凸 CRT 扫描线的后处理 Shader：

```glsl
// res://shaders/retro_crt_gb.gdshader
shader_type canvas_item;

uniform bool enabled = true;
uniform vec2 target_resolution = vec2(160.0, 144.0); // 经典 GB 分辨率
const vec4 GB_PALETTE[4] = {
    vec4(0.059, 0.220, 0.059, 1.0), // 最深墨绿
    vec4(0.188, 0.384, 0.188, 1.0), // 深绿
    vec4(0.545, 0.675, 0.059, 1.0), // 浅草绿
    vec4(0.608, 0.737, 0.059, 1.0)  // 亮底色
};

void fragment() {
    if (!enabled) {
        COLOR = texture(TEXTURE, UV);
        return;
    }
    
    // 1. 强行像素化下采样 (Pixelate)
    vec2 grid_uv = floor(UV * target_resolution) / target_resolution;
    vec4 src_color = texture(TEXTURE, grid_uv);
    
    // 2. 灰度转换
    float gray = dot(src_color.rgb, vec3(0.299, 0.587, 0.114));
    
    // 3. 量化映射至 GB 墨绿四阶色彩
    int index = clamp(int(floor(gray * 4.0)), 0, 3);
    vec4 gb_color = GB_PALETTE[index];
    
    // 4. 叠加水平 CRT 扫描线
    float scanline = sin(UV.y * target_resolution.y * 3.14159) * 0.1;
    COLOR = vec4(gb_color.rgb - scanline, 1.0);
}
```

### 6.2 异维小游戏核心沙盒控制器 (RetroPlatformerSandbox.gd)

```gdscript
# res://scripts/retro_platformer_sandbox.gd
extends Control
class_name RetroPlatformerSandbox

signal minigame_completed(is_success: bool)

@onready var player: CharacterBody2D = $PixelPlayer
@onready var timer_label: Label = $HUD/TimerLabel
@onready var crt_rect: ColorRect = $CRTScreenOverlay

var time_left := 15.0
var is_active := false

func launch_sandbox() -> void:
	visible = true
	is_active = true
	time_left = 15.0
	crt_rect.material.set_shader_parameter("enabled", true)
	player.global_position = $SpawnPoint.global_position

func _process(delta: float) -> void:
	if not is_active:
		return
		
	time_left -= delta
	timer_label.text = "TIME: %02d" % int(ceil(time_left))
	
	if time_left <= 0.0:
		_finish(false) # 超时失败

func _on_goal_reached() -> void:
	_finish(true) # 成功触碰终点

func _finish(success: bool) -> void:
	is_active = false
	crt_rect.material.set_shader_parameter("enabled", false)
	visible = false
	minigame_completed.emit(success)
```

## 七、 总结

本次扩充方案在保留前期高水准设计的基础上，达成了两项关键升级：
1. **脑洞机制的大胆突破（8-bit 异维像素小游戏）**：在严肃典雅的 AI 任务公路片中，设计了一次性强反差的“古董底层测试沙盒劫持”，15 秒极速跑酷兼具幽默、怀旧与战术戏剧性；
2. **工业级疲劳控制与玩家体验保护**：建立了一整套严格的局内配额（Run Hard Cap 0~1次）、遭遇概率门禁（小怪 0% 绝不出）、战后 2 战防疲劳冷却，以及设置菜单的无障碍兜底开关，确保超常机制成为**“旅途中令人津津乐道的高光点缀，而非破坏构筑体验的恼人噪点”**。
