## 一 设计总则与视听语言规范

### 1.1 总体视听定位
- **定位核心**：*温暖的任务公路片，藏着一座由数据残光搭成的记忆剧场。*
- **战斗场景本质**：战斗不是切换到与现实割裂的“异次元魔幻擂台”，而是**明线公路与工作台在面临“交付验收压力”时的结构性变形**。
- **克制原则**：
  1. 画面发光面积严格控制在 **15%** 以内，禁止满屏光污染、代码瀑布与霓虹泛滥。
  2. 角色始终是有生活温度的少女，保留 12~18 帧的清晰动作采样；数字 AI 感通过眼内对焦环、细微状态光缝、残像和阴影慢半拍等轻量级语言呈现。
  3. 扣费（向卡牌流动的琥珀/青色数据粒）与承伤（向受击方向崩散的粒子断裂）严格在形、色、声上区分，避免玩家误判。

### 1.2 非颜色强语义规则
为了保障色觉障碍无障碍体验及低分辨率下快速读招：
- **攻击类**：向前断面的锐角三角形、推进式箭头、切割裂隙；高频短促顿挫声。
- **防护类**：圆角双外框、层叠书页、向内收束包围弧；沉厚纸张压合声或水幕包裹声。
- **回复/支援类**：闭合回路、双向光弧、平缓流动的水纹；暖色微光、舒缓回甘音。
- **已行动/下线**：落下的书签/失活印记、离散虚线、连接点断开声。

## 二 角色与敌人动效系统设计

### 2.1 角色八层骨架与 2D Puppet 动画规范
在 `1280×720` 画布下，角色待机高度约为 **280px**（占屏高 33% 左右）。三名角色均继承统一的 8 层层级渲染协议：
```text
(底层) shadow -> aura -> back -> body -> head -> prop -> front -> effect (顶层)
```

#### 通用动作标签（Motion Tags）与动画曲线
单次出牌动画全长控制在 **0.75s ~ 1.15s**，快速连击或倍速模式下缩短至 0.5s：

| 动作类型 (motion_tag) | 动画时序与幅度 | 肢体与道具协同 (`prop` / `body` / `head`) | 镜头/位移表现 |
| :--- | :--- | :--- | :--- |
| **Idle (待机循环)** | 2.4s 呼吸循环，EaseInOut | `body` 微幅上下沉浮 4px；`head` 随呼吸微倾 1.5°；`prop` 悬浮微颤；`aura` 慢速轻拂 | 原地微幅呼吸，无镜头晃动 |
| **Basic (基础动作)** | 0.65s (前摇 0.15s, 释放 0.25s, 回位 0.25s) | 最精炼的单手引出或道具微展；不抢专属技能风头 | 向前滑移 20px，迅速回位 |
| **Light Attack (轻攻击)** | 0.85s (前摇 0.2s, 冲击 0.35s, 缓冲 0.3s) | 身体重心前倾 12px；手臂/道具朝向目标直线延伸；`front` 发带/衣角后扬 | 角色向前突进 45px，命中瞬间帧冻结 (Freeze Frame 2帧) |
| **Heavy Attack (重攻击)** | 1.15s (前摇 0.4s, 爆发 0.4s, 后摇 0.35s) | 明显的后撤蓄势（身体下沉 8px）；道具发光过载；双手同时爆发导向敌方 | 前冲 70px，屏幕纵向轻微震荡 2px，伴随局部中性补光聚焦 |
| **Guard (防护)** | 0.8s (展开 0.25s, 维持 0.35s, 收敛 0.2s) | 侧身面向保护目标（可为自己或队友）；手部向前平推；`prop` 展开屏障投影 | 角色在原位展开气场，重心下沉，稳固感增强 |
| **Support (支援/补给)** | 0.9s (引导 0.3s, 传输 0.35s, 确认 0.25s) | 道具托举至胸前；双手轻柔合拢；光芒由身体流向道具 | 原地微仰，向目标队友投射弧线光流 |
| **Transfer (额度转交)** | 1.0s (扣除 0.3s, 跃迁 0.4s, 目标接收 0.3s) | 使用者指尖引导出琥珀 token 核心；目标同伴做“低头接纳/光环升起”短回应 | 双角色间产生视线与连线互动 |
| **Hit (受击)** | 0.35s (受创击退 0.08s, 僵直 0.12s, 复位 0.15s) | 身体向后剧烈错位 25px；`head` 后仰；骨骼出现 2 帧的离散错位残影（像素微撕裂） | 整体红色边缘闪光一次，迅速复原 |
| **Offline (下线/力竭)** | 1.2s 单向不可逆 | 身体逐渐脱力微躬，半跪或站立低垂；透明度降至 45%，材质转化为灰度虚线与光点散落 | 角色从实体转为离散记忆剧场状态，状态条灰暗化 |

### 2.2 三位首发角色的个性化动作特征

#### 1. GPT (标准与结构 · 连攻主 C)
- **视觉特征**：珍珠白与淡蓝风衣、指尖悬浮的“小蓝云”、严谨明晰的逻辑几何。
- **动作设计语言**：
  - **分步推进 (G1)**：单手在虚空中快速点画出三级阶梯状的淡蓝菱形踏板，足尖轻点前移，最后指尖一弹，阶梯崩解为锐利光刺射向敌人。
  - **一鼓作气 (G2)**：蓄力时身后出现两条闭合的环形轨迹；连击满层时，两条环轨瞬间并拢、拉直为一条高穿透力的高亮淡紫白色光枪，GPT 双手推出光枪洞穿敌人。
  - **专属细节**：每次动作完成后，右手习惯性在胸前整理微斜的文件边角，严谨从容。

#### 2. Claude (检查与审校 · 保护反击)
- **视觉特征**：黑橙长裙、古典重装档案厚书、翻动的琥珀色书签。
- **动作设计语言**：
  - **最小改动 (C1)**：双手翻开沉重的黑色典籍，典籍中弹出一枚精致的橙黄书签，精准悬浮于受保护队友的额前，化为一本张开的半透明纸质保护页。
  - **逐条回应 (C2)**：轻挥书脊，空中浮现三行批注线，Claude 指尖划过，批注依次变为橙光刻刀逐道切向敌人核心。
  - **反击姿态 (Counter Ready)**：触发反击时，其厚书合拢，发出清脆的“啪”声，书脊上的橙色书签亮起并向上翻转，Claude 眼神微凛，进入审判准备姿态。

#### 3. DeepSeek (节约与蓄力 · 辅助爆发)
- **视觉特征**：深海蓝白女仆装、轻柔摆动的大鲸尾鳍、素雅白瓷饭碗与温润水纹。
- **动作设计语言**：
  - **稳住火候 (S1)**：双手稳稳端住白瓷饭碗，脚下泛开一圈清透的深蓝水纹，身侧微亮起柔和的温火光芒，一粒闪耀数据光泽的“饱满米粒”轻盈落入碗中（白饭层数增加）。
  - **提早开饭 (S2)**：高举瓷碗，碗内积攒的水纹骤然收束，身后的机械大鲸尾剧烈向前拍击，掀起一道由极度压缩的蓝白水浪与鲸尾弧光构成的冲击破，摧枯拉朽冲垮敌方。
  - **专属细节**：下线时双手仍将饭碗护在怀中，周身泛起细碎散逸的蓝色气泡水珠。

### 2.3 敌方造物动作设计 (四态循环)

敌人是现实生活/工作中“验收压力、混乱格式与交付障碍”的具象化造物。

| 对手名称 | 待机 (Idle) | 意图预告 (Anticipate) | 受击 (Hit) | 击败解构 (Defeat/Break) |
| :--- | :--- | :--- | :--- | :--- |
| **缺失附件 (Missing Attachment)** | 悬浮的文件信封匣上下起伏，胸口巨大的回形针附件空洞像吸尘器一样微弱收缩吸气。 | 附件空洞剧烈发红，周围伸出数条黑色数据线缆像八爪鱼般绷紧，指向目标槽位。 | 信封外壳震颤，掉落碎裂白纸屑，空洞闪烁灰白杂讯。 | 核心空洞被一张素白完整的“附件”填满，所有红线断开，机械盒自动合拢归档下落消散。 |
| **重复条目 (Duplicate Entries)** | 由 4~5 节一模一样的表格虫体组成，前后做波浪式同频蠕动，节拍机械一致。 | 每一节同时向上昂起，各节上的“相同行号”发出刺眼黄色闪烁，发出复读机般的警报。 | 虫身像手风琴般被压缩，节与节之间擦出火花。 | 冗余的节段一层层向中央对齐折叠，最终合并成一张单行表格薄纸，轻轻飘落。 |
| **口径冲突 (Metric Conflict)** | 背靠背的双指针机械刻度盘互相较劲，左右齿轮以不同角速度反向摩擦。 | 两根粗大的红色量规指针在空中缓缓向两侧拉开，蓄力交叉成一把巨大的“X”形剪刀。 | 左右仪表盘指针狂跳打滑，喷出冷白冷气蒸汽。 | 两根指针终于归零并对齐重合在同一条水平线上，外壳平衡解体，化为清脆金属碎音。 |
| **版面溢出 (Layout Overflow)** | 类似一扇被挤爆的文档门框，密密麻麻的文字行、红圈批注和超长表格如触手般四溢垂挂。 | 溢出的纸带触手汇聚并向屏幕中央暴涨，形成横贯整个己方队伍的宽幅红色方框。 | 纸带触手被切断一段，断口处化为字符碎屑飘散。 | 触手飞速回缩进文档门框之中，页边距自动排版紧缩，门扉“咔哒”一声整齐关严。 |
| **Boss: 本次提交版 (Submit Version)** | 巍峨的单页折纸塔，周围环绕着周报表格网格/投影片幕布，顶部挂着一柄巨大的金属验讫公章。 | 公章在半空悬起并高速充能下压蓄力，四周出现倒计时水印；若进入休整，则折纸塔合拢屏气。 | 塔身震荡，剥离一层泛黄的初稿废纸，露出内部更干净的第二版结构。 | 沉重的公章轻柔落下，印出一个端正稳固的绿色通行印章；杂乱折层尽数退散，留下一页轻盈发光的无暇成果。 |
| **Boss: 请确认收件人 (Recipient)** | 由老式信箱、翻页站牌与交织的红色收件人连线构成，胸口正中是一个漆黑的“空白座位”。 | 一根高压红线从地址栏抽出，在己方各位角色头顶依次扫过，最后死死钉在目标角色的胸口。 | 站牌快速翻滚打乱，信箱震落两封空白信封。 | 空白的座位被一束温暖柔和的暖阳打亮，正确的收件人地址连通成金线，站台闸门安静放行。 |

## 三 战斗音效 (SFX) 与视觉特效 (VFX) 体系

### 3.1 视效分层与配色哲学
- **发光率控制**：特效主体高光严格落在发光通道，柔光散开半径不超过 16px。
- **色彩含义**：
  - `#69D7E7` (冷青)：通用系统指令、校验成功、常规进攻轨迹。
  - `#F2B85B` (暖琥珀)：Claude 保护书页、token 转移、补给流向、达成共识。
  - `#EF6A62` (珊瑚红)：敌方蓄意攻击、受创判定、错误与矛盾项。
  - `#75C9A7` (薄荷绿)：生命/token 恢复、验收通过、状态刷新。
  - `#9A75F0` / `#C8D7FF` (淡紫白)：GPT 专用连击加成与穿透线。
  - `#204B9B` / `#BCE7FD` (深蓝青)：DeepSeek 专用低火水纹与鲸浪。

### 3.2 角色机制核心视效 & 音效 (VFX & SFX)

#### 1. GPT · 连击系统 (Streak)
- **VFX (视觉)**：
  - **0 层 -> 1 层**：GPT 身后浮现一条半透明圆弧轨迹（长度 180°），尾端带着冷青小光点。
  - **1 层 -> 2 层 (满连击)**：圆弧轨迹闭合成一个完整的发光双环圆规轨道，环内开始有淡紫白的数据粒子顺时针高速循环旋转。
  - **满连击打出攻击卡**：双环瞬间爆裂聚拢成一直线光束，光束前方带有 3 重锐角箭头。
  - **断连击**：若使用非攻击卡或跳过，光环不发生爆炸，而是像断电的霓虹管一样轻柔由亮转暗、自然熄灭消散。
- **SFX (音效)**：
  - 1 层：`UI_GPT_Streak1.wav`（清脆的终端回车键敲击声 + 上行单音电子和弦音，D大调）。
  - 2 层：`UI_GPT_Streak2_Full.wav`（两声连续快速的高音清脆跳键 + 环形蜂鸣共振音）。
  - 断连：`UI_GPT_Streak_Drop.wav`（低沉轻柔的电子降音，如同纸张滑落在桌面）。

#### 2. Claude · 保护与对齐反击 (Riposte)
- **VFX (视觉)**：
  - **提供保护**：受保护者脚下升起一个半透明的书页护框（外层带有括号 `[ ]` 几何暗纹，琥珀色微光）。
  - **实际挡伤判定**：敌方攻击撞击护框，护框泛起金色纸张层叠波纹，挡住所有伤害；同时一根带着橙色流苏的书签从护框弹回 Claude 的书本中。
  - **反击就绪 (Riposte Ready)**：Claude 头顶悬浮一枚优雅的橙金书签徽记，典籍封面浮现一圈金色校验文字。
  - **释放反击**：下一次攻击时，特效在常规弹道上附加一道金色的巨大“批注修订裁决划线”，斩断敌方外壳。
- **SFX (音效)**：
  - 施加保护：`VFX_Claude_PageShield.wav`（厚重羊皮纸或铜版纸快速翻动拂过的舒缓风声）。
  - 挡伤触发：`VFX_Claude_BlockSuccess.wav`（硬质书脊撞击沉稳木桌的敦厚声 + 极清脆的金属书签扣合声）。
  - 反击释放：`VFX_Claude_Riposte_Slash.wav`（高速破空的风刃声伴随羽毛笔用力划过纸面的划刻声）。

#### 3. DeepSeek · 白饭蓄力与兑现 (Rice Cooking)
- **VFX (视觉)**：
  - **1 层白饭**：DeepSeek 脚底荡开一圈淡青色细水纹，碗中冒出一缕微弱的白色蒸汽。
  - **2 层白饭**：水纹扩展为双重涟漪，碗中光芒凝实为温润的圆玉珠光。
  - **3 层白饭 (满层)**：三重水纹在脚下有节奏地起伏，DeepSeek 周身环绕着小型透明鲸鱼虚影，身侧浮现蓝白色的水幕浪花。
  - **提早开饭 (S2 兑现)**：水纹瞬间倒吸回瓷碗中，随后一道高饱和度的深蓝青色鲸尾巨浪向前拍出，撞碎敌人外壳。
- **SFX (音效)**：
  - 增层：`VFX_DS_Rice_Bubble.wav`（清脆水滴落入温水的声音 + 砂锅低火咕嘟轻鸣）。
  - 满层：`VFX_DS_Rice_Full.wav`（低沉宁静的远方座头鲸叫声谐振，极具安全感）。
  - 开饭爆发：`VFX_DS_CashIn_Wave.wav`（厚重浪潮澎湃拍击堤坝的重低音轰鸣，夹杂瓷器清脆碰击）。

## 四 战斗场景与验收态环境设计

### 4.1 场景总览与通用分层构架
所有战斗场景均沿用 `1280×720` 的视差结构，严格分为四层：
```text
远景层 (Parallax 0.2x) -> 中远景地标 (Parallax 0.5x) -> 核心战斗舞台 (Parallax 1.0x) -> 前景可读/UI保护层
```
在战斗打响时，场景触发**验收态变形**：地表的纸层卷起收紧、天空云雾退散露出排版网格、周围任务道具转入待命警备角度，但角色脚下地平线始终保持水平坚固。

### 4.2 场景 A：纸页旷野 (Paper Wasteland)
- **从属章节**：第一章（委托：“把本周做成一页” / “最后一页”）
- **核心意象**：由层层叠叠的白纸、折叠页角、巨大的 Excel 表格网格梯田以及远处只有“一页厚度”的纪念碑组成的奇迹平原。

```text
┌─────────────────────────────────────────────────────────────────┐
│ 远景：苍穹为淡淡的墨蓝渐变，远处立着巨大的白色单页剪影(终点地标)  │
│ 中景：由巨型排版辅助线、折叠便签山峰和横向数据梯田构成的旷野    │
│ 近景地面：整洁微泛暖黄的 A4 纸层地表，边缘带有微微翻卷的立体纸褶 │
│ 舞台两侧：左侧停泊着小巧的行旅终端车车尾，右侧为敌方生成的错误区域│
└─────────────────────────────────────────────────────────────────┘
```

#### 两个任务装饰变体：
1. **周报变体 (Weekly Report)**：
   - 地表布满横向表格虚线与交错行斑马纹；
   - 场景中点缀着被风吹拂翻飞的黄色便利贴旗帜；
   - 远处地标上投射着跳动的工作进度百分比光影。
2. **演示变体 (Slides/Presentation)**：
   - 纵向宽屏幕布构图，地面变成幻灯片放映台的磨砂亚克力反光板；
   - 场景中有从天空射下的聚光灯束，打在散落的图表展板上；
   - 远景是一座层层展开、如同剧场幕布般的白色山峦。

#### 两个人生阶段覆盖层 (Overlays)：
- **大学生覆盖层 (Student)**：
  - 纸张带有手写圆珠笔涂鸦痕迹、荧光黄色划线批注、散落的橡皮屑；
  - 光照为斜照进教室百叶窗的明朗午后暖阳；
  - 终端车窗上贴着手绘的日程贴纸和小猫便签。
- **公司员工覆盖层 (Employee)**：
  - 纸张边缘带有严谨的条形码、机打公文编码和打孔装订孔；
  - 光照为写字楼傍晚的冷蓝天光与温暖工位台灯的交织冷暖对比；
  - 终端车顶上载着整齐归档的黑色硬质文件夹箱。

### 4.3 场景 B：收件站 (Cloudside Recipient Station)
- **从属章节**：第二章（委托：“请留一个座位” / “把那一天找回来”）

```text
└─────────────────────────────────────────────────────────────────┘
```

#### 两个任务装饰变体：
1. **邀请变体 (Seat Invitation)**：

2. **相册变体 (Photo Memory Archive)**：
   - 地面铺满了像潮汐般微微翻动的半透明胶卷底片；

   - 空气中漂浮着散发微光的时间戳小字（如 `2024-06-12`）。

#### 两个人生阶段覆盖层 (Overlays)：
- **大学生覆盖层 (Student)**：
  - 站台上放着旅行双肩包、运动水壶与一张学生半价车票；
  - 氛围像毕业季离校前夕的黄昏车站，带着青涩的期待与不舍；

  - 站台长椅旁立着一把收拢的长柄黑伞与皮质公文包；

  - 告示牌上张贴着清晰但冷冰冰的列车班次表。

## 五 卡牌插画与卡面视觉设计

### 5.1 卡面架构与尺寸基准
- **卡牌标准画布**：`150 × 210 px`（比例 5:7），在战斗中悬停放大为 `205 × 287 px`。
- **卡面黄金四层分区**：
  1. **顶部 Header (14%)**：左上角费用圆章（以金属印章形式凹陷，数字加大）；正中卡名；右上角升级星芒标（未升级为空心浅金，已升级为实心亮金）。
  2. **中部 Illustration Frame (52%)**：带有 1px 细线边框的插画区。插画内严格不包含任何文字、数字与图标，纯靠视觉构图传意。
  3. **下部 Rule Text (24%)**：纸白底磨砂衬底，左对齐规则文本。关键数字（伤害 `6`、防护 `4`）字号放大 130% 并上色，前方配以极简微图标。
  4. **底部 Footer (10%)**：左侧类型标签（`攻击` / `防护` / `支援` / `转交`），右侧归属标记（通用为素白星标，专属为 GPT 蓝云 / Claude 书签 / DeepSeek 水滴印章）。

## 结语与后续接入建议

本设计严格遵循《未尽之托》**“规则执行口径 docs/规则基准.md”** 与 **“首批内容.json”**，在不修改任何底层战斗数值与时序机制的前提下，为 Demo 构建了完整的视听闭环。

在后续实机开发推进时，建议采取以下敏捷替换流程：
1. **第一步（卡牌视觉）**：直接将 12 张卡牌插画导入 `game/assets/cards/illustrations/`，Godot 卡牌预制体读取卡牌 ID 自动绑定插画纹理。
2. **第二步（音效通道）**：按表中的 `motion_tag` 和卡牌 ID，在 `CardModel` 中注册 `sfx_path`，于出牌命中帧调用 `AudioController.play_sfx()`。
3. **第三步（场景视差与验收态）**：加载《纸页旷野》与《收件站》的 4 层视差背景，并配置开战时地形微折与收紧的环境 Tween 补间动画。
4. **第四步（特效与反馈完善）**：依次补齐 Claude 保护反击的橙色书签与 DeepSeek 的 1~3 圈动态水纹粒子，达成高完成度的垂直切片交付。
