## 实现范围

已实现标题页、GPT / Claude / DeepSeek 选择、普通战、休息恢复、Boss 战和结果页。规则层位于 `game/scripts/game_rules.gd`，不引用任何 UI 节点；界面只调用预览、行动、回合和结算接口。

## 实际验证

以下命令均已实际执行并成功：

```powershell
powershell -ExecutionPolicy Bypass -File .\_build\sync_game_data.ps1 -Check
node .\_build\validate_gameplay_v05.cjs
godot --headless --path .\game --script res://tests/test_rules.gd
godot --headless --path .\game --script res://tests/smoke_runs.gd
godot --headless --path .\game --script res://tests/test_ui_flows.gd
godot --headless --path .\game --export-release "Windows Desktop x86_64" ..\dist\windows\LeftInTrust.exe
.\dist\windows\LeftInTrust.exe --headless --quit-after 3 -- --seed=20261025
```

结果：

- 既有 Node 规则验证：34 项通过。
- Godot 规则层：13 / 13 通过；覆盖十二张初始牌与抽弃循环、多角色牌组、固定 seed、支付原子性、一次行动、防护与多段伤害、下线与锁定目标、击杀停手、三名角色被动及战斗实例登记。
- 主场景 UI 流程：三名角色各自完成普通战、休息和 Boss 战。
- Windows x86_64 release：成功导出并从非编辑器环境启动，退出码 0。
- 导出文件：`dist/windows/LeftInTrust.exe`，109,202,856 bytes，SHA-256 `6E553A038825090F9D03DFB36295A76F5CF4951456A8C9E518D9CF9367A3BC80`。
