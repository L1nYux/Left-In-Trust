## 一、 怪物外观设计哲学与通用美术管线

在《未尽之托》的美术工业化生产中，怪物（对手）的外观设计绝非奇幻怪兽、赛博生化人或张牙舞爪的恶魔，而是**“现实工作与生活委托中的具体障碍，在验收压力下异化而成的功能性科技造物”**。

```text
 ┌────────────────────────────────────────────────────────────────────────┐
 │                      怪物外观设计的四大视觉戒律                         │
 ├────────────────────────────────────────────────────────────────────────┤
 │ 1. 办公物料异化：以纸张、信封、网格、回形针、时钟、量尺、闸门为本体骨架 │
 │ 2. 剪影对峙原则：友方以连续弧线/圆角为主；敌方以尖角、截断线、套框为主  │
 │ 3. 冗余剥离美学：受击不喷血爆裂，而是脱落冗杂草稿、校正错位、补齐空洞  │
 │ 4. 严禁妖魔化现实：不画丑化的人形老师/上司，关底是“考核体系与终审环境”│
 └────────────────────────────────────────────────────────────────────────┘
```

### 1.1 画布尺度与比例阶梯（基于 1280 × 720）

在战斗对峙舞台（`Y=54–438`）中，右侧对手的体量必须与左侧 2~3 名角色（单人高约 280 px，三人站位宽度约 360 px）形成鲜明的视觉对应关系：

```text
       ┌───────────┐
       │ 普通怪    │ 尺寸：约 260×220 px ~ 280×240 px
       └───────────┘ 视觉特征：轻盈悬浮、单一故障焦点、占画面约 1.2 倍单人宽度
             │
       ┌───────────┐
       │ 精英怪    │ 尺寸：约 340×280 px ~ 380×300 px
       └───────────┘ 视觉特征：多层复合结构、机械咬合、占画面约 1.8~2.0 倍单人宽度
             │
       ┌───────────┐
       │ 角色特色怪│ 尺寸：约 320×280 px ~ 360×320 px
       └───────────┘ 视觉特征：鲜明的机制符号隐喻（树/钟/标/柱），高辨识度意图轮廓
             │
       ┌───────────┐
       │ 关底 Boss │ 尺寸：约 420×320 px ~ 480×380 px
       └───────────┘ 视觉特征：宏大建筑装置、跨越地面与天际、占画面约 2.2~2.6 倍单人宽度
```

### 1.2 统一材质渲染与标准色板

所有怪物严格遵循以下材质与色彩组合，严禁出现高饱和度糖果色霓虹与脏乱泥浆质感：

| 材质类型 | 视觉质感描述 | 标准色值与应用部位 |
| --- | --- | --- |
| **特种纸浆与卡纸** | 带有细微植物纤维毛边、受压折痕反白、哑光微透光 | 纸面白 `#F2EFE7`、暖米黄 `#E8E2D5`（外壳、书页、纸带） |
| **亚光冷轧钢与钣金** | 工业级哑光喷涂、平滑边缘倒角、微弱线性拉丝高光 | 墨蓝黑 `#0A101B`、工业深灰 `#252D3B`、冷钢灰 `#4A5568`（骨架、滑轨、闸门） |
| **警示与故障 HUD** | 半透明全息光膜、高对比度断续虚线、激光刻度 | 珊瑚红 `#EF6A62`（受压警示、故障核心、裁切线、错印） |
| **系统校验与通流** | 纯净冷光、平滑连续光弧、晶体透射光 | 冷青 `#69D7E7`、薄荷绿 `#75C9A7`（数据回路、对齐基准、准予印章） |
| **历史磨损与便签** | 边缘泛黄微卷、背胶半透明、圆珠笔划痕 | 暖琥珀 `#F2B85B`、便签淡黄 `#FBF3C4`（历史注释、临时路标、发票） |

### 1.3 工业级 6 层 2D 骨骼切片规范（Godot 运行容器）

每个怪物交付必须包含主概念全景透明图（Master Sheet）与 6 层分层独立切片（Layer Slices），以支持 Godot 的 `Node2D` 动画树插值与独立 Shader 效果：

```text
  [EnemyMasterNode (Node2D)]
  ├── layer_0_shadow : 地面柔和接触阴影（带 Y 轴缩放与呼吸淡出）
  ├── layer_1_back   : 背部结构（背向连接线缆、后置散热格栅、阴影纸片）
  ├── layer_2_body   : 主体框架（机身壳体、主文件夹外壳、核心机械臂）
  ├── layer_3_core   : 能量核心与故障焦点（红光空洞、发光齿轮、跳动发条、电离晶核）
  ├── layer_4_front  : 前景游标与活动部件（前景爪具、表层翻动便签、滑动游标、指针）
  └── layer_5_effect : 前景粒子与光栅层（悬浮 01 碎屑、激光警戒线、全息扫描框）
```

### 1. 「缺失附件」(Missing Attachment) —— *官方标准范例完善*

```text
         ┌─────────────────────────┐
         │     [ 虚线回形针 ]      │ ── 漂浮在空洞上方的冷青全息回形针
         │   ┌─────────────────┐   │
         │   │ 黑色金属折叠机匣│   │ ── 双侧微型伺服合页
         │   │   [ 附件形空洞 ] │   │ ── 贯穿机身的大号回形针负空间，向外辐射红光
         │   │  (漏光与断线触手)│   │ ── 四条在地面爬行的黑色细绝缘线缆
         │   └─────────────────┘   │
         └─────────────────────────┘
```

#### 1.1 核心轮廓与材质
*   **主体造型**：一个横向悬浮的折叠式黑色金属档案夹，外壳为亚光炭黑冷轧钢（`#1F242D`），中间被粗暴地镂空出一枚**巨型回形针形状的贯穿式空洞**。
*   **材质细节**：空洞边缘参差不齐，露出撕裂的白卡纸纤维与微弱短路的橙红火花；机身下方垂下 4 根黑色细绝缘线缆，线缆末端带有裸露的金属铜丝探针，如同机械蜘蛛的爬行足。
*   **尺寸与构图**：运行容器 405 × 350 px，美术净轮廓约 400 × 267 px，离地悬浮约 25 px。

#### 1.2 6 层骨骼切片拆解
*   `layer_0_shadow`：椭圆形半透明墨蓝暗影（`#0A101B`，Alpha 0.45），随悬浮上下呼吸微缩。
*   `layer_1_back`：后侧两根辅助支撑线缆，表面带有冷钢高光与阴影。
*   `layer_2_body`：主档案夹外壳，分为左扇与右扇，带有一道浅灰中轴合页。
*   `layer_3_core`：位于机匣正中的回形针空洞内衬，常驻珊瑚红（`#EF6A62`）脉冲光晕，边缘带有电火花发光点。
*   `layer_4_front`：前景活动机爪与挂在外壳上的半透明文件索引标签「`Attachment_NotFound.dat`」。
*   `layer_5_effect`：从空洞边缘向外四散飘飞的白色纸片碎片粒子，带轻微的重力下坠。

#### 1.3 四态微动与形变
*   **待机姿态**：机匣在空中以 1.2 秒为周期沉浮，4 根底足在线缆弹性下轻微点地；核心红光如心跳般以 0.8 Hz 缓慢呼吸。
*   **蓄力预告**：双侧金属夹板向内猛烈收缩 15%，核心空洞红光骤然暴涨为刺目白红，探针尖端射出两道微弱的红外引线锁定角色槽位。
*   **受击解构**：受击时外壳向后倾斜，边缘的冗杂数据线一根根断裂自融；生命低于 30% 时，空洞内部浮现出一枚半透明的纯白信件轮廓。
*   **击败消解**：空洞被一张完全匹配的素白特种纸附件完美“填平嵌合”，红光瞬间转为平静的薄荷绿；外壳如折纸般平顺合拢，化作一枚标准的规整文件夹，沉入地平线归档。

### 2. 「404 空链接」(Broken Hyperlink)

```text
             ┌───┐
             │ ? │ ── 悬浮的浅青全息锚点框
       ┌─────┴───┴─────┐
       │ ── ── ── ──   │ ── 断裂的蓝色下划线（带虚线游标）
       │  [404] 晶体匣 │ ── 破碎的冰蓝色亚克力方盒
       └───────┬───────┘
              ╱ ╲        ── 两根晃荡的断裂光纤线缆（末端漏电）
```

#### 2.1 核心轮廓与材质
*   **主体造型**：一个由两条悬浮的亮青色双下划线（带跑马灯虚线）承托的微型亚克力晶体方盒。方盒中间刻着破碎的镂空数字 `404`。
*   **材质细节**：方盒采用半透明磨砂亚克力（冷青色 `#69D7E7`，Alpha 0.75），内部可见微小的折射三棱镜；底部挂着两截断裂的透明玻璃光纤线缆，线头不规则断裂，不断冒出冷白色的数据漏电火花。
*   **尺寸与构图**：运行容器 280 × 260 px，美术净轮廓约 260 × 220 px，高位悬浮。

#### 2.2 6 层骨骼切片拆解
*   `layer_0_shadow`：极浅的冷灰圆形悬浮投影，随高度变化淡入淡出。
*   `layer_1_back`：后侧的断开虚线轨道与一圈暗淡的网页锚点选框 `<a>`。
*   `layer_2_body`：磨砂亚克力晶体方盒本体，表面有细腻的冰裂纹理。
*   `layer_3_core`：方盒内部的 `404` 浮雕发光字模，发光中心呈琥珀金与冷青交织。
*   `layer_4_front`：前景断裂的两根发光光纤探针与前端的亮青色游标箭头。
*   `layer_5_effect`：光纤断口处随机迸发的微小方块乱码粒子（`0x00`、`NULL`）。

#### 2.3 四态微动与形变
*   **待机姿态**：在空中轻微上下漂浮，断线光纤如同水草般缓速摆荡，双下划线上的冷青虚线以跑马灯形式向左持续平移。
*   **蓄力预告**：晶体盒内部的 `404` 字符转为猩红，两截光纤线缆猛烈绷直，断口处的电弧汇聚成一枚锐利的刺针状准星。
*   **受击解构**：受击时光纤剧烈抖动，亚克力方盒裂纹扩大，掉落几枚半透明的玻璃碎片。
*   **击败消解**：两根断裂的光纤在线缆磁力引导下“咔哒”一声紧密对接，下划线瞬间闭合为一条平滑无瑕的通车实线，404 字符被替换为翠绿的 `200 OK`，整体化作一缕青烟散去。

### 3. 「乱码字符群」(Corrupted Encoding)

```text
            ◆ [ ? ]
       ┌───┐    ┌───┐
       │   │ ∷  │æø │ ── 错乱翻转的 UTF-8 / GBK 黑白字模方块
       └───┘    └───┘
         ▲ 乱码风暴核 ▲ ── 墨蓝黑重力坍缩空腔
       ┌───┐    ┌───┐
       │   │ ∷  │   │
       └───┘    └───┘
```

#### 3.1 核心轮廓与材质
*   **主体造型**：一个由 12 枚黑白相间的精密机械字模方块围绕一个微型引力黑洞高速自转构成的“几何字符星团”。
*   **材质细节**：字模方块为哑光象牙白树脂与炭黑金属双色拼接，表面印有黑底白字或白底黑字的错乱字符（包括黑色菱形白问号 ``、北欧字母 `ø`、乱序日文片假名与西里尔字母）；字模之间由微弱的静电弧相连。
*   **尺寸与构图**：运行容器 280 × 280 px，美术净轮廓约 250 × 240 px。

#### 3.2 6 层骨骼切片拆解
*   `layer_0_shadow`：地面散射状的多点微弱投影，随方块转动闪烁。
*   `layer_1_back`：位于引力核后方的 5 枚高速公转的暗色小方块与深色静电引力线。
*   `layer_2_body`：中央引力核心（墨蓝黑坍缩球体，表面泛着油膜般的干涉色）。
*   `layer_3_core`：中央引力核内部的微型冷青色编码罗盘，刻有 `UTF-8`、`GBK`、`ISO-8859` 刻度。
*   `layer_4_front`：前景 7 枚清晰的大号字模方块，包括正面最大的 `` 菱形方块。
*   `layer_5_effect`：外围翻滚的字符光屑、断续的黑色方块噪点（Bilinear Moire 干扰）。

#### 3.3 四态微动与形变
*   **待机姿态**：12 枚方块像行星环一样围绕核心平稳公转，每个方块每隔 0.6 秒如翻牌时钟般“啪嗒”自转 90 度，变换展示的乱码。
*   **蓄力预告**：公转速度骤然加倍，所有方块拉直收缩成一柄锐利的双刃字符长矛，枪尖直指受击槽位，闪烁高频红白交替光芒。
*   **受击解构**：受击时外围方块被击飞后在引力拉扯下重新归位，每次受击都有一枚乱码方块被纯化为工整的汉字或英文词根。
*   **击败消解**：所有方块停止公转并迅速靠拢，在中央罗盘的清脆校正声中拼合为一个完整的方正字典印章，向地面盖下一个「校验通过」印记后化为光尘。

### 4. 「未保存草稿」(Unsaved Draft)

```text
          ╭───────╮
         ╱  草稿   ╲
        │ 揉皱折痕 │ ── 质地轻薄的半透明方格信纸折叠燕雀
         ╲ 铅笔稿 ╱
          ╰───┬───╯
              │ ── 尾部拖带的闪烁文本垂直光标 [ | ]
```

#### 4.1 核心轮廓与材质
*   **主体造型**：一只由单张薄型半透明带格草稿纸手工折成的机械纸燕。纸身上布满了反复擦写的铅笔痕迹与细碎褶皱。
*   **材质细节**：纸张呈现温润的纸白中略带微透（`#F2EFE7`，微透光），纸面印刷着极淡的灰蓝网格（Grid line）；燕尾末端拖着一条半透明且高频跳动的深青色文本垂直光标 `|`（Text Cursor）。
*   **尺寸与构图**：运行容器 260 × 240 px，美术净轮廓约 240 × 200 px，飞行掠地体态。

#### 4.2 6 层骨骼切片拆解
*   `layer_0_shadow`：极为轻盈柔和的纸燕轮廓阴影，随翅膀扇动变形。
*   `layer_1_back`：后侧折叠翼板与后掠的浅灰纸质尾翼。
*   `layer_2_body`：纸燕的主体纸质折痕躯干与腹部。
*   `layer_3_core`：纸身中轴线内部蕴藏的一根半透明铅笔芯骨架（泛着石墨微光）。
*   `layer_4_front`：前侧主翼板，表面有清晰可见的手绘红笔问号与被擦掉的阴影。
*   `layer_5_effect`：尾部闪烁的文本光标 `|` 及伴随扇翅飘落的微小白石墨粉末。
