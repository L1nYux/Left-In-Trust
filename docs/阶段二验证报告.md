唯一人工数值源：docs/首批内容.json，同步 SHA-256 18a3f160d32c50dedf33dad868e55e7a3d45e97b0bacbbe84c45cafa900df232

## 实现结果

- 常规委托支持 1–2 人编队；三名现有角色可进入独立测试场。
- 每名在线角色每回合至多行动一次，玩家可自由选择行动顺序和角色目标。
- 费用从使用者个人余额支付；防护、补给与额度转交按所选角色结算。
- 敌人按上场槽位轮换并在回合开始锁定目标；目标中途下线后，剩余攻击段空过。
- 下线只封存下线者的专属牌；队友继续战斗，健康替补不会自动入场。
- 胜后所有正余额已入队成员（含替补）各恢复 3；0 token 不复起。
- SaveManager 独立于 GameRules 与界面，使用“完整快照 → 临时文件 → 重读校验 → 上一有效备份 → 替换主档”的落盘流程。
- 快照封套包含 schemaVersion、SHA-256 和完整 payload；主档损坏或校验错误时恢复 .previous，不支持的 schema 返回明确错误且不删除文件。
- 战斗结算由 battle instance 与 node 共同去重；重载、重复点击和结算中断不会重复发放 token、算力或奖励。
