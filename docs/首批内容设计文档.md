## 0. 文档定位与效力

### 0.1 为什么需要这份文档

到 2026-10-26，视觉、数值、战斗设计分散在五份"策划案级"文档里：《对手设计与战斗场景规范》《精细化战斗场景设计方案》《精细化战斗与日常待机动作设计》《Demo视听与表现设计方案》《精细化怪物外观设计方案》，另有《UI与战斗美术重构方案》《总体视觉风格》提供通用规范。它们同时写了首批内容与后续内容，导致"做首批"时无法一眼看出：

- 哪些条目属于首批（9 个对手、12 张卡、3 名角色、4 个场景）；
- 哪些条目有可直接执行的规格，哪些只有概念；
- 数值的唯一口径在哪里、与设计文档是否冲突；
- 现有引擎能跑到什么程度。

本文档做三件事：**圈定首批范围 → 把首批需要的地方从各设计文档抽出来 → 明确标注完成度与缺口**。它不是新的数值源，也不替代任何设计文档；设计文档仍是原始出处，本文档是首批制作与验收的执行视图。

### 0.3 状态标签

全文使用五种标签，避免"文档写了"被误读为"游戏里有"：

- **【已定稿】**：数值/规则已入库并通过校验（当前仅第 2 节数值）。
- **【有完整规格】**：设计文档给出可直接制作的分层、尺寸、色值、时长。
- **【概念级】**：设计文档只有一两句母题描述，缺分层/尺寸/分镜。
- **【缺口】**：首批需要，但五份设计文档都没有给出。
- **【未实现】**：引擎/资产中不存在，仅设计存在。

## 3. 战斗设计现状（首批 9 个对手怎么打）

> 本章只写"这批敌人与现有规则/引擎的关系"。数值见第 2 节；视觉见第 4 节；场景演出见第 5 节；引擎证据见第 3.3 节与 `_build/drafts/首批_引擎映射与数值核对.md`。

### 3.1 规则口径（首批适用的部分）【已定稿】

- 个人 token 同时是生命与费用，上限 12，跨战斗继承；战内降到 0 即下线封存，本场不能复活。
- 每人每回合一次行动（出 1 张牌或基础攻击/基础防御）；共享抽牌每回合 5 张；回合末防护清空。
- 胜利结算：所有正余额（含替补）各 +3；普通战奖励 4，Boss 战奖励 8。
- 引擎已实现：单敌人、**多段攻击（逐段结算，但所有段共用同一目标）**、`target:"rotate"` 轮换、Boss 休整段、按回合拖延加压 `floor((turn-1)/4)` 只加到首个正值段。
- 引擎未实现：群攻、敌人侧护盾、减伤、意图伪装、双阶段、奇数轮反馈、偶数轮 AI 镜像、难度加压 `floor(D/2)`、`stageOnly`/`challenge`/`hidden` 入口。逐项证据见 3.3。

### 7.3 发光与可读性硬规则

- 战斗开始画面发光面积 **≤15%**；卡牌展开时场景发光与粒子降到约 **60%**。
- 发光只用于表示**状态**（连击、白饭、防护、校验、反击就绪），不用于装饰性满屏特效。
- 状态不能只用红/绿颜色区分，必须有形状或位置语义（如书签、水纹圈、双环、方框准星）。
- 每个场景只保留**一个高密度视觉焦点**；手牌与 token 条永远优先于背景演出。
- 敌人意图预告必须同时给"形状、颜色、方向、节奏"四类线索中的至少三类；纯数字/纯文字预告不可接受。

### 7.4 剪影、朝向与受击

- 全场敌人**面向左**，玩家角色在左、敌人在右；角色站位 GPT 左前、Claude 左后、DeepSeek 左前或中位。
- 友方连续弧线/圆角，敌方尖角/截断线/套框——双方剪影必须在小尺寸下可区分。
- 受击不喷血：表现是"草稿脱落、校正错位、补齐空洞、数据碎片化"。
- 敌人受击/退场只走 `purification_dissolve` 消解通道，**禁止**破碎颗粒物理爆炸；"我"连消解都不做，直接定格留座。
- 战斗胜利不做满屏烟花：只让正确路径连上、一个座位点亮、一张照片稳定。

### 7.5 禁止项（表现层）

- 不用整屏滚动代码表现"AI 很聪明"；不用不停弹窗表达"警告"；不用大量食物梗遮住任务信息。
- 不把女仆造型等同"服从"、不把红色批注做成无意义的满屏噪点。
- 场景发光/粒子不得超过 7.3 阈值，不得盖住卡面数值与 token。

### 8.2 消解 Shader（敌人受击/退场的唯一通道）

```glsl
// purification_dissolve.gdshader
shader_type canvas_item;

uniform float dissolve_amount : hint_range(0.0, 1.0) = 0.0;
uniform sampler2D noise_texture;
uniform vec4 clean_color : source_color = vec4(0.95, 0.94, 0.91, 1.0); // 纸面白
uniform vec4 edge_light_color : source_color = vec4(0.41, 0.84, 0.91, 1.0); // 冷青

void fragment() {
    vec4 base_color = texture(TEXTURE, UV);
    float noise_val = texture(noise_texture, UV).r;
    if (noise_val < dissolve_amount) {
        discard;
    } else if (noise_val < dissolve_amount + 0.08) {
        COLOR = mix(clean_color, edge_light_color, (noise_val - dissolve_amount) / 0.08);
    } else {
        COLOR = base_color;
    }
}
```

| 参数 | 取值 | 语义 |
| --- | --- | --- |
| `dissolve_amount` | 0.0–1.0，默认 0 | 消解进度 |
| `noise_texture` | 噪声图 | 取 `.r` 通道 |
| `clean_color` | `vec4(0.95,0.94,0.91,1.0)` | 消解边缘去向＝纸面白 |
| `edge_light_color` | `vec4(0.41,0.84,0.91,1.0)` | 边缘光＝冷青 |
| 边缘带 | 硬编码 `0.08` | 混色带宽度 |
