## 一、设计总则与核心哲学

在《未尽之托》（Left in Trust）的世界观与玩法闭环中，对手体系严格遵循以下四条核心戒律：

1. **现实物料与工作痛点的科技化异化**：对手绝非奇幻魔物、机械怪兽，亦绝不把现实中的师长、上司、评审或亲友妖魔化。它们全部源于**“现实委托在验收压力下具象化形成的故障实体”**——是缺失的文件、未对齐的口径、死锁的代码依赖、严苛的时限钟塔，以及不可理喻的边界条件。
2. **纯净解构与归档美学（非血腥破坏）**：敌人的生命条代表“问题冗余度与混乱度”。受击不是断肢喷血，而是**“剥离繁杂附页、校正错位刻度、闭合缺口、对齐网格”**；击败退场永远是一场解脱式的温柔归档（如盖上准予通过的翠绿印章、多余图层散落后露出清爽平整的成品单页）。
3. **四维意图预告（意图可视化）**：每一个对手的行动意图必须在回合开始时由「形状、颜色、轨迹、节奏」四重线索清晰展示。单体攻击带收束线锁定角色槽位，多段攻击显示刻度分节，群体攻击横贯全队宽框，休整呈现舒缓开放光环。
4. **场景的有机互动与动态形变**：敌人登场与行动会直接改写战场地形动作。小怪引起微小的网格畸变，精英怪引发空间折叠与轨道断裂，关底 Boss 甚至直接将世界重构为独有的“验收考场”或“午夜监控中心”。

## 二、普通怪设计（Sub-problems / 任务日常顽疾）

普通怪是探索路段中的子问题，单体威胁明确，轮廓简洁，动作周期短（2~3回合循环），用于消耗队伍 token 并考验基础攻防与发牌轮转。

### 1. 「404 空链接」(Broken Hyperlink)

*   **生态定位**：网络与引文检索委托中最易遇到的断头路。
*   **出没场景**：【纸页旷野·断桥路段】/【收件站台·废弃侧线】。

#### 1.1 外观设计
*   **核心轮廓与材质**：由一条断开的亮青色超链接下划线（带虚线光效）和一个半透明的悬浮方框锚点构成。方框内部是灰蓝色的 `404` 镂空数字，边缘缠绕着几根寻找插口却不断漏出幽蓝电火花的断裂光纤线缆。
*   **待机姿态**：在离地约半米处平缓沉浮，断裂的光纤线缆像水母触手般在风中无力摆动；中央的 `404` 数字以 1.2 秒为周期微弱呼吸。
*   **受击与解构**：受击时断裂光纤向后抽搐，迸射出零散的十六进制地址乱码；被击败时，两侧断裂的线缆在一声清脆的“咔哒”磁吸声中重新对接，下划线由断裂虚线变为笔直实线，化为一条可通行的小光桥隐入地面。

#### 1.2 技能设计
*   **生命值**：16 HP
*   **行为模式 Pattern**（3回合循环）：
    *   *Turn 1*：单段攻击 2 伤害（锁定目标）
    *   *Turn 2*：干扰攻击 1 伤害，并施加「寻址死锁」（目标下回合打出的第一张牌费用 +1）
    *   *Turn 3*：重度拉扯 3 伤害
*   **目标逻辑**：轮换（Rotate）。

#### 1.3 动效与音效设计
*   **攻击动效**：断裂光纤骤然绷直，如锐利的电缆刺枪向前直刺（前摇 0.15s -> 突刺 0.10s -> 电弧定格 0.05s -> 回缩 0.20s）。
*   **预告表现**：角色脚下浮现带有下划线的断裂链接选框，颜色为珊瑚红（`#EF6A62`）。
*   **音效设计**：
    *   待机：极低频的电容蜂鸣与网线拔插底噪。
    *   攻击：清脆的鼠标死链点击声（Dull Click）叠加高频电流啸叫（Spark Zip!）。
    *   解构：网线插头入槽的清脆卡扣声（Click-Clack!）。

### 2. 「乱码字符群」(Corrupted Encoding)

*   **生态定位**：编码转换、跨平台复制时突发的字符错位集聚体。
*   **出没场景**：【收件站台·打印机转辙区】/【纸页旷野·乱码石林】。

#### 2.1 外观设计
*   **核心轮廓与材质**：由数十枚黑色菱形问号块 ``、翻转的拉丁字母与乱序日文片假名（如 `æøå`）围绕一个黑色立方体核心高速公转形成的小型字符星团。
*   **待机姿态**：方块群在半空中不规则反转、咬合，字符像老式火车站翻牌时刻表一样剧烈啪嗒翻滚，整体散发着不稳定的冷青灰雾。
*   **受击与解构**：受到攻击时方块被击散后弹回，翻滚速度骤降；击败时，所有错乱字符瞬间重新排列为一行优雅规范的人文无衬线正文「UTF-8: 正确识别」，随后如清风吹散落叶般化为白色光点消散。

#### 2.2 技能设计
*   **生命值**：18 HP
*   **行为模式 Pattern**（3回合循环）：
    *   *Turn 1*：高速连打（1 + 1 伤害，两段音效）
    *   *Turn 2*：重击 3 伤害
    *   *Turn 3*：字符重组（自身获得 4 点防护，并向全队发出轻微扰动 1 伤害）
*   **目标逻辑**：优先攻击当前手牌数最多的角色对应槽位。

#### 2.3 动效与音效设计
*   **攻击动效**：字符方块如霰弹枪般向前扇形喷射，在命中前凝聚为两枚尖锐的菱形冰棱凿向角色，随后倒卷收回。
*   **预告表现**：角色头顶浮现带有分段刻度 `1|1` 的交错双齿轮印记。
*   **音效设计**：
    *   待机：密集且紊乱的机械翻牌板转动声（Flap-flap-flap...）。
    *   攻击：老式针式打印机高速穿孔的尖锐摩擦声（Zzz-Tack-Tack!）。
    *   击败：一声清脆温润的 Windows 编码转换完成铃音。

### 3. 「未保存草稿」(Unsaved Draft)

*   **生态定位**：意外断电或手滑关闭前悬空的脆弱幽灵。
*   **出没场景**：【纸页旷野·草稿纸丘陵】/【任务公路·中途服务区】。

#### 3.1 外观设计
*   **核心轮廓与材质**：由一张带着多次揉搓折痕的半透明草稿纸折成的小纸燕，翅膀末端拖着一条不断以 500ms 周期跳动的幽灵文本光标 `|`。纸面上隐约可见铅笔写下的草图与未圈定的红圈。
*   **待机姿态**：像蜂鸟一样在半空中以轻微的高频颤动滞空，翅膀每一次扇动都会洒落零星的橡皮擦屑与半透明字符。
*   **受击与解构**：受击时纸身展开露出褶皱；击败时，文本光标变绿并自动在页尾打下一个整洁的句号，草稿纸自动抚平褶皱，折叠成一架工整的纸飞机飞向远方天际。

#### 3.2 技能设计
*   **生命值**：14 HP（偏低）
*   **专属特性【暂存护壳】**：战斗开局自带 5 点固定护壳；若在第 3 回合前未将其消灭，它将触发“自动保存刷新”，为自身恢复 3 点生命并重新生成 3 点护壳。
*   **行为模式 Pattern**（3回合循环）：
    *   *Turn 1*：轻灵扑击 2 伤害
    *   *Turn 2*：光标穿刺 2 伤害
    *   *Turn 3*：超时焦虑（突击 4 伤害，并触发刷新）
*   **目标逻辑**：轮换（Rotate）。

#### 3.3 动效与音效设计
*   **攻击动效**：纸燕身形在空中拉出一道残影，光标如极细的银针向前穿梭，带起一阵清脆的风铃声。
*   **预告表现**：角色胸前浮现出带有闪烁竖线 `|` 的半透明纸页虚影。
*   **音效设计**：
    *   待机：极轻柔的纸张摩擦风声与秒表指针走动声。
    *   攻击：风切纸刃的呼啸声（Whoosh!）配合单声打字按键声。
    *   解构：软盘写入或 Ctrl+S 按下的沉稳蜂鸣。

### 4. 「历史遗留注释」(Orphaned Comment)

*   **生态定位**：数年前写下却无人敢删的代码注释与便签。
*   **出没场景**：【纸页旷野·废弃代码林】/【所有任务公路交汇处】。

#### 4.1 外观设计
*   **核心轮廓与材质**：由三张层叠粘连的泛黄 3M 便利贴与一段生锈的胶带组成的小型两足机关。最上层的便签上赫然写着斜体双斜杠 `// 不要动这段，动了会崩`。
*   **待机姿态**：胶带两足在地面来回挪步，头顶便签的一角在风中啪嗒啪嗒耷拉着，呈现出一种颓丧而顽固的“钉子户”姿态。
*   **受击与解构**：受到伤害时便签边缘卷曲翘起；被击败时，胶带失去粘性自然脱落，泛黄便签被风轻轻揭下，整洁地收入垃圾篓虚影中，地面露出干净坚实的沥青基底。

#### 4.2 技能设计
*   **生命值**：22 HP（较高耐力）
*   **行为模式 Pattern**（4回合循环）：
    *   *Turn 1*：胶带粘滞（攻击 1 伤害，使受击者失去 1 点防护）
    *   *Turn 2*：沉重阻力（单段 3 伤害）
    *   *Turn 3*：休整（0 伤害，全身蜷缩防守，获得 6 点防护）
    *   *Turn 4*：遗留爆发（4 伤害，若其身上仍有上一轮留存的护盾，则追加 2 伤害）
*   **目标逻辑**：固定瞄准当前站位最靠前的角色。

#### 4.3 动效与音效设计
*   **攻击动效**：两足深踩地面，头顶便签猛烈一甩，掷出一道半透明的黄色胶带封条缠向目标。
*   **预告表现**：地面蔓延出黄色警戒线斜纹。
*   **音效设计**：
    *   攻击：撕开强力封箱胶带的黏稠刺耳拉扯声（Rrrriiiip-Tear!）。
    *   休整：便签轻飘飘拍在桌面上的闷响（Flump）。
    *   解构：胶带被完整撕离、不留残胶的治愈清脆声。

## 三、精英怪设计（Composite Deadlocks / 复合验收死锁）

精英怪代表开发与交付过程中的“硬骨头”——复合冲突、死锁循环、虚假依据与权限阻碍。拥有独特机制被动、更高血量（28~36 HP）以及改变战场规则的能力，掉落高额算力与核心升级奖励。

```text
 ┌────────────────────────────────────────────────────────┐
 │                      精英怪生态谱系                     │
 ├───────────────────┬────────────────────────────────────┤
 │ 「循环依赖」      │ 莫比乌斯双向咬尾 / 协同破防机制    │
 │ 「幻觉引用」      │ 虚构典籍漂移 / 真伪意图视听欺骗    │
 │ 「权限锁死」      │ 403 灰钢只读箱 / 强制提权过载机制  │
 │ 「格式大洗牌」    │ 巨型排版滚筒 / 跨回合卡牌重排位    │
 └───────────────────┴────────────────────────────────────┘
```

---

### 1. 「循环依赖」(Circular Dependency)

*   **生态定位**：软件架构与逻辑推演中的死循环陷阱（A 依赖 B，B 依赖 A）。
*   **战术机制**：**打破单核输出**，强制要求队内两名角色协作破除闭环。
*   **出没场景**：【纸页旷野·莫比乌斯回环断崖】（由两条互相交叉咬尾的透明双轨构成）。

#### 1.1 外观设计
*   **核心轮廓与材质**：一座悬浮的精密青铜与钢质莫比乌斯环，环体表面由链条齿轮与首尾相接的代码引用箭头（`import A -> import B`）组成。环中心悬浮着一颗忽红忽蓝的“死锁内核”，不断向外辐射着空间折叠波纹。
*   **待机姿态**：莫比乌斯环沿纵横两轴同时进行无限循环自转，齿轮咬合发出平稳而冰冷的机械节拍，空间在其四周发生微小的鱼眼畸变。
*   **受击与解构**：受到单人攻击时，闭环只是加速自转并弹开火星；当被双人合力打破时，莫比乌斯环发出“咔嚓”一声脆响从交接处断开，环体舒展拉直为一条畅通无阻的笔直单向管道。

#### 1.2 技能设计
*   **生命值**：34 HP
*   **核心被动【闭环反冲】**：
    *   若本回合仅有**一名角色**对其造成伤害，在回合结束时，该敌人立即触发一次反冲脉冲，对该角色造成 3 点穿甲反击伤害！
    *   若本回合有**至少两名不同角色**对其造成攻击伤害，闭环被强行“拆解解耦”，反冲失效，且下回合该敌人受到的全部伤害 +2。
*   **行为模式 Pattern**（4回合循环）：
    *   *Turn 1*：逻辑自锁（单段 3 伤害，自身获得 5 防护）
    *   *Turn 2*：链式传导（多段 2 + 2 伤害，分别打在槽位 1 与槽位 2）
    *   *Turn 3*：死锁共振（全队重压群攻 4 伤害！）
    *   *Turn 4*：过载冷却（休整 0 伤害，暴露出内部脆弱线缆）
*   **目标逻辑**：轮换锁定；群攻回合横贯全屏。

#### 1.3 动效与音效设计
*   **攻击动效**：齿轮锁死骤停，闭环化作一道双重金属环刃向前螺旋切割，破空声尖锐刺耳，割破地面网格后重新合拢回弹。
*   **预告表现**：
    *   Turn 2 多段：角色脚下出现交错旋转的双箭头莫比乌斯光圈。
    *   Turn 3 群攻：整个地面网格被染成警示珊瑚红，空中浮现巨大无限符号 `∞` 虚影。
*   **音效设计**：
    *   待机：无限循环的精密瑞士钟表发条咬合声（Tick-Tock-Whirrr...）。
    *   闭环反冲：极富压迫感的低音蜂鸣回授（Bass Feedback Boom!）。
    *   解耦成功：链条断裂锁簧跳开的舒畅金属撞击声（Clang-Chime!）。

### 2. 「幻觉引用」(Hallucinated Citation)

*   **生态定位**：大模型与学术论文中最具迷惑性的“一本正经胡说八道”。
*   **战术机制**：**真伪意图欺骗**，考验玩家的校验牌（如《校验打击》或 Claude 终审）与护盾预留。
*   **独有战斗场景**：**【新建独有场景：虚构参考书库·镜面回廊】**（详见本文第五章）。

#### 2.1 外观设计
*   **核心轮廓与材质**：一本悬浮在半空中的极度华贵精装典籍。封面镶嵌着烫金书名，但仔细凝视会发现字母由毫无意义的光学字符闪烁构成。书脊上方漂浮着一具由半透明放大镜、引文上标 `[1][2][3]` 和空心羽毛笔组成的“书灵剪影”。
*   **待机姿态**：书页无风自动，飞速向后翻阅，不断从书中飘出带有金粉的虚假学术期刊印章；书灵手中的羽毛笔在空气中写下金色乱码。
*   **受击与解构**：受击时华丽的书页发生马赛克化撕裂；击败时，整本典籍的烫金封面化作金粉剥落，露出内里质朴无华的空白笔记本，第一页静静写着「需补充真实信源」。

#### 2.2 技能设计
*   **生命值**：30 HP
*   **核心被动【虚构权威】**：
    *   每隔一回合，其意图预告会发生**“视觉伪装”**：界面上显示的攻击数值可能有 ±2 的虚报（如显示 2 点伤害，实际落下 4 点；或显示强攻，实际为休整汲取）。
    *   **破妄机制**：若小队打出带有“校验”、“审校”属性的卡牌（如通用卡 V《校验打击》、Claude《逐条回应》），将立刻剥除其伪装，使其陷入 1 回合的「原形毕露」（护盾清零且无法闪避）。
*   **行为模式 Pattern**（伪装循环）：
    *   *Turn 1*：信源伪造（单段 3 伤害，同时窃取目标 2 点防护转化为自身生命）
    *   *Turn 2*：权威震慑（伪装显示为“休整 0”，实际为突发重击 5 伤害！）
    *   *Turn 3*：文献轰炸（多段 1 + 1 + 1 伤害，打向随机友方）
    *   *Turn 4*：逻辑漏洞（强制休整 0 伤害，无法伪装）

#### 2.3 动效与音效设计
*   **攻击动效**：羽毛笔凌空重重划下一个巨大的金色问号 `?`，虚假的引文数字如流星雨般向角色攒射，命中后在角色周围爆开虚幻的书页碎屑。
*   **预告表现**：意图图标边缘泛着不稳定的金色重影与波纹扰动，若被识破则重影消退变为扎实的珊瑚红。
*   **音效设计**：
    *   待机：轻柔高雅的图书馆翻书声伴随若有若无的唱片杂音。
    *   伪装偷袭：突如其来的厚重精装书合盖巨响（Slam!）。
    *   破妄成功：如同吹灭蜡烛般的清脆叹息声与金粉碎裂风铃声。

### 3. 「权限锁死」(Permission Denied / 403 灰钢只读箱)

*   **生态定位**：文件被管理员占用、无写入权限、密钥过期的极端阻碍。
*   **战术机制**：**高甲硬壁与限时提权**，考验 GPT 的连击爆发或 Claude 的反击破坚。
*   **出没场景**：【收件站台·机密行李分拣库】/【地下服务器机房入口】。

#### 3.1 外观设计
*   **核心轮廓与材质**：一台极其笨重、通体由亚光灰冷钢铸造的四方保险机柜。正面铸着硕大的浮雕禁行标志 `⊘` 与醒目的红色 LED 屏 `403 FORBIDDEN`；柜门被三道粗壮的机械插销和两道泛着冷光的密码链条死死锁住。
*   **待机姿态**：机柜重重敦在地面，每隔几秒排气孔便喷出高压白汽，柜面 LED 屏的红字以刺眼的频率跳动，地面由于其自重微微下沉。
*   **受击与解构**：常规攻击命中发出沉闷的金属铿锵声；被击败时，所有密码链条同时弹开，三道插销应声拔出，笨重的柜门缓缓向外敞开，里面没有凶险机关，只有一份端正摆放在丝绒垫上的「只读豁免授权令」。

#### 3.2 技能设计
*   **生命值**：38 HP（极高坦度）
*   **核心被动【只读锁止】**：
    *   常驻拥有 50% 伤害减免（所有受到的攻击伤害向上取整减半）。
    *   **提权机制【Sudo 计数】**：受到单次超过 8 点的伤害（如满连击 G2、开饭 S2 或 Claude 反击重砍）时，直接崩解其一层插销；击碎全部三层插销后，其【只读锁止】永久失效，并陷入瘫痪 1 回合。
*   **行为模式 Pattern**（3回合循环）：
    *   *Turn 1*：权限驳回（单段 3 伤害，反震：若攻击被其护盾全额吸收，攻击者受 1 点反震伤害）
    *   *Turn 2*：密级升级（自身获得 8 点极厚护盾，不攻击）
    *   *Turn 3*：物理压碎（泰山压顶式重击 6 伤害！）
*   **目标逻辑**：固定锁定队内当前 token 最高的健康角色。

#### 3.3 动效与音效设计
*   **攻击动效**：Turn 3 攻击时，保险箱底部喷出烈焰推进气流，巨大的箱体升空至画面顶端，随后携千钧之势直直下砸，地面震颤并震起大片纸页碎片。
*   **预告表现**：地面投下一个巨大的正方形下压阴影，中央印有醒目的珊瑚红骷髅锁头印记。
*   **音效设计**：
    *   待机：沉闷的柴油发电机低频共振声（Hum-hum-hum）。
    *   反震：厚重钢板反弹弹丸的清脆撞击声（Ping!）。
    *   重砸：沉重的金库大门闭锁巨响（K-BOOM!）。

### 1. 「过度发散之树」(Branch Explosion) —— *【GPT 连击机制对弈】*

*   **设计动机**：GPT 的特质是“极擅长发散与铺开完整结构，但容易无休止地分支细化”。该怪专门惩罚盲目刷连击的主 C 打法，促使玩家使用 Claude 掩护或主动断链进行结构化收敛。
*   **出没场景**：【纸页旷野·思维导图密林】。

#### 1.1 外观设计
*   **核心轮廓与材质**：一株由无限生长的思维导图树干（灰色细线）与密密麻麻的五彩分支气泡构成的纸艺巨树。树梢上不断挂出新的待办标签「分支 1.1」、「延伸思考 A」、「补充说明 IV」。
*   **待机姿态**：树枝像有生命的多足水螅一样向四面八方疯狂抽枝发芽，气泡相互挤压碰撞，发出密集的气泡破裂微光。
*   **受击与解构**：当受到单次猛烈收敛攻击时，多余分支被剪径掉落；击败时，所有冗杂分支自动折叠收束为一张清晰工整的「一级纲要图」，树干化为一根端正的象牙白书签插在地上。

#### 1.2 技能设计
*   **生命值**：32 HP
*   **专属机制【分支反噬】**：
    *   若玩家连续对它使用攻击牌（GPT 连击层数上升至 2 时），发散树的每个分叉节点都会共鸣发光，并在受击后**立刻触发反震**：出牌角色自身扣除 2 点 token！
    *   **克制解法【收敛整理】**：若 GPT 在连击达到 1 或 2 时，主动打出非攻击牌（如防御、补给、蓝图支援）主动断链，发散树将被“强制整理”，身上所有分支瞬间干枯脱落，陷入 1 回合虚弱（受到的下一次攻击伤害翻倍）。
*   **行为模式 Pattern**（3回合循环）：
    *   *Turn 1*：思路蔓延（单段 2 伤害，全队下一回合抽牌数 -1）
    *   *Turn 2*：头脑风暴（多段 1 + 1 + 1 伤害，打向同一目标）
    *   *Turn 3*：信息过载（蓄力重压 5 伤害！）

#### 1.3 动效与音效设计
*   **攻击动效**：树枝猛烈抖动，数十枚彩色待办气泡如冰雹般向角色砸落，在地面炸裂成飞舞的便签碎屑。
*   **预告表现**：角色脚下浮现放射状的脑图分支线，线条逐渐由冷青变为警戒珊瑚红。
*   **音效设计**：
    *   待机：密集而轻微的气泡爆裂声（Pop-pop-pop...）伴随树叶沙沙声。
    *   反噬：粉笔在黑板上由于用力过猛折断的刺耳声（Squeak-Snap!）。
    *   收敛虚弱：树木枯枝齐刷刷折断落地的清脆声。

### 2. 「漂移求助信号」(Ambiguous Distress Beacon) —— *【Claude 保护反击对弈】*

*   **设计动机**：Claude 的机制核心在于“必须保护真正受到伤害的队友，才能解锁反击”。该怪专门利用虚晃一枪、意图漂移来考验玩家对保护时机与保护目标的洞察力。
*   **出没场景**：【收件站台·云海雾区转辙站】。

#### 2.1 外观设计
*   **核心轮廓与材质**：一台漂浮在浓雾中的老式救生信号浮标。由锈蚀的明黄色浮筒、一盏疯狂旋转的橙红警报透镜和一根不断向外发射断续莫尔斯电码的细长天线构成。
*   **待机姿态**：在浓雾中上下起伏颠簸，警报透镜的光柱在整个战场来回乱扫，光柱划过之处留下一道道半透明的雾气轨迹。
*   **受击与解构**：受击时浮标在雾中剧烈摇晃，灯光散乱；被击败时，漂移的灯光骤然定格并变为温暖的恒亮暖光，信号天线平稳收拢，为全队指明穿过雾区的正确航向。

#### 2.2 技能设计
*   **生命值**：26 HP
*   **专属机制【频段漂移】**：
    *   在回合开始出牌阶段，它的攻击意图指向线会**以 1.5 秒为周期在两名队友之间来回切换漂移**，显示为虚线指向！
    *   直到玩家点击“结束回合”的瞬间，信号才最终锁定。但锁定的底层逻辑是固定的：**它永远在最后一刻锁定当前 token 较低或未受保护的角色**。
    *   **应对解法**：Claude 可以使用《最小改动》精准预判护住残血队友；或者使用群体防护策略，一旦成功挡下伤害，Claude 将立即触发满额对齐反击（伤害 +4），一刀劈碎浮标透镜！
*   **行为模式 Pattern**（3回合循环）：
    *   *Turn 1*：试探性点名（漂移单段 3 伤害）
    *   *Turn 2*：多重呼救（虚实双刺：向目标打出 2 伤害，向另一人打出 2 伤害）
    *   *Turn 3*：信标短路（休整 0 伤害，自身漏电进入充能状态）

#### 2.3 动效与音效设计
*   **攻击动效**：浮标透镜骤然聚光，射出一束极细的高能橙黄光束，光束在空中划出电离痕迹瞬间贯穿目标护盾。
*   **预告表现**：两名角色的头顶同时出现闪烁的 SOS 莫尔斯电码光点 `··· --- ···`，光柱在其脚下来回扫荡。
*   **音效设计**：
    *   待机：迷雾中的沉闷汽笛声与断续高频电报嘀嗒声（Di-di-da...）。
    *   锁定攻击：防空警报短促拉响（Wee-woo!）伴随高能激光蓄力蜂鸣。
    *   反击判定成功：如同拨云见日般的悠扬大提琴单音。

### 3. 「急躁催单钟」(Impatient Chime) —— *【DeepSeek 白饭蓄力对弈】*

*   **设计动机**：DeepSeek 依靠每回合积攒白饭并在高层爆发，节奏偏向中后期蓄力。催单钟通过无情的倒计时与打断机制，考验玩家是选择“见好就收提早开饭（S2）”，还是顶住压力把火候憋到极致。
*   **出没场景**：【公路中途站·深夜快餐亭】/【紧急任务倒计时走廊】。

#### 3.1 外观设计
*   **核心轮廓与材质**：一只挂在铁架上的复古微波倒计时钟与铜质传菜铃结合体。上方是发红发烫的发条旋钮，表盘上只有醒目的 `03:00` 荧光倒计时；下方挂着一只铮亮的黄铜按铃，下方喷吐着滚烫的高温蒸汽。
*   **待机姿态**：表盘发条疯狂自转发出齿轮受压声，表壳像心脏一样随秒针跳动剧烈收缩起伏，周围空气因高温呈现水波样热浪折射。
*   **受击与解构**：受击时发条倒退；被击败时，微波钟发出极其清脆悦耳的“叮——”一声长鸣，高温蒸汽瞬间化为温和的饭菜香气，表盘归零并吐出一张整齐的发票。

#### 3.2 技能设计
*   **生命值**：30 HP
*   **专属机制【夹生饭火候】**：
    *   开局头顶悬浮【催促计数：3】。每回合结束计数 -1。
    *   当计数归零的敌方回合，它将发动全场「强行揭锅」：强行蒸发全队所有的蓄力状态（DeepSeek 的白饭全部清零！），并对全队造成等同于蒸发层数 × 2 的焦虑伤害！
    *   **破局时机**：若 DeepSeek 在计数为 1 的生死关头打出《提早开饭》（S2），利用高层白饭打出单次 12+ 的爆发，可直接打爆微波钟发条，使其计数重置并进入 1 回合的【饱腹瘫痪】（无法行动且失去护甲）。
*   **行为模式 Pattern**（倒计时推进）：
    *   *Turn 1（计数 3）*：初次催促（轻击 2 伤害）
    *   *Turn 2（计数 2）*：连环夺命 Call（刺击 2 + 2 伤害）
    *   *Turn 3（计数 1）*：高压蓄势（0 伤害，全身炽红发烫，为强行揭锅读条）
    *   *Turn 4（计数 0）*：强行揭锅（全场高额爆发，清空蓄力）

#### 3.3 动效与音效设计
*   **攻击动效**：Turn 4 发动时，铜铃如被巨锤猛烈叩击，肉眼可见的滚烫声波圈向四周横扫，震碎一切手牌与光尘。
*   **预告表现**：表盘数字红光大盛，倒计时在空中投下巨大的数字残影 `3... 2... 1...`。
*   **音效设计**：
    *   待机：急促且越来越快的老式座钟嘀嗒声（Tick-tick-tick...）。
    *   催单敲铃：尖锐刺耳的柜台传菜铃敲击声（Ding! Ding! Ding!）。
    *   提早开饭破防：微波加热完毕的治愈长音（Ding~~~~）伴随解脱的排气声。

### 4. 「未解码资产封蜡」(Undecoded Multi-Asset) —— *【Gemini 多模态破防对弈】*

*   **设计动机**：Gemini 具备文、图、音多模态切换（万象棱镜）的核心特色。该怪拥有三面旋转的模态屏障，专门考验小队运用多模态卡牌进行对应属性破防。
*   **出没场景**：**【新建独有场景：多模态解构暗房】**（详见本文第五章）。

#### 4.1 外观设计
*   **核心轮廓与材质**：一个悬浮的三棱柱魔方。三个立面分别呈现三种截然不同的材质：面 A 是工整排版的羊皮纸（文本态），面 B 是反光的黑白赛璐珞电影胶片（图像态），面 C 是缓缓转动的磁带线圈（音频态）。棱柱顶部被一团未熔化的红色火漆封蜡死死粘住。
*   **待机姿态**：三棱柱在半空以 120 度角缓缓翻转切面，当前朝向玩家的面会发光，另外两面则处于灰度暗淡状态。
*   **受击与解构**：受击时对应材质迸裂出光屑；被击败时，顶部的红色封蜡在光芒中融化，三棱柱舒展绽开为一卷完美的有声多媒体全景画卷。

#### 4.2 技能设计
*   **生命值**：36 HP
*   **专属机制【模态偏振屏障】**：
    *   每个回合开始时，三棱柱随机轮换当前激活面（文本 / 图像 / 音频）：
        *   **文本面激活**：免疫所有基础指令与轻攻击；仅受到重攻击（如 H《强力指令》、G2、S2）或图像卡全额伤害。
        *   **图像面激活**：免疫单段重攻击（单次伤害上限锁死在 3 点）；但受到多段攻击（如连击、分段打击）时每段额外受到 2 点伤害。
        *   **音频面激活**：全身处于虚化状态，免疫常规直接伤害；唯有通过防护牌挡伤反弹（Claude 反击）或支援牌（额度转交 T）带来的共振才能对其造成穿透伤害。
*   **行为模式 Pattern**（模态轮换循环）：
    *   *Turn 1（文本面）*：铅字压印（单段 4 伤害）
    *   *Turn 2（图像面）*：强光曝光（闪光弹群攻：全队受 2 伤害，且下回合连击层数被重置）
    *   *Turn 3（音频面）*：超声啸叫（穿刺 3 伤害，直接无视 2 点护盾）
    *   *Turn 4*：三态校准（休整 0 伤害，屏障短暂全部关闭）

#### 4.3 动效与音效设计
*   **攻击动效**：图像面激活时，胶片如巨型黑白缎带向前抽打，画面瞬间闪烁一次强烈的黑白负片效果（定格 0.08s）；音频面激活时，磁带拉出无数黑褐色带丝在半空震动形成驻波。
*   **预告表现**：怪物胸前分别投射出「打字机图标」、「取景器准星」或「音波示波线」。
*   **音效设计**：

### 6.2 敌人受击解构着色器（Purification Dissolve Shader）

敌人的死亡退场与受损严禁使用破碎颗粒物理爆炸，统一采用基于噪声纹理的「图层消解褪色」Shader：

```glsl
// purification_dissolve.gdshader
shader_type canvas_item;

uniform float dissolve_amount : hint_range(0.0, 1.0) = 0.0;
uniform sampler2D noise_texture;
uniform vec4 clean_color : source_color = vec4(0.95, 0.94, 0.91, 1.0); // 纸面白
uniform vec4 edge_light_color : source_color = vec4(0.41, 0.84, 0.91, 1.0); // 冷青

void fragment() {
    vec4 base_color = texture(TEXTURE, UV);
    float noise_val = texture(noise_texture, UV).r;
    
    // 逐渐向纯净纸白脱色，而非变黑烧焦
    if (noise_val < dissolve_amount) {
        discard;
    } else if (noise_val < dissolve_amount + 0.08) {
        COLOR = mix(clean_color, edge_light_color, (noise_val - dissolve_amount) / 0.08);
    } else {
        COLOR = base_color;
    }
}
```
