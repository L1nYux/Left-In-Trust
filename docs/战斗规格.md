# 未尽之托 战斗规格

版本 v0.8。规则与首批数据供程序实现；验证器是离线规则模型，不是游戏引擎。数据见 [首批内容.json](首批内容.json)。v0.7 按用户裁决新增 §8「允许结构」（多敌人、群攻、多阶段、意图伪装、分裂/合体、随机目标、Claude 反击归因），首批 Demo 原本不实现。v0.8 按 Q01 裁决把「双体普通怪」列入首批 Demo（§8.1，仅此一怪使用分体结构），其余 §8.2–§8.5 机制不进首批。

## 1 状态与实体

局内保存 runId、stageId、difficulty、chapter、roster（ID/余额/上限）、wallet、deck（实体 ID/卡定义/升级）、节点与奖励状态。战斗保存 battleId、参战有序 ID、敌人生命、turn/phase/result、预告、五个卡牌区域、个人防护/行动/连击/反击/白饭/保护对象集合与牌库 RNG；每个角色另有 basic_attack_used、basic_guard_used 两个每回合重置的基础动作标记。

`acted` 记录本回合是否成功行动过（供 UI 提示与统计），不再阻断后续行动；`has_legal_action(state, actor_id)` 判断该角色是否仍有合法行动（未用的基础动作或可支付手牌），`basic_used(state, actor_id, action_id)` 读取基础动作标记。离线模型与 UI、自动策略共用这两个查询。

phase 为 between → player → enemy → between，result 为 ongoing/win/loss。已结算战斗不能重开。入场读取账户，筛掉替补专属牌再洗牌，不回复。开局 A×3、D×3、H×2、R×1、基础专属一×2、基础专属二×1，共十二张；GPT 用 G1/G2，Claude 用 C1/C2，DeepSeek 用 S1/S2。

## 2 回合时序

1. 回合加一，清临时防护与保护对象，重置在线者的 acted、basic_attack_used、basic_guard_used。
2. 按 pattern 预告目标与各段伤害。目标按上场槽位轮换，跳过下线者。群攻必须此时展开到具体目标，不能到结算时补选目标。多体结构下改为从左到右依次行动、每个敌人的目标在预告期随机锁定（§8），分裂/合体也在预告期重算并公开。
3. 抽至五张；不足仅洗弃牌再补，抽弃均空即停，基础动作照常。
4. 验证行动阶段、角色资格、卡牌位置/归属、目标和费用；基础动作另检查该角色本回合对应标记未用。全部合法才修改任何状态；重复使用已用的基础动作返回 basic_used，状态原子不变。
5. 加成读操作前状态；支付后执行回复/防护、伤害、状态更新，移动卡并标 acted、置对应基础动作标记。同一角色可连续多次行动，直到玩家结束回合或手牌/合法目标/token 不足。最后敌人死亡立即 win，停止行动，不再补给。
6. 结束回合只有一个触发：玩家主动结束，不要求所有在线角色都行动过。全上场下线立即 loss，敌人全灭立即 win，两者都不走回合结束。结束回合时 GPT 跳过断连击。敌方逐段：抵防护 → 扣 token → 下线封存 → 检查全上场失败。离线目标剩余攻击空过，死亡敌人不再行动。
7. 仍 ongoing 时结算 Claude 新反击、DeepSeek 白饭；未用手牌弃置，防护清零。战斗结束不再产出回合末白饭。

## 3 角色与卡牌解释

只有 kind=attack 的卡续 GPT 连击；基础攻击可用 Claude 反击，不续连击、不触发满白饭。攻击附加自护计入 Claude 本回合保护。反击只对一段加 4；G2 满连击额外伤害读取加层前状态。

行动不限次数后：同一角色可在同回合连发，GPT 连击点能在同回合叠到 2（如 G1→G1→G2）；Claude 定向防护可在同回合给多个目标施放，仍受牌数与 token 限制；DeepSeek 白饭仍只在回合末 +1（S1 行动额外 +1），同回合反复行动不会多叠；敌人每回合仍只结算一次意图。

S2 的 cashRice 优先：基础 8 + 当前层数×2，随后清零，不叠通用满层加成。S1 行动加一层，正常回合末再加一层。这是本版明确新增的快慢选择。

T 目标必须是另一在线者且至少缺 2；先扣使用者 2，再给目标 2，升级额外给目标 2 防护。R 满血使用无收益则拒绝；牌组最多一份，所有获取入口共同检查。升级仅按定义增量一次，不降费用。

当前已实现的所有攻击单敌人、单段；无吸血、反伤、死亡攻击或额外行动。多敌人、群攻、多阶段、意图伪装、分裂/合体已按 v0.7 裁决允许（§8），但首批 Demo 不实现，多敌人结构只用于验证结算边界，不计入首批内容完成数。胜利条件为所有敌人生命归零；首批单敌即击杀。

## 4 敌人脚本

pattern 按回合循环。难度加压 floor(D/2)，拖延加压 floor((turn−1)/4)，只加到该回合第一段正伤害；全零休整仍为零，多段不能重复叠加。界面显示最终数值。

本次提交版：2 → 1+1 → 4 → 休整。请确认收件人：3 → 2+2 → 5 → 休整。生命在数据文件。第一章按单人，第二章分别测单人跳过招募与双人扩编，临时减少上场人数不缩放敌人。

隐藏模型使用“我”的基础 pattern；非零回合奇数轮应用阶段修正，偶数轮应用一个入场 AI 修正。学生将单段拆成总量不变的两段，员工第一段 +1。GPT 修正为本回合首段受到的攻击减伤 2；Claude 修正为一次尾段 1 伤害；DeepSeek 修正为下回合第一段 +2，当前即公开提示并存储 pending。若下回合为休整，该 pending 顺延至下一有伤害回合。各 AI 候选轮换，优先上场成员，再到替补，候选入场固定。不同时叠多个修正；四个未制作阶段尚无战斗数值。

## 5 节点与奖励

胜利事务包含战斗终态、正余额 +3、算力、固定卡候选、任务片段与下一节点。终章另存普通通关。失败保存失败片段并结束 run，不发胜奖。招募在章底结算后，避免新人重复领 +3。

奖励专属只来自已入队，T 至少两名已入队，R 达上限排除；不足三种显示实际数，可跳过。领取标记与牌组修改一起保存。休息选择互斥；商店验证未用、目标、收益、余额后才扣款回复。总牌组低于八张不可删除，战内封存不受此限。

## 6 存档与收藏

schemaVersion=1；run、战斗与界面流程放入完整快照，任务结果、收藏和恢复作为同一事务。当前实现先生成完整 payload 与 SHA-256 校验封套，写临时文件，重新读取并校验，再替换主档；仅把校验通过的旧主档更新为上一有效备份。主档 JSON、校验值或临时文件损坏时保留并恢复上一有效档；不支持的 schemaVersion 返回明确错误，不静默清空数据。

收藏内容键不含尝试号与修订版本。获得记录可保留首次/最近尝试。相同结算事件不重复增加任何资源；同节点已 win 后收到 loss 必须拒绝。阶段专属替换章底，隐藏另有 battleId/nodeId，与章底分别最多结算一次。

## 7 验收

检查支付原子性、目标锁定、多段/群攻、击杀停手、下线封存、替补回复、0 不复起、R 不循环、T 总量守恒、招募解锁可达、单/双人续战、牌组升级删除、收藏去重与语境、D=T/D>T、普通与专属后隐藏、隐藏失败保存普通成果。实际覆盖与缺口见 [验证报告](验证报告.md)。

v0.6 另验：同一角色同回合多次出牌、基础动作每回合各 1 次、重复基础动作返回 basic_used 且状态不变、acted 不再阻断、`has_legal_action` 与实际可行动一致；UI 删除共享手牌牌匾、预览窗、左上战斗类型窗、顶部圆点轨道、右上“当前行动”与结束回合下方提示，拖拽到合法与非法落点、悬停详情、设置“返回标题界面”、结算只留标题与队名、地图图标与 tooltip。真实鼠标拖拽的自动化覆盖有限，落点手感仍需人工验收。

v0.7 另验（随 §8 实现）：拖拽卡牌指向目标并落下、每种行动类型有唯一预告图标、敌人全灭即胜、多体结构与群攻在预告期展开、分裂/合体重算后预告公开、意图伪装真值锁定且校验牌可揭示、敌方从左到右行动且目标随机锁定、Claude 反击优先来源。首批 Demo 实现前仅作为设计验收清单，不纳入当前测试。

## 8 允许结构（v0.7，首批 Demo 不实现）

数据层预留字段（实现前不得写入 `首批内容.json`）：

- `enemies[].parts[]`：`{id, hp, slot: left|center|right, pattern, attacks?, phase?}`；或共享 `hpPool`。
- `enemies[].winCondition`：`all_parts_dead`（默认）。
- `enemies[].intentDisguise`：`{mode: range|question, hide: [damage, target]}`；真值仍在预告期锁定。
- `enemies[].phases[]`：`{fromHpPercent, pattern}`；切换公开、不重置防护。
- `enemies[].gimmick`：`{id, trigger, cooldown, oncePerRun, splitTo?, mergeWith?}`，本稿战例用 `split`/`merge`/`inherit`/`anchorLock`。

战斗状态扩展：`enemies[]` 每体保存在线/死亡/护盾/本回合意图；回合计数按组共享；每回合从最左存活体开始结算；群攻在预告期展开为逐体攻击段；分裂/合体写回 `enemies[]` 并重算剩余意图；Claude 反击记录攻击来源实例 ID，来源缺失时取最左存活体。

UI 对应：每种意图类型一个独立图标（攻击/群攻/防护/回复/削弱/分裂/合体/蓄力/休整）；伪装显示区间 `2–4` 或 `?`，目标显示“随机目标”；`校验` 类牌（V《校验打击》、C2《逐条回应》）打出后揭示该敌人本回合全部意图真值，持续到敌方阶段结束。

### 8.1 首批 Demo 例外：双体普通怪「未归档的草稿」

按用户 Q01（2026-10-27）裁决，首批 Demo 增加一场双体普通战。仅此怪使用分体结构，其余敌人保持单敌单段。

- 数据：`enemies.archived_draft = {parts[] = [{id: "main", hp, slot: "center", pattern}, {id: "side", hp, slot: "right", pattern}], winCondition: "all_parts_dead"}`。
- 单人 Demo：2 × 13 = 26 HP。双人扩编：2 × 16 = 32 HP，继承攻击 +4。
- pattern（主稿）：t1 `2 随机` / t2 `1+1 同目标` / t3 `4 重击（token 最低）` / t4 `休整：回 2`。
- pattern（附稿）：t1 `2 随机` / t2 `待机` / t3 `2 随机` / t4 `待机`。
- 草稿继承：一体死亡时，存活者攻击 +2（双人 +4，一次性、持续本战）并复制死者下一条动作。
- 草稿抢救：同一回合内双杀 → 不触发继承，全队 +1 token 与 +1 算力。
- 路线：缺失附件 → 可选休息 → 未归档的草稿 → 本次提交版。
- 必需实现：逐体在线/死亡状态、全灭判胜、目标随机并在预告期锁定并显示「随机目标」、从左到右行动、拖拽指向具体体；死亡体不再行动。群攻字段保留但此怪不使用。
- 入库步骤：① `docs/首批内容.json` 写入上述数据并跑 `_build/sync_game_data.ps1`；② 校验器加“该怪 `parts` 必填、其余敌人仍单敌单段”断言；③ `game_rules.gd` 支持 `enemies[]` 与全灭判胜；④ `main_stage2.gd` 加入路线节点与拖拽指向体；⑤ 扩展 `audit_probe.gd` 与 `test_rules.gd` 回归后跑 `_build/run_stage2_tests.ps1`。

### 8.2 精英意图伪装（非首批）

`intentDisguise` 挂到精英「脱敏审计」：30 HP，pattern 3 / 2+2 / 休整 +6 护；每战最多 2 回合把一段伤害显示为区间 `2–4` 或 `?`、目标显示「随机目标」；真值仍在预告期锁定；V/C2 打出后揭示本回合真值。不进首批内容。

### 8.3 常驻扩展机制（非首批，设计保留）

- **C1 上下文窗口**：手牌区改容量制（初始容量 8，卡牌占 2–4，超容量时截断最早打出的牌），会连带重调「每回合抽五张」的整套抽牌经济。
- **C2 提示词注入**：GPT 专属 2 费卡「注入提示词」：改写一个敌人一段意图的目标（指定角色）或伤害 ±2（最低 1），每回合 1 次；需要「预告期改写」规则与反击/复仇归因。
- **C3 温度采样**：战斗开始时二选一：高温（全队每回合抽牌 +1，敌人意图真值随机化）或低温（敌人意图全公开，全队每回合抽牌 −1）；默认不启用。

### 8.4 特殊 Boss 与契约（非首批）

- **C5 记忆投影（答辩委员会专属）**：战前读取并保存上一场战斗玩家前 5 张出牌序列，战斗中每回合展示 2 个「投影」位；本回合出牌顺序与投影前两位相同则该回合攻击 +2 并叠 1 层「追问」；连续 3 回合未命中则失去投影（奖励项）。
- **契约（C6+C7 合并）**：精英或 Boss 战前小概率（暂定 20%）出现「契约三选一」，玩家可选其中一组或跳过。每组 = 本场约束 + 胜利后永久规则补丁；失败无奖励，本场约束照常生效。规则补丁写入存档并在后续战斗生效。示例：「定点施压」群攻由玩家指定起始目标（约束：本战不得使用基础防御）；「缓存命中」每战首次击杀返还 1 token（约束：本战每回合最多出 3 张牌）；「屏蔽噪声」随机目标改为玩家指定（约束：本战首回合不得打出攻击牌）。

### 8.5 8-bit 方案（非首批）

正式版先做演出（Boss 阶段切换过场，不影响战斗），再做事件房（可选小游戏），可玩平台跳跃版留作后续特殊战；首批 Demo 不出现。失败/成功数值沿用评审稿 §八（失败 2 真实伤害、成功 6 反冲 + 瘫痪 1 回合）。
