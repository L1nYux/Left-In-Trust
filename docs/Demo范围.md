## 基础 Demo 验收

- [ ] 三名角色各能单人开局；付费保留 1、独立防护与基础动作清晰。
- [ ] 在真实手牌和公开敌人意图下，有至少两种可解释的策略取舍。
- [ ] 一人下线继续、全上场下线失败；封存、消耗与结算正确。
- [ ] 两章每条路线都有休息机会；首次玩家无需碰随机商店才能恢复。
- [ ] 招募包含未解锁者，实际候选不足三人时正常展示；旧余额不重置。
- [ ] 单人/双人任务对白均成立，无未招募角色插话；失败片段匹配节点。
- [ ] 同章重开能抽到不同任务，存档重载不重抽；学生/员工有实质不同现实片段。
- [ ] 成功与失败收藏去重，主要结局纯胜利可达；语境不混拼。
- [ ] 奖励、恢复、片段、通关记录同时保存；重载及重复操作无额外收益。
- [ ] 断写、坏档、旧版本档恢复有明确结果，保留上一有效档。
- [ ] 三至五名陌生玩家独立完成首战，记录困惑、死亡原因、时长和再玩意愿。
- [ ] 低分辨率与非颜色提示可读；剧情可跳过回看，关键验收条件始终可查。
- [ ] 干净环境启动与完整一局通过；素材使用范围与打包说明有记录。

## 裁剪顺序

先减少表情、动画与重复对白，再减少随机事件和奖励种类；保留两短章、两阶段实质区别、每章多任务候选、个人 token、一次行动、必达休息与收藏闭环。挑战扩展独立排期，不混进基础 Demo 完成声明。

十六角色与六阶段是长期内容方向；GPT 进化、DeepSeek 双形态/不限插件、Kimi 记录不取消，只暂不进入基础版。完整章节长度等待基础战斗与时长证据后决定，不延续旧“六章十一层必须同时实现”的验收。
