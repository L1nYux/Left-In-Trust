Use case: stylized-concept
Asset type: game visual direction key art / three-zone mood board for a PC turn-based roguelike card game

Materials/textures: frosted glass, matte painted metal, paper fibers turning into holographic planes, volumetric dust, pixel fragments, point-cloud particles.
Constraints: no readable text, no logos, no trademarks, no watermark, no copied interface, no resemblance to existing game characters, avoid cyberpunk city clichés, avoid excessive neon, avoid photorealism, avoid dense HUD overlays, keep gestures simple and silhouettes clear.
