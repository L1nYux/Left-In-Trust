# 《未尽之托》地图事件图标 v1 设计说明

日期：2026-10-26。

> 2026-10-27 更新：本文件保留第一轮彩色图标设计过程。当前地图改用 [地图路线与事件符号 v2](地图路线与事件符号_v2.md) 的小型单色 SVG，v1 PNG 不再由地图加载。

## 1. 定位

地图图标借鉴卡牌爬塔游戏“依靠轮廓快速辨认节点”的信息层级，不沿用《杀戮尖塔》的具体符号。视觉母题统一为：**路线手帐、任务票据、文档缺口、验收套框和离散记忆**。

图标必须先靠轮廓区分，再用颜色确认语义。纸张、表格网线、票据缺口、文件夹、座位和验收门来自本作任务世界；不使用剑、骷髅、篝火、宝箱、金币等通用奇幻速记。

## 3. 共通造型规则

- 友好或服务节点使用圆角、连续弧线、开放或闭合回路。
- 战斗与验收节点使用尖角、截断线、审核括号和盖章式套框。
- 不确定信息使用明确缺口、虚线或负空间，不使用模糊滤镜。
- 每个图标只保留一个主轮廓和最多三组内部线；低分辨率下先保外形，再保纸纹。
- 墨蓝黑 `#0A101B` 与纸面白 `#F2EFE7` 是结构色；语义色不承担唯一识别职责。
- 单图标发光或高饱和强调面积不超过约 15%。

## 4. 地图使用规格

- 建议源文件尺寸：`256 × 256 px` 透明 PNG；常规显示 `64 × 64 px`，紧凑显示不低于 `48 × 48 px`。
- 安全区：主体占画布约 76%—82%，四周保留一致留白，避免悬停放大时切边。
- 图标与节点底座分离：图标表达“类型”，节点底座表达“可用、悬停、已完成、锁定”。
- 可用：保留语义色，外环低亮；悬停：外环增亮并放大至约 104%；已完成：降低饱和度并叠加一枚落下的确认签片；锁定：改为失活灰并在连接处显示缺口，不只降低透明度。
- 连接路线不要穿过图标主体；Boss 路线可以在图标下方收束，强化终点感。
