## 一 概述与设计总则

在《未尽之托》的世界观中，战斗绝非抽离于剧情之外的纯数值对抗，亦非霓虹都市或满屏代码的刻板赛博空间，而是**“明线任务世界在验收压力下的结构性变形”**。
敌人不是妖魔怪物，而是现实委托中具象化的问题、漏洞、指标与时限；战场则承载着**“温暖任务公路片＋离散记忆剧场＋任务验收战场”**的三层共存结构。

### 1.1 三层世界的动态嵌套法则

```text
┌─────────────────────────────────────────────────────────────┐
│ 【明线旅途】(占比 60%)：任务几何地貌、道路、车厢、温暖柔和软科幻   │
│   ↓ （进入验收态：压力上升，几何体折叠、拉伸、锁死、出现警示） │
│ 【战斗验收】(占比 25%)：对手驱动的地形动作、意图预告、清晰中性补光│
│   ↓ （深层背景留白：0/1 粒子散点拼凑、现实生活物件的暗线锚点） │
│ 【暗线剧场】(占比 15%)：墨蓝黑底、无声打字光标、冷便当、未回消息 │
└─────────────────────────────────────────────────────────────┘
```

1. **现实材料科技化**：办公与生活物料被系统重新解释——纸张为地貌，表格网格为道路，批注为路标，附件为车厢，红笔为刀刃。
2. **敌人机制可视化**：所有敌人的攻击意图同时具备“颜色、形状、轨迹、声律”四维线索；受击反馈表现为“删减冗余、归正排版、填补空缺”，而非血肉横飞或机械爆炸。
3. **战斗结果生活化**：战斗的胜负终结于“一份交付物的归档”，胜后回归安静平和的生活质感，失败保留具体缺口与重试线索，严禁将师长、上级或“我”怪物化。

### 1.2 战斗四段力学与伴随微表情在场景中的联动

战斗中角色的所有技能释放均严格执行四段力学节拍：
`起手前摇 (Wind-up: 0.12~0.30s) -> 爆发发力 (Strike/Cast: 0.10~0.25s) -> 命中定格 (Freeze & Impact: 0.04~0.08s) -> 缓冲回位 (Settle: 0.20~0.35s)`。
在无出牌长考间歇，角色自动进入基于 `dsh-pet` 理念的 Level 1~3 闲置微表情（如理风衣袖口、抚摸书脊、抱碗打瞌睡、玩数据魔方），使战场始终充满旅伴的生命温度。

## 二 场景一：【纸页旷野·单页城关】
**—— Chapter 1 任务交付验收战**

### 2.1 任务背景与概念定位
*   **任务归属**：第一章《把本周做成一页》/《最后一页》（大学生 / 公司员工）
*   **战斗节点**：第一章章末交付 Boss 战（事件 ID：`ch1.student.boss` / `ch1.employee.boss`）
*   **Boss 实体**：**「本次提交版」**（生命 30 HP / 攻击模式：`2 → 1+1 → 4 → 休整 0`）
*   **核心意象**：数据折线梯田、表格经纬道路、折叠展开的素白城关、朱红验收公章。

### 2.2 三层空间精细化描述

#### 1. 明线地貌（纸页旷野）
*   **地面与材质**：脚下的路面由层层叠叠的纸面白（`#F2EFE7`）特种纸张铺展而成，纸缘带着微温的油墨香气。车轮碾过之处，表格外框网线如经纬线般向远方延展。
*   **地貌起伏**：两侧是一望无际的“数据梯田”，起伏的丘陵实为被系统放大的周报柱状图与折线走势。半空中漂浮着几枚被山风卷起一角的淡黄手写便签，铅笔划痕清晰可见：“就一页，别超”。
*   **色调与光影**：环境主光为清透的清晨日光（暖琥珀调 `#F2B85B`），阴影部分泛着柔和的蓝灰纸面反射光，绝无刺眼的赛博霓虹。

#### 2. 验收态变形（城关隆起）
*   **空间折叠**：当队伍抵达终点线时，平整的路面突然沿折痕向上立体翻折，犹如巨型立体书机关开启，瞬间拔地而起一座薄如蝉翼却遮天蔽日的“单页城关”！
*   **警示几何**：天空横贯起三道珊瑚红（`#EF6A62`）的巨型裁切虚线，伴随清脆而沉重的订书机咬合声，四周空气凝固为半透明的磨砂玻璃围栏。

#### 3. 暗线记忆投影（黑底微光）
*   **远景黑场**：城关背后极远方的天幕沉入墨蓝黑（`#0A101B`）。
*   **生活锚点**：稀疏的青白光点在黑场中投射出一张逼仄的书桌剪影：一盏简陋台灯下，搁着一盒未揭开且凉透的便当；桌角的手机屏幕悄然亮起，微信聊天框停留在旧友发来的「这周六？」，输入框空无一字，光标微微闪烁。

### 2.3 Boss 实体表现与战斗签名

```text
       ┌────────────────────────┐
       │     [ 验 收 公 章 ]     │ ── 悬浮中心，自转蓄势
       │   ┌────────────────┐   │
       │   │  数 值 一 致   │   │ ── 镂刻验收则一
       │   │  待 补 项 分 明 │   │ ── 镂刻验收则二
       │   │  严 守 单 页   │   │ ── 镂刻验收则三
       │   └────────────────┘   │
       │     多层白纸折叠城门     │ ── 承受伤害时逐层剥离
       └────────────────────────┘
```

*   **轮廓与外形**：Boss「本次提交版」是由无数折叠纸层与硬质封皮拼合而成的巨型活字机关。其正面镂刻着“数值一致、待补项分明、严守单页”三道凹槽；中央悬浮着一枚朱红色的机械验收公章。
*   **四拍循环声画节拍**：
    *   *第 1 回合（单段 2 伤害）*：公章在地面投影出红色实线线框，打字机单次回车声（Clack!）震响，公章轻砸，盖下一枚“排版未齐”戳记。
    *   *第 2 回合（多段 1+1 伤害）*：城门左右裂开，滑出两柄高速旋转的锋利纸页裁刀，发出两声清脆撕纸声，自两侧交叉掠过。
    *   *第 3 回合（蓄力重压 4 伤害）*：天际三道裁切线剧烈发红，上方浮现倒计时进度条，公章携千钧风压呼啸下砸！
    *   *第 4 回合（休整 0 伤害）*：机关由于过载完全舒展摊平，公章回弹悬停，城关喷射出薄荷绿（`#75C9A7`）的冷却白汽，露出内部核心。
*   **受损质感**：**削减冗余而不是打碎肢体**。满血时 Boss 臃肿、充斥着飞舞的草稿碎片；每受一次重创，其表面便脱落一层杂乱附页；生命低于 10 时，原本杂乱的机关只剩下最纯净、平整、笔挺的一页白纸。

### 2.4 典型小队作战与动作交互（GPT + Claude）
*   **GPT（Astra 连攻主 C）**：
    *   *动作四段*：身姿挺拔，小蓝云在半空点亮三级淡青踏板（前摇 0.18s）；足尖踏碎光阶跃出，右手推出锋利的紫白光轨切削冗余条目（发力 0.24s）；命中瞬间画面轻微顿帧（定格 0.06s）；后滑步平稳回撤，整肃风衣下摆（回位 0.25s）。
    *   *闲置微动*：长考时长时，GPT 轻轻抬起左手抚平袖口，右手在胸前投影出 3×3 数据魔方快速复原。
*   **Claude（审校反击与保护）**：
    *   *动作四段*：在第 3 回合重压来临前翻开黑金典籍，空中张开琥珀色张开括号盾牌 `[ ]` 将 GPT 笼罩（挡伤）；判定成功的刹那，头顶书签徽章翻面，挥出一道金色裁决光刃，在 Boss 正面划出清脆的完成勾号 `✓`。
    *   *闲置微动*：食指抚摸书脊，低头对典籍封面轻轻吹出一口光尘。

### 2.5 胜负与收束演出
*   **胜利**：公章最后一次缓缓落下，没有冲击波，而是温柔地盖上一枚翠绿色的“准予通过”戳记。城关如折纸般顺从舒展，平铺为一条宽阔坦荡的白色大道。
*   **现实片段沉淀**：黑场剧场里，光标终于按下了电脑保存键。桌角那张单页纸整整齐齐地收进文件夹，手机屏幕上的消息亮起，主角终于揭开了那盒虽然凉了、但依然可口的便当。

## 三 场景二：【收件站台·云海轨道】
**—— Chapter 2 任务交付验收战**

### 3.1 任务背景与概念定位
*   **任务归属**：第二章《请留一个座位》/《把那一天找回来》（邀请函 / 老相册）
*   **战斗节点**：第二章章末交付 Boss 战（事件 ID：`ch2.student.boss` / `ch2.employee.boss`）
*   **Boss 实体**：**「请确认收件人」**（生命 42 HP / 攻击模式：`3 → 2+2 → 5 → 休整 0`）
*   **核心意象**：暮色长桌站台、发光的时间轴铁轨、未点亮的空悬席位、摇摆的日期指示牌。

### 3.2 三层空间精细化描述

#### 1. 明线地貌（收件站台）
*   **月台质感**：建在浩瀚云海边缘的候车站。月台地面由温润的胡桃木长桌与磨砂亚克力拼合而成，整齐陈列着复古长椅与立式信箱。
*   **轨道与流光**：列车轨道并非铁轨，而是**由一条条发光的“收件人连线”与滚动着泛黄照片胶片的“时间轴”**交织而成。
*   **环境天色**：宁静从容的黄昏暮色，落日余晖将云海边缘染成暖琥珀与焦糖紫。

#### 2. 验收态变形（站务塔降临）
*   **机关拔地**：战斗警报响起，站台尽头的发车信号机与多排信箱被机械支柱顶起，组合成一座垂直耸立的“自动化站务分拣巨塔”。
*   **轨道分叉冲突**：塔前铁轨突然断裂并分叉为两条互相错位的虚线，两块标着冲突时间的指示牌（如 `周六 14:00` 与 `周日 18:00`）在强风中剧烈对撞发光。

#### 3. 暗线记忆投影（黑底微光）
*   **暗线画幅**：墨蓝黑的背景中，浮现出一面映照着车窗外飞速倒退路灯的玻璃投影。
*   **生活锚点**：一只疲惫的手握着手机，通讯录长久停留在某个熟悉的名字上。手指悬停在呼叫按钮上空几毫米处，指节微颤，终究未曾按下。

### 3.3 Boss 实体表现与战斗签名

```text
       ┌────────────────────────┐
       │   [ 核心收件槽：空悬 ]  │ ── 漏出珊瑚红乱码光斑
       │ ┌────────────────────┐ │
       │ │  席 位 编 号 格 栅  │ │ ── 成排待点亮的席位卡
       │ │  时 间 轴 较 验 轨  │ │ ── 冲突日期摆针
       │ └────────────────────┘ │
       │    巨型立式站务分拣塔    │ ── 气阀与黄铜机械臂
       └────────────────────────┘
```

*   **轮廓与外形**：Boss「请确认收件人」是一座泛着冷冽金属与胡桃木光泽的站务分拣机械。其顶端最显眼的核心收件插槽赫然**“空悬无物”**，不断向外泄漏着警示的珊瑚红光屑。
*   **四拍循环声画节拍**：
    *   *第 1 回合（单段 3 伤害）*：站务塔顶亮起刺眼探照灯锁死目标，播报音冰冷响起：“姓名栏未匹配”，射出一枚高亮红光束。
    *   *第 2 回合（多段 2+2 伤害）*：两封边缘带金属锯齿的加急特快信件破空旋出，贴着铁轨划出两道锐利音爆。
    *   *第 3 回合（蓄力重击 5 伤害）*：月台上所有空座位的席位卡同时翻转亮起红色感叹号，断轨中爆发出一股巨大的水银状数据冲击流！
    *   *第 4 回合（休整 0 伤害）*：分拣塔阀门过热卡死，黄铜指针在半空中艰难摆动，发出“咔哒……咔哒”的发条停顿声。
*   **核心破绽**：它的一切狂暴皆源于“找不到收件人”。击破其护盾时，攻击会直接作用于那个空悬的插槽，使其防御校验陷入紊乱。

### 3.4 典型小队作战与动作交互（Claude + DeepSeek）
*   **DeepSeek（蓄力爆发主 C）**：
    *   *稳住火候（蓄力）*：双手将白瓷小碗捧在胸前，小脑袋低垂，脚下泛起一圈圈纯净清澈的深蓝水纹，身侧文火静燃。
    *   *提早开饭（满白饭兑现）*：在 Boss 第 4 回合休整时，双手将瓷碗高举过顶！身后机械大鲸尾暴涨数倍，掀起漫天水沫重重拍击而下！深蓝色的浩瀚鲸浪（宽达百像素）席卷全场，将整座分拣塔正面彻底淹没！
    *   *挂机彩蛋*：长考超过 30 秒，DeepSeek 捧着饭碗犯困小鸡啄米，险些将碗跌落时瞬间惊醒，慌忙护住小脸通红。
*   **Claude（缝合轨道）**：
    *   抽出一道金光流苏书签，以手腕优雅挥针，将错位的两条日期轨道强行缝合拉平，使团队免遭轨道脱轨伤害。

### 3.5 胜负与收束演出
*   **胜利**：水浪退去后，一张工整填好名字与日期的席位卡咔哒一声滑入空插槽，严丝合缝。月台防风灯转为温润的暖橙色，断轨在云海中延展成一条平稳的黄金航道，列车汽笛清扬。
*   **现实片段沉淀**：黑底剧场中，悬空许久的手指终于勇敢地按下了发送键。“发送成功”四个字亮起，车窗外，晨曦微露。

## 四 场景三：【红线长廊·匿名审验台】
**—— 阶段高难专属挑战战**

### 4.1 任务背景与概念定位
*   **任务归属**：高难挑战关底《今天必须交》/《全篇引用必须闭合》（研究生 / 公司员工）
*   **战斗节点**：阶段专属 Boss 战（事件 ID：`ch2.employee.stageBoss` / `ch2.student.stageBoss`）
*   **Boss 实体**：**「今天必须交」**（生命 42 HP / 攻击模式：`3 → 1+1+1 → 5 → 休整 0`，具备拖延加压）
*   **核心意象**：宋体双栏长廊、漫天红色批注线、急速迫近的子夜水银防暴铁闸。

### 4.2 三层空间精细化描述

#### 1. 明线地貌（双栏回廊）
*   **空间布局**：逼仄纵深的狭长走廊。地面与两侧墙体全是由小五号宋体字块层叠砌筑的学术与契约高墙，空气中充斥着干燥滚烫的打印墨粉味。
*   **高空视效**：走廊上方垂挂着漫天荧光红色的批注标签：“【格式错误】”、“【缺少对比实验】”、“【此处有歧义】”。

#### 2. 验收态变形（铁闸逼近）
*   **物理压迫**：长廊尽头凭空砸下一面沉重无比的液压防暴铁闸门。闸机中央屏幕上的红色倒计时无情锁定在 `23:59:59`。
*   **空间挤压**：伴随着沉重的金属齿轮传动声，铁闸随着回合推进不断向前推进滑移，将角色队伍的立足之地逼入绝境。

#### 3. 暗线记忆投影（黑底微光）
*   **暗线环境**：墨蓝黑深处，是一处深夜只有单台显示器发光的格子间工位。
*   **生活锚点**：桌角凌乱倒伏着三个喝空的速溶咖啡纸杯，键盘噼啪作响，右下角的时钟分秒无情跳动，惨白的屏幕光映着一张写满倦意却咬紧牙关的脸。

### 4.3 Boss 实体表现与战斗签名
*   **轮廓与外形**：Boss「今天必须交」形似一座由无数红色校对剪刀、删除线与审核公文夹拼成的浮空审判高台，核心浮动着一根不断被压榨的红色进度条。
*   **四拍循环声画节拍**：
    *   *第 1 回合（单段 3 伤害）*：审判台前亮起刺目红字“逻辑断裂！”，一道凌厉的红色光刺从天穿透。
    *   *第 2 回合（多段 1+1+1 连续斩击）*：三把校对飞刃在半空中划出三道笔直的血红删除线，高频切削队伍防线。
    *   *第 3 回合（极压 5 伤害穿透）*：水银铁闸剧烈下压，整座双栏长廊剧烈震颤，发出沉闷刺耳的金属断裂声。
    *   *第 4 回合（休整 0 伤害）*：闸机由于液压过载停顿泄压，排气管喷出白汽：“等待合规补丁注入……”。
*   **拖延加压法则**：遵循 `floor((turn−1)/4)`，战斗拖延越久，其第一段伤害越高，逼迫玩家在时限内组织致命爆发。

### 4.4 典型小队作战与动作交互（GLM + GPT）
*   **GLM（工程支援热修）**：
    *   手提半透明工具箱，单膝点地按在受损的地面上，掌心亮起翠绿色的热修补丁，在水银闸门导轨间强行打入一道加固光栓，使全队爆发牌费用即时 -1。
*   **GPT（星环极速穿透）**：
    *   三层连击瞬间拉满，身侧星环化为一道笔直的紫白贯穿射线，顶着闸门下坠的狂暴气流逆流而上，精准轰穿审判台的核心进度条！

### 4.5 胜负与收束演出
*   **胜利**：倒计时的最后 1 秒死死定格，血红跳变为翠绿的 `00:00:00 · 提交完毕`。水银铁闸缓缓升起，满天的红色批注如同被阳光融化的雪花，化作温暖的金黄光屑静静飘落。
*   **现实片段沉淀**：深夜工位上，键盘声戛然而止。主角长舒一口气，仰头靠在椅背上。合上笔记本电脑，推门走出写字楼，迎面是清晨第一缕微风。

## 五 场景四：【终极之界·记忆散点座】
**—— 隐藏终极验收战**

### 5.1 任务背景与概念定位
*   **任务归属**：隐藏追加验收《刚才那份先放着，我还有一个要求》（D > T 阈值触发）
*   **战斗节点**：终局隐藏 Boss 战（事件 ID：`ch2.student.hidden` / `ch2.employee.hidden`）
*   **Boss 实体**：**「我」**（生命 56 HP / 基础模式：`3 → 2+2 → 6 → 休整 0`，具备在队 AI 镜像修正）
*   **核心意象**：虚空并轨重叠、退散的明线地平线、由 0/1 散点构成的普通办公转椅、屏幕前闪烁的打字光标。

### 5.2 三层空间精细化描述

#### 1. 虚空并轨重叠
*   **空间的极致留白**：在这里，明线的纸页公路与暗线的离散剧场**第一次也是唯一一次彻底并轨重叠**。所有多余的草稿、轨道、长椅如潮水般悄然退去，化作地平线尽头微弱的蓝光。
*   **镜面地面**：脚下是平静如镜的水银黑底地面，倒映着稀疏漫天的冷青（`#69D7E7`）与暖琥珀（`#F2B85B`）光点。

#### 2. 实体凝聚（散点转椅）
*   **非怪物形体**：虚空中央，由微小的 0 和 1 字符与扫描光线汇聚交织，缓缓拼凑出一张再普通不过的**办公转椅、一张木桌，以及一台泛着幽光的电脑屏幕**。
*   **环境声场**：所有热烈的战斗音乐彻底隐去，只剩下空旷房间内的底噪、椅子滑轮挪动的细微吱呀声，以及敲击键盘的清脆声响。

### 5.3 Boss 实体表现与战斗签名
*   **轮廓**：转椅上半隐着一个由光点勾勒的背影，没有狰狞面孔，只有疲惫而执着的坐姿。
*   **台词与规则改写（核心机制）**：
    *   *开场白*：“刚才那份先放着。我还有一个要求。”
    *   *第 1 回合（单段 3 伤害）*：“先按这个口径算。”光标一跃，一道淡青色校验波纹无声横扫全场。
    *   *第 2 回合（多段 2+2 伤害）*：“昨天说的那几条，今天全改一下。”虚线框将两名角色分别锁定。
    *   *第 3 回合（高难极压 6 伤害）*：“三条要求里有两条互相打架，但我现在就要。”屏幕光芒暴涨，全屏白光冲击！
    *   *偶数轮 AI 镜像修正*：若 GPT 在场，「我」学会了首段减伤 2；若 DeepSeek 在场，「我」在屏幕前蓄力（下回合首段 +2）。玩家是在与自己赋予的规则搏弈！

### 5.4 典型小队作战与全员守护
面对「我」反复摇摆的新要求，AI 少女们展现出相伴至今的沉稳：
*   **GPT**：“先把这一轮的完成条件写下来。三条标尺，不能一边走一边改。”
*   **Claude**：“新增的部分，必须单独确认。我绝不让你在慌乱中再次按下确认。”
*   **DeepSeek**：“先把出于恐惧而硬加的废话划掉，再来谈怎么动手。”
*   **终极协议（world.execute(me)）**：少女们的大招全数展开，化为一层温柔而坚定的滤网，把混乱的光点梳理为井然有序的结构。

### 5.5 胜负与终极情感升华
*   **胜利（不演消灭，唯有释怀）**：
    将 Boss 打至 0 HP 时，转椅与背影**绝对不会爆炸或消散**。
    屏幕上的光标停顿了三秒。Backspace 键发出一连串轻响，那句充满纠结的“都行，你看着办”被逐字删去。
    随后，屏幕上安静地敲出了一行平静、笃定、终于下定决心的字句：
    > **“收到。今天就到这里，谢谢你们。”**
    光点拼成的转椅留在原地，所有刺目的警示红光彻底退去，化为一圈温暖的暖琥珀光晕。
*   **终局收束**：
    行旅终端车缓缓滑行至转椅旁停下。车门轻启，暖风拂过。
    *任务会完成，故事还在继续。*
