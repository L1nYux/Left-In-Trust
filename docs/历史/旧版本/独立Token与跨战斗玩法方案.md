# 算力回廊独立 token 与跨战斗玩法方案

版本 v0.4　日期 2026-10-24

> **后期挑战补充 v3.2**：用户新增通关后提高难度，以及超过阈值在最后章底之后追加隐藏“我”，依人生阶段与 AI 队伍变招。见 [AI 任务视角与高难隐藏 Boss 方案](AI任务视角与高难隐藏Boss方案.md)。隐藏战为后续独立战斗，建议正常胜后 +3 一次、余额继承、不回满不复起；连续 Boss 资源与难度尚待验证。AI 对白同时改为处理任务的视角。

> **叙事开局补充 v3.1**：用户已明确局外可选“我”的人生阶段，影响部分 AI 对话、暗线与概率专属关底，见 [人生阶段与随机 Boss 叙事方案](人生阶段与随机Boss叙事方案.md)。旧文身份暂缓不再排除这项叙事选择；身份主动技能、初始资源差异与额外成长仍未恢复。下述个人 token 与战斗规则不变。

**每名角色独立持有 token，既用于付费出牌，也用于承受伤害；余额跨战斗保留。每次胜利后，余额仍大于 0 的已入队角色恢复 3 token，上限内。** 单名角色耗尽只会下线；当前所有上场角色耗尽才导致本局失败。耗尽者保留角色与卡组，可通过战外整备恢复。

这让主要决策从“花全队多少资源”变成“这张牌让谁来用、这一刀保护谁、下一战派谁上场”。公共操作仍是看意图、抽牌、每人行动一次，特色继续来自各角色自己的玩法。缓存记录只属于 Kimi。

独立 token、跨战继承和每场有限恢复由用户明确提出；下列恢复时点、数值、下线处理等是本轮具体设计默认，仍需原型试玩。原 Word 与 v0.2、v0.3 材料保留，不直接当作本版数值依据。

## 1 三条最重要的变化

| 事项 | 本版规则 | 玩家得到的选择 |
| --- | --- | --- |
| 谁支付 | 出牌者用自己的 token 支付，不能自动借用队友余额 | 同一张通用牌换人使用，费用承担者和角色效果随之变化 |
| 谁受伤 | 敌人意图显示目标头像，伤害只扣目标的 token | 防御和支援有明确受益者，可以保护下一战需要的输出角色 |
| 打完剩多少 | 胜利保留实际余额，正余额者再 +3，不回满；耗尽者需整备 | 战斗过程影响后续选路、商店、休息与轮换 |

首轮每名角色 token 上限统一为 12，开局角色从满额开始。上限不随当前上场人数变化，取消旧版单、双、三人共享 12/16/20 的参数。角色之间的上限差异后续通过自身成长与插件实现，先用相同上限验证规则。

每人只显示一条 token 条，不再加独立 HP 或每回合刷新的法力条。算力仍是地图货币，不能在战斗中自动抵扣不足的 token。

## 2 战斗与行动

### 2.1 公共回合保持简单

1. 展示每个敌人的意图、目标、攻击顺序与具体数值。
2. 从共享牌库抽 5 张，抽牌堆不足时洗入弃牌堆。
3. 玩家自行安排尚未行动的在线角色，每人出一张牌或进行一次基础动作。
4. 存活敌人按预告顺序行动，逐段处理个人防护、个人 token 与下线。
5. 清空本回合防护、处理未用手牌，进入下一回合。

通用牌可由任意在线且未行动角色使用；专属牌只由绑定角色使用。**使用者、付费者是同一角色，目标可以是自己、队友或敌人。** 对队友使用补给或防护，不会把费用转嫁给受益者。

付费操作必须使使用者至少剩 1 token。不能先用该牌的回复垫付费用，也不能自动从队友扣取差额。0 费牌和基础动作在仅剩 1 token 时仍可使用。

基础攻击免费造成 3 伤害；基础防御免费给自己 3 防护。两者都消耗自己的行动。没有公共温度、窗口负荷或全队记录配方。

### 2.2 防护和敌人目标

防护也按角色独立记录：有防护的角色受击时，先消耗自己的防护，再扣自己的 token。多段伤害逐段扣除同一份防护，不能重复使用；回合末剩余防护清零。

普通防护牌可以指定一名在线友方角色，包括自己。给出的防护结算后不会因施加者下线而立即消失，仍持续到本回合末；施加者下线后不再触发自己的被动。

敌人选择目标的规则预先写在模板中，例如按队伍槽位轮换、固定攻击当前第一名在线角色、或群体攻击。每回合意图出现后锁定目标，不在玩家出防护后悄悄改打最低余额者。

同一条意图的目标中途下线，其剩余伤害段空过；其他已锁定该目标的普通攻击也空过，不自动转火。下一回合重新选择在线目标。群体攻击只各自结算一遍，不把下线者应受的伤害转给队友。

首轮不增加前后排距离、速度或走位规则。用已存在的队伍槽位与目标头像表达，支援卡改变承伤结果。

### 2.3 下线与失败

| 情况 | 处理 |
| --- | --- |
| 某角色受到伤害后 token 为 0 | 立即下线，token 保持 0；本场失去行动与被选为新目标的资格 |
| 本回合尚未行动便下线 | 本回合行动直接失去，不转送队友 |
| 一人下线但还有在线队友 | 战斗继续，奖励不会仅因此取消 |
| 所有本场上场角色下线 | 本场失败，本局结束；即使替补有余额也不自动救场 |
| 胜利时有下线角色 | 胜利照常结算，但该角色保持 0，须通过休息或商店恢复后才能再编入 |
| 战内普通回复选中下线角色 | 不合法，不靠常规回复复活；未来专门复活卡须另行定义 |

下线不是永久删除角色。下线时清除自己的连击、反击、白饭和私有记录资格；已消耗卡仍保持消耗。所有属于该角色、尚未消耗的专属卡从抽牌堆、手牌、弃牌堆和私有记录槽移入本场封存区，不补抽，不再堵塞后续手牌。

封存不是遗忘或删卡；战斗结束恢复局内牌组。替补专属卡本来就不加入本场牌库。仍不开放战斗中热插拔或 API 调用。

## 3 跨战斗恢复与编队

### 3.1 唯一自然恢复时点

**胜利结算时，所有余额大于 0 的已入队角色各恢复 3 token，包括替补，不超过各自上限。余额为 0 的角色不自动恢复。** 一场战斗只结算一次。失败、载入存档、查看地图、进出编队、重复打开战利品页面都不触发恢复。

新战斗开始时只读取当前余额，不再恢复一次。未获胜的战斗不给补给，首轮不提供可反复进入的逃跑刷恢复流程。

选在胜利后恢复有两个好处：玩家在选路前就能看到真实状态；恢复不会被误解为每次进入战斗都能领取。替补同步恢复让轮休有用，恢复量不随已经打了几回合或队伍中谁造成击杀改变。

0 token 角色不能编入新战斗，需要休息整备或商店补给恢复。两者在战外可以选择 0 token 角色，战内普通补给不行。所有可用角色均为 0 时不能出发；失败后不先执行恢复来自救。

不给耗尽者免费复起，是为了防止每场都把低余额队友当作一次性挡刀者。它不是永久死亡，也没有新增伤势条，只是需要花费一个地图恢复机会。

### 3.2 战外可以免费调整阵容

每个节点之间可以换上场阵容，最多三名，至少一名余额大于 0 的角色。每名角色的余额跟随唯一角色 ID 保存，换位、换装或暂列替补都不重置。

余额大于 0 的轮休角色不承担本场费用和伤害，胜利后也获得同样的 +3。这是保护受损角色的一种办法；代价是本场少了它的技能、专属牌和行动者。0 token 替补仍需整备，不能后台复起。敌人不会因为临时少上一个人就动态减弱，不能通过反复减员获得更低难度和更多恢复。

初期一人时没有轮休余地，首章路线与补给必须按单人设计；不能要求先招募第三名才有合理恢复。完整 roster 上限沿用 6 人长期方向，当前 Demo 仍只制作三名角色。

### 3.3 恢复来源各有位置

| 来源 | 首轮候选效果 | 限制与用途 |
| --- | --- | --- |
| 战后自然恢复 | 每名余额大于 0 的已入队角色 +3 | 每次胜利一次，含正余额替补；不自动复起耗尽者 |
| 休息整备 | 选择一名角色 +6 | 与升级一张卡、删除一张卡互斥；解决某人的集中亏空 |
| 商店补给 | 支付 6 算力，使一名角色 +4 | 每间商店一次，付款前预览实际回复，不购买 0 收益补给 |
| 战内应急补给 | 选择一名在线角色 +2 | 0 费、占施用者行动、此卡本场消耗；牌组初版只放一张 |
| 额度转交 | 施用者支付 2，另一在线角色 +2 | 占行动，不创造全队净 token；施用者至少留 1，受益者须有至少 2 的缺口 |

战内没有可无限循环的免费回复牌。应急补给在战后恢复为牌组实体卡，下一场可再用，但每场只有牌组里那一份；生成、复制、回收此类牌暂缓。首轮普通卡不同时“高伤害并按伤害回血”。

自然恢复和战内消耗回复都有明确上限。敌人后期按公开脚本增强，不能在普通防御下永久等待；需要允许有限的补给时机规划，但不让拖长一战成为无限充电。

## 4 首批公共卡与个人预算

| 卡牌 | 使用者花费 | 效果与目标 |
| --- | --- | --- |
| 标准指令 | 自己 1 | 对一名敌人造成 6 伤害 |
| 防护指令 | 自己 0 | 为一名在线友方角色提供 4 防护 |
| 强力指令 | 自己 2 | 对一名敌人造成 10 伤害 |
| 应急补给 | 自己 0 | 一名在线友方角色恢复 2；本场消耗 |
| 额度转交 | 自己 2 | 另一名在线友方角色恢复 2；不算治疗复制，不允许对自己使用 |

低余额角色不一定必须休息：它仍可以用 0 费防护保护他人，或者用免费基础攻击补刀。健康角色负责使用通用付费攻击牌，自己的费用自己承担。

但受伤者继续上场也有风险：敌人可能预告攻击它，它一旦下线就会损失行动和专属卡。若其关键技能下一战很重要，提前轮休或花一次休息恢复可能更划算。

个人预算按 `战后余额 = min(个人上限, 本战入场余额 − 自己支付 − 自己实际损失 + 战内实际收到的回复 + 本次自然恢复)` 计算。本次自然恢复仅在胜利且结算前余额大于 0 时为 3，否则为 0；之后若选择休息或商店，再单独加上该节点实际恢复。转交者的支付计入前项，受益者的到账计入后项；不会因为全队总额足够就允许某个穷角色出牌。

## 5 角色玩法如何随之改变

### 5.1 GPT 连续进攻变成体力管理

沿用连击 0–2：攻击牌按已有层数每层增伤 2，之后加一层；非攻击牌、基础动作或跳过使连击归零。现在费用全部由 GPT 自己承担，Claude 不会在后台替它付费。

GPT 需要决定是否为了提早结束战斗继续烧自己的余额。队友可用防护或转交支持它；若下一场还要它主攻，也可以让别人用通用攻击收尾，GPT 以 0 费防护结束当前战斗。连击不跨战斗。

### 5.2 Claude 保护明确的人

反击改为：本回合 Claude 向某个在线友方角色提供了正数防护，且该保护对象在敌方阶段有防护实际抵挡伤害，则在敌方阶段结束时获得一次反击就绪；Claude 必须仍在线。下一次自己的攻击对一个目标的一段伤害 +4，最多存一次。

不要求追踪“消耗了谁贡献的哪一点盾”；条件明确是该保护对象本回合有防护挡伤。Claude 本回合没参与保护、或保护对象没有受击，都不获得新反击。基础防御只能保护自己，防护牌可保护他人。

她保护的是队友的长期余额，又能以反击输出；但自己成为目标时也需要留有防护。已授出的防护在 Claude 下线后仍按本回合效果存在，反击被动则停止。反击不跨战斗。

### 5.3 DeepSeek 等待爆发要考虑真实承伤

沿用每个在线回合末 +1 白饭，最多 3，满层下一张卡面费用至少 2 的攻击消耗全部并加伤 6。白饭不跨战斗，替补不在后台叠层。

对手预告攻击别人时，DeepSeek 可以安全积蓄并提供低费支援；对手连续点名它时，等待第四回合可能造成过多长期损耗，提前花自己的 2 token 用强牌解决威胁也许更好。

不再把满层作为唯一合理出手点。卡牌分支应允许“较早兑现”和“满层收益更高”两条后续路线，但首轮只做现有满层机制。

### 5.4 Kimi 仍只管理自己的记录

延续两槽私有记录、下一回合接力、消耗旧卡与满槽溢出回弃牌堆。只有她的专属卡提供三种标签，其他角色不参与配方。

校验→分析的减费只影响 Kimi 本人的费用；生成→校验回复 1 也只回复 Kimi 自己，不能额外给全队各发 1。她的记录不能跨战斗带入，不恢复已经消耗的补给卡，也不能让专属回复无限循环。

Kimi 下线时，未消耗的私有记录卡本场封存；战后牌组恢复，记录清空。她仍作为后续进阶角色，不自动扩大三人 Demo。

## 6 地图开始承担持续运营

地图路线提前展示节点类型与下一场主要敌人特征，玩家结合个人余额选路。例子是 GPT 只有 4、Claude 还有 10：前方精英持续点名 GPT，则可以走休息恢复 GPT，或换阵容走普通战保住它；不能因为全队总额仍高就无视其危险。

一条首章短路线先安排普通战、事件、普通战、休息、普通战或商店分支、Boss，共约 6 个实际经过节点。首个 Boss 前保证能选择至少一次休息整备；精英路线是可选风险，不承担首次玩家必要的恢复来源。

普通战奖励算力初拟 4、精英 8，卡牌仍三选一可跳过。商店治疗初拟 6 算力，与买卡、删卡竞争；价格和收益未做整局平衡，不承诺该路线无需任何补给也能过。

休息的回血选项重新变得有效。强化成长会牺牲本次恢复，恢复则牺牲当前升级机会；不再使用 v0.3“下场回满所以休息不回血”的理由。

Boss 胜利先给现有队员自然恢复，再进入招募或微调。新招募角色以自己的满额 12 加入，不重置旧队员余额；同角色不重复招募，首轮也不提供解雇再招募的洗余额办法。

招募先给两张可加入或替换的专属卡，其余进奖励池。新钱包与额外行动都很有价值，跳过招募的奖励仍需专门比较，不能沿用旧“两次升级已经等价”的假设。

## 7 两场连续战斗的例子

GPT 与 Claude 初始各 12。敌人 26 生命，前三回合每次攻击 4；第一场依次点名 GPT、Claude、GPT，第二场交换开头两人的目标顺序。角色都使用自己的 token，防护指令可给队友。

| 战斗 | 主要行动 | 结算前 GPT | 结算前 Claude | 各自 +3 后 |
| --- | --- | --- | --- | --- |
| 第一场 | 首回合 GPT 攻击，Claude 保护 GPT；第二回合两人进攻，Claude 用反击；第三回合 GPT 收尾 | 9 | 7 | GPT 12，Claude 10 |
| 第二场 | 从 12 与 10 入场；Claude 先保护自己；第二回合 GPT 承受锁定攻击；第三回合 GPT 收尾 | 5 | 9 | GPT 8，Claude 12 |

两场都有胜利，长期亏空却从 Claude 转移到了 GPT。第三场的选路和通用牌使用者因此会变化，不能把两人又当成同一个共享钱包。

第一场也可改为两人连续进攻，两回合击杀，战后为 GPT 9、Claude 12。它更快，但比保护路线多损耗 GPT、少损耗 Claude；玩家根据下一战预告选择。这是本版希望产生的取舍，不宣称两条序列在所有场景等强。

具体复现与边界验证见 `docs/历史/旧版本/独立Token玩法推演.md`。该例只用指定牌序与敌人脚本，不代表完整随机地图已平衡。

## 8 首轮实现与验收

角色头像旁显示个人余额与上限、当回合防护、该角色的一项专属状态。选牌时预览具体从谁扣费、给谁加盾或回复；选路时显示结算后的真实余额。不设置可以付费的“全队总 token”数值，避免误以为几个余额仍能自动通用。

存档须按唯一角色 ID 保存余额与上限，并保存已结算的战斗 ID、休息或商店服务的领取状态；恢复到账和结算标记应作为同一次存档更新。一个休息节点只能做一次选择，重新打开不能重复治疗。本轮夹具仅检查内存中的恢复幂等和服务限次，不代表实际存档与故障恢复已完成。

先做一个角色的两场连续战斗，确认余额不重置和恢复不重复，再加入 GPT 与 Claude 的定向防护、个人支付和下线，之后加入 DeepSeek。Kimi 不进入这轮三人数量。

必须验证：

- 每名角色的上限、余额、防护独立；缺钱不能扣队友，给队友加盾不等于自己有盾。
- 胜利 +3 只结算一次，正余额替补同样按个人上限截断；0 token 角色不自动复起；开战、编队和读档不给额外恢复。
- 一人耗尽继续、全上场耗尽失败；失败不恢复，普通补给不能战内拉起 0 token 角色。
- 下线专属卡封存、不再抽到，卡牌实体守恒；封存与本场消耗不同，战后局内牌组正常还原。
- 定向防护、多段攻击、目标中途下线与群体攻击按明确顺序结算；个人状态在战斗间正确清零。
- 应急补给每张每场一次；额度转交严格等量且受益者合法；不存在无限免费回血或重开同一节点领补给。
- 单人首章具有可到达的恢复节点，不依赖队伍轮休；多角色测试健康者进攻、伤者支援是否有实际选择。

具体恢复量 3、角色上限 12、休息 +6、商店价格、敌伤、招募与微调强度均为试验默认。可玩界面、随机牌序胜率、完整两短章经济和真人理解成本仍未完成，不将旧版样例验算算作本版通过。
