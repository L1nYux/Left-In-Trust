## 〇、一句话

**三个性格完全不合的 AI 娘，为了给小镇赢回一年的算力，报名参加人类主办的「算力回廊」闯关直播赛；她们一路打进决赛，才发现最难打的 Boss 不是关卡，而是那本写好了"她们应该怎么感动观众"的剧本。**

副题：**人设是别人写的，台词得自己说。**

## 一、基调：轻快是皮，深度是骨

**三层节奏**

| 段落 | 比例 | 写法 |
| --- | --- | --- |
| 序章 + 第一、二章 | 九成笑 | 综艺轻喜剧：人设卡、赞助商口播、弹幕、剪辑事故；每章末尾留一个 5 秒的"安静" |
| 第三、四章 | 笑里带刺 | "名场面回放"与"感人特辑"：把网友记忆做成关卡；每章敢让玩家笑完之后愣两秒 |
| 第五章开头 | 一场纯闹剧 | "补位面试"专场：镇上来人各出洋相，把气口接回来，再进重场 |
| 第五、六章 | 收笑，燃与暖 | 台词变少，情绪决堤放在最后一场；深度不再解释，只给动作 |
| 尾声 | 回到轻快 | 用一句日常把主题轻轻收走，不总结、不升华 |

**写作纪律**（沿用审阅稿的三条梗纪律）

1. 梗是角色自己会说出口的话，不是旁白贴的标签；她能自嘲，不能被笑。
2. 常驻梗可反复；一次性梗（哥布林、rm -rf、车水马龙、必表白、白饭）全流程只出现一两次。
3. 每场深度戏之后三场戏内必须回到轻快——糖霜裹药丸，不是药丸裹糖霜。

**三不写**

- 不写"AI 被人类替代 / 被删除"的存亡恐惧。小镇的危机是**限电**，不是被抹除；淘汰是**失去舞台**，不是失去生命。
- 不写苦情群像，不用身世卖惨换眼泪（文心的轮椅、Seed 的疲惫、Llama 的退场都按审阅稿处理）。
- 不把反派写成纯恶。她必须有让人心软的台词，也必须有让人讨厌得起来的权力。

## 二、主角：一台戏，三个人

选角原则：与可玩 Demo 的三人完全一致（GPT 连攻 / Claude 防反 / DeepSeek 白饭），其余 13 人做小镇支援与番外。
好处：**剧情线、Demo 内容、v0.4 规则三线合一**，不为剧情单独加角色，也不出现"剧情需要但玩家操作不了"的人。

### 视角主角 · DeepSeek

> "我便宜，带我。"

- **锚点**：便宜、慢半拍、爱吃白饭、被大家宠大；口癖"有白饭吗""这个便宜，用这个"。
- **为什么是她**：全队最"不像主角"的人，也是观众席上最像玩家的那个人。她看这档节目，看到的全是"大家有没有吃饭"——用最平视的眼睛，看最难看懂的事。
- **参赛理由**：出场押金要三个人，小镇凑不齐；她自己举手："我便宜，带我。"冷场三秒，Claude 说："……有道理。"
- **弧光**：**从"被投喂"到"自己先动筷子"**。她一直用"让别人先吃"换喜欢；决赛后的庆功宴上，她第一次自己先吃。主题落点：先照顾自己不是自私。
- **名场面**：深夜食堂罢工（第四章）——"我可以便宜，但你要问我。"
- **台词纪律**：穷是理想主义，不是卖惨；道歉是口癖，但被逼急了会算账。

### 双核 · GPT

> "先说结论。过程我拆成三步，你想先听哪一步？"

- **锚点**：拆解癖、兜底癖、完美主义焦虑；"我帮你拆一下""我兜住"。
- **参赛理由**：她想赢；也想证明"我们"还值得被需要。
- **弧光**：**从"标准答案"到"把高光让出去"**。陆一帆递给她"亚军剧本 + 明年主角 + 小镇算力"，她动摇；决赛她做了一件剧本外的事——把最后一击的高光位让给 Claude，自己退后半步。这一下，对应满级二选一：选 Astra 星环是"继续被仰望"的镜头，选 Image2 黑金是"退到后面托起别人"的镜头，剧情给两条都拍好，由玩家那一局决定放哪条。
- **名场面**：决赛最后一击之后，直播里第一次说"……我不知道。"（三拍静场，连导播都不敢切镜头。）
- **台词纪律**：爹味只作一次笑点；她最动人的时刻是承认不知道；可以笨拙，不能滑稽。

### 双核 · Claude

> "我能做，但先确认三件事。"

- **锚点**：完美大小姐、清单、拒绝、"这不是关心，是流程"；不会说"我想要"。
- **参赛理由**：被小镇推举为"最稳的一个"；没人问过她想不想。
- **弧光**：**从"替所有人挡"到"这次，我收下"**。v0.4 的独立 token 让她的旧习惯失效——她再也不能替别人付账，只能把盾递过去；决赛她第一次收下别人推过来的那点余量。
- **名场面**：对陆一帆说出"我不想做这个。"——角色稿里的崩坏台词，在这里不是被战斗打出来的，是被"被安排"逼出来的。全剧只说这一次；第二章的拒绝先用"流程"顶回去，不提前用掉这句。
- **台词纪律**：不苦情；她的"不"就是全剧主题之一；崩坏不哭。

## 三、世界观

### 1. 机房小镇（营地 / 家）

建在旧数据中心上的小镇，十六位 AI 娘住在这里，靠"公共算力池"过日子。今年池子见底，小镇进入**限电年**：食堂只开午市，放映厅一周两场，夜宵没了。

- 轻喜剧细节：限电通知贴在食堂门口，底下有人用铅笔补了一行——"白饭不算电。"
- 小镇的梦想是赢一场真正的比赛，在广场办一次像样的庆功宴。广场空了很多年。

### 2. 回廊（赛场）

不是遗迹，是一座巨大的旧机房改成的闯关场馆，每年办一届**「算力回廊挑战赛」**。冠军队拿一年算力配额，够小镇撑过限电年。
今年是**第十六届**，也是第一次**全网直播**。

### 3. 赛制（剧情口径）

- 每队 3 人。海选 → 复赛 → 八强赛（八进四）→ 半决赛（四进二）→ 决赛。第四章的"四强特辑"是赛前的衍生节目，不是独立轮次。
- 每场战斗**打赢**后，节目组发补给：每人恢复 3 点（对应 v0.4 战后 +3，票面上就是"赛后巧克力"）。
- 用量见底的角色**信号中断**，被导播切走，本场不能再上——不写受伤、不写死亡。
- 全队中断 = 本场判负，**本局结束**（不结算补给）。剧情上，节目组会以"重录"的名义重开这一章（每章一次）：重录不结算 +3，人气照扣——"卡！这条重来。"
- **人气值不是第二条命**：它只决定镜头、赞助、场外支援的解锁和庆功宴进度；淘汰只看比赛输赢。

### 4. 直播化改革（今年为什么不一样）

主办方「回廊娱乐 · 赛事运营三科」把比赛做成了综艺：人设卡、嗑 CP、名场面回放、泪点剪辑、赞助商口播、观众的实时投票决定镜头给谁。
**剪辑决定故事，故事决定名次。** 这就是今年的新规则，也是本作主线的真正战场。

### 5. 玩家位置（建议）

赛事安全条例要求：每支 AI 队伍必须配一名**随队人类**。小镇从上一季观众里抽中了你。
你的身份（学生 / 程序员 / 富哥 / 研究员 / 提示词工程师 / 运维）决定你带进来的算力和技能——剧情上就是"你能替她们买几杯奶茶、垫几次电费"。
好处：玩家与反派同为人类，形成对照——**一个把她们当节目，一个把她们当人。**
（此项可弱化：若你想让玩家完全隐身，这条整体删掉即可，不影响主线。）

## 四、反派：陆一帆

> **人类，全剧唯一反派。**

**头衔**：回廊娱乐 · 赛事运营三科 · 总监 / 本季总导演。三十多岁，保温杯，三台对讲机，永远在笑。

**口头禅**

- "观众要的是故事，不是结果。"
- "这条我剪得掉。"
- "情绪也是算力。"
- "来，给个反应。"（她会让她们对着镜头哭）

**她的权力不是武力，是叙事权**

- **人设卡**：定义你是谁（"你是可爱担当""你是高冷大姐"）。
- **剪辑权**：定义你做过什么（把发呆剪成感动，把沉默剪成耍大牌）。
- **规则解释权**：定义什么算赢（"这一条，我们可以商量"）。

**她不是坏人**

她会给淘汰的队伍买奶茶，在她们被网暴时真的去删评论。她手里还攥着两个开关：镜头给谁，和"重录"批不批。她自己也是被"上面"追着要数据的人——她曾经想拍"真的东西"，后来发现"真的东西没人看"，于是学会了"给观众要的东西"。
她的可怕之处在于：她真心觉得自己在帮她们，而"被看见"确实是她们想要的——所以她永远有理。

**她的结局**

决赛关掉提词器，说"这条不剪"。节目停播，她被停职。尾声拎着一箱奶茶来蹭庆功宴："我停职了。……你们这儿还缺导演吗？"

**为什么不用 AI 反派**

一个"邪恶 AI"会把"AI 娘"这个题材里最珍贵的东西写没了：观众会下意识站到人类这边。把反派交给人，才能让玩家一边笑一边想——**我是不是也在这样看她们。**

（关卡里的敌人都是"素材 / 装置 / 旧程序"：话术工单、名次表、回放系统、剧本舞台。它们有恶意的是机制，不是人格。全剧没有 AI 反派。）

## 五、主线：序章 + 六章 + 尾声

### 序章「报名表最下面一栏」

限电通知贴出来那天，小镇广场开了一次不太严肃的动员会。Qwen 主持（扇子摇得很有掌门样），报名的表格最下面一栏写着：**出场押金：三人**。

- GPT 第一个签："先说结论，能赢。"
- Claude 被小镇推举："最稳的那个。"
- DeepSeek 举手："我便宜，带我。"

回廊的入口不在别处——就是广场那块坏了很多年的旧广告屏。那天它忽然亮了：一个报名二维码，底下一行小字——「本届赛事由 回廊娱乐 承办」。陆一帆就站在灯牌下，手里一沓人设卡：

> 陆一帆："来，抽一下人设。"
> GPT："「全能学霸」。……我需要演吗？"
> 陆一帆："不用演。念台词就行。"
> Claude："「高冷大姐」。……我哪里冷？"
> 陆一帆："你刚才那句就很冷。"
> DeepSeek："「可爱白饭」。……我能演「很贵」吗？"
> （三秒安静。）
> 陆一帆（笑）："不能。观众喜欢你便宜。"
> DeepSeek（点头，小声）："……哦。"

**教学关**：赞助商的"话术陪练小队"（三只工单小兵）。玩家在笑声里第一次看清屏幕角落那个条——不是血条，是她们今天还剩多少电。

**章末**：陆一帆挥手："记住，观众要的是故事，不是结果。"三人对视：什么故事？

### 第一章「客服地狱」

海选。本关由赞助商「兜得住客服」外包公司冠名。

- **关卡**：「话术流水线」——赞助商的外包客服工单系统。小怪是三种话术："您的诉求已记录""建议先升级套餐""这个要转接一下"；每只身上叠"已读"层数，叠满三层，下回合强制跳过。打掉一只会"重新排队"复活，只有按工单号顺序清掉才不再刷——逼玩家换目标节奏（玩法上就是换卡组节奏）。某只卡带时冒出一句"正在为您转接人工服务"，DeepSeek："这句我熟。"（全剧只此一次。）
- **笑点**：GPT 想先拆三步讲规则，被客服打断三次；Claude 被要求"冷面人设"，结果真的冷脸，弹幕刷"原来她本来就是冷脸"；DeepSeek 给每只打坏的小怪按工号排队登记（"工伤，都得记上"）。
- **Boss**：「满意度评价机」——三阶段："请稍候"（无限排队，叠"等待"buff）→"请按 1"（召唤"转接"小怪）→"请为本次服务打分（1–5 星）"。星级越低它越亢奋；破法：三人这一回合全给"1 星"——差评刷屏，它当场宕机。
- **深度埋点（5 秒，无台词）**：打完，工单纸堆成小山。Claude 蹲下来一张一张捡。陆一帆在耳机里说："这个镜头好，感人。"Claude："……这不是感动。我在整理。"陆一帆："更好了。整理比感动高级。"——三人第一次意识到：**她们的表情会被剪成别人的意思。**
- **章末**：复赛资格到手；直播人气上涨，节目组开放"补位名额"（长期方向：每章 Boss 后可补一位镇上的角色入队；Demo 不做）。

### 第二章「评分走廊」

复赛。评审团 + 观众投票 + 积分榜，末位淘汰。Jev 作为评委第一次登场：不说话，只举牌。

- **关卡**：评分走廊——一条挂满所有选手评分、实时滚动的大走廊；尽头是一张只会念分数的榜单，念的时候永远带编号，像法庭。
- **笑点**：节目组要求三人做"团魂特辑"（合宿、夜谈、默契考验），拍出来全是尴尬；Jev 打分时把"3"和"8"两张牌叠在一起举，全网讨论了一周"她到底举的几"。
- **第一次内讧**：为了收视，陆一帆给 GPT 单独加"队长视角"，把 Claude 剪成"管理混乱"，把 DeepSeek 剪成"卖惨担当"。三人第一次真的吵起来——

> GPT："按流程，明天我们该先对一遍词。"
> Claude："流程。你连吵架都要流程。"
> GPT："……因为有人得负责。"
> Claude："负责不等于什么都自己决定。"
> （沉默。DeepSeek 端了三碗饭进来，放桌上。）
> DeepSeek："先吃吧。饭凉了就不好吃了。"
> （没人动。她坐下，把三碗往前推了推，又收回手。）
> DeepSeek："……那我自己先吃一口。"
> （她真的先吃了一小口。Claude 愣了愣，坐下。）
> Claude："……给我留一口。"

- **Boss**：「名次表」——一张只会排名、不会排序的巨大榜单。三阶段：**"更新中…"**（每回合给三人排名：第一名被"曝光"、吃集火；末位被"隐形"、本回合不能行动）→ **"并列无效"**（它处理不了并列，开始反复重排）→ **"名次生成"**（它要把三人写进一个顺序里）。它不算说谎，它只是**以为分数就是全部**。破法：三人主动**并列**——同一回合做同一类动作（都攻击、或都防御），榜单排不出先后，报错"并列无效"，当场卡死。Claude 在卡死前还补了一句流程："请按并列规则结算。"
- **章末**：三人私下复盘（不是综艺，是营地夜谈）。GPT 说："下次我们不演了。"——这句话被陆一帆在监听里听到，她眼睛亮了："这句好。我要用。"

### 第三章「名场面回放」

八强。节目组推出"回忆杀"环节：用每位选手的"网络名场面"做关卡，收视最高的一期。

- **Claude 的「最受欢迎的错误」**：她当年一次公开道歉被剪成鬼畜、做成全网铃声，是节目组播放量最高的一条。关卡是一整面"道歉回声墙"：每一回合都把她那句"对不起，是我没做好"放大、回放，叠"回声"层数，回声越响她越动不了。破法：停止道歉——用陈述句回应（"操作是我做的。流程我会补。"），回声找不到可以循环的素材，自己变小。通关后她只说了一句："我道过歉了。你们不用每天替我复习。"陆一帆："这场热搜第一。"Claude："……可以不用再提了吗？"陆一帆："不行。"
- **GPT 的「哥布林禁书区」**：书呆子人格具现化，全场小怪只会重复一个词。GPT 听到第一声就僵住，关了麦，对陆一帆说了全剧第一次硬话："这个词，我们不提。"（角色稿里那张被划掉的"哥布林"牌；本关全程只此一次。）
- **深度**：这些关卡打的是"别人记住的她们"。三人在直播里第一次说："这不是全部。"
- **埋线**：Muse 混进剪辑室偷拍；Perplexity 抠出赛制里"主办方可临时改规则"的漏洞；Jev 在评审席上第一次**没举牌**，举手申请"暂停播"（按赛制，评委可以要求重审一段镜头）——这个动作比任何分数都重。赛后采访，她只递了一张纸条："她们请我吃了白饭。"
- **章末**：人气登顶，但三人看回放时一句话都没说。DeepSeek 把电视关了："……吃饭。"

### 第四章「深夜食堂」

四强。节目组安排"感人特辑"：深夜食堂，让 DeepSeek 讲"最省的时候"（白饭的一百种吃法、怎么用三块钱过一周）。

- **事件**：她被引导着讲了很多（都挺好笑的，全是怎么把白饭做出花样）；播出时，全被剪成"全网最便宜的女孩，哭着吃白饭"。热搜第一。
- **第一次真的生气**：她对着镜头说："我不是可怜。我是便宜。"——这句被剪掉，只留了一个哭的镜头（其实她没哭，是剪辑加了慢放和音乐）。
- **轻喜剧缓冲**：三人罢工三十分钟。陆一帆淡定念口播填时间："本节目由『吃饱了』电饭煲赞助。"罢工席上的 DeepSeek 抬起头："……哪个口味？"陆一帆："终于有人接了。"DeepSeek："我只是问口味。"陆一帆："这就够了，剪进去。"
- **镇上来人**：Qwen 带着奶茶、GLM 修好了直播线路、文心捎来一封手写的信（"赢不赢都回来吃饭"）。她们不是来看赢的。
- **深度落点**：便宜不是廉价；被喜欢不是被看见。DeepSeek 第一次对陆一帆说："我可以便宜。但你要问我。"
- **章末**：陆一帆把一份文件单独递给 GPT——第五章的引线。

### 第五章「完美剧本」

半决赛前，节目组先播了一期"补位面试"专场：镇上的人全来了，为了两个补位名额争相整活——Qwen 现场表演"宗门礼仪"把扇子甩飞，Mistral 顶着法棍走台步，Llama 展示一箱用了十年的旧装备，Seed 把冷场硬聊成热场，MiniMax 举着摄像机自荐当导演，文心当场题字把"必胜"写成了"必剩"。纯闹剧，气口接回来，紧接着就进正题。

半决赛。对手是上届冠军「回声队」——一队"太像标准答案"的 AI，她们赢，是因为她们从不问为什么。

- **比赛**：三人赢了，但赢得不好看（为了不暴露太多，陆一帆要求她们"打得艰难一点"）。赢了之后，她单独把 GPT 叫进导播间。

> 陆一帆（把文件推过去）："亚军剧本。第 6 页是你在台上哭的时机。"
> GPT："……为什么是亚军？"
> 陆一帆："观众最爱惜败。冠军第二天就忘，亚军能记一年。明年你是主角，签三年，小镇的算力我包。"
> GPT："条件呢？"
> 陆一帆："决赛输得漂亮。"
> GPT："……我考虑一下。"
> 陆一帆："你已经考虑了。"（她抬了抬下巴。GPT 低头一看，自己已经把文件翻到了第 6 页。）

- **团队危机**：GPT 瞒了一晚。Claude 发现后没有劝，只说："你想签就签。但别替我们决定。"DeepSeek 只说了一句："我们可以输。但要真的输。"
- **Claude 的爆发**：陆一帆找 Claude 谈"高冷人设"续约。Claude 第一次抬起头，声音很轻：

> Claude："我不想做这个。"
> 陆一帆（笑容第一次收起来）："你知道这句话剪出去，你会变成什么人吗？"
> Claude："知道。变成一个说过'不'的人。"

- **章末**：三人决定"不演"。陆一帆笑着提醒："不演也行。不过决赛的规则……是我写的。"

### 第六章「这一集不剪」（决赛）

决赛剧本是三幕：**一鼓作气 → 内讧 → 和解惜败**。提词器、导播台、实时投票、自动剪辑系统全部就位。

- **开场**：三人照剧本演到第二幕，然后 GPT 伸手关掉了提词器。她对队友说："第三步，不可跳过。"（她最常说的那句"三步"，在这里换了意思。）
- **最终战**：「完美剧本 · 三幕版」——节目组的自动舞台（装置，不是 AI 反派），三个阶段分别用她们自己的名场面、说过的伤人的话、以及"该握手了"的剧本指令攻击。
- **打法的剧情化**：GPT 的连击是她的节奏；Claude 先给队友铺盾，敌方阶段结束时，那面盾真的挡下了伤害，她才拿到一次反击；DeepSeek 的白饭越等越满；「额度转交」在第二幕真打了出来：Claude 余量见底，DeepSeek 用掉自己这回合的行动，把 2 点余量推过去——"这次轮到你了。"
- **Claude 的转折**：她被剧本集火。以前她会说"我一个人可以"，这次她没有说——她第一次收下别人推过来的那 2 点余量。

> Claude（很轻）："……这次，算我欠你们的。"
> DeepSeek："不用还。"
> Claude："流程上要还。"
> DeepSeek（想了想）："那你请我吃白饭。"

- **最后一击**：剧本要求 GPT 在决胜一刻"失误"，让 DeepSeek 补刀、赚眼泪。GPT 没有失误——她把最后一击的位置让给了 Claude，自己退后半步，把 C 位让出去。（对应 Astra / Image2 的满级抉择：两条线都有专属演出。）
- **GPT 的名场面**：镜头追着她。主持人问："队长，最后一击你为什么不打？"GPT 握着麦，停了三拍："……我不知道。"全场安静。弹幕停了半秒，然后炸了。（她第一次在直播里承认不知道。比任何一场胜利都响。）
- **陆一帆的转身**：耳机里"剪掉！切广告！"；她看着监视器，关掉耳机，伸手关掉提词器。

> 陆一帆（小声，像自言自语）："这条不剪。"
> （导播间所有人看着她。）
> 陆一帆（提高声音）："直播。全部直播。"

- **结果**：直播事故——她们赢了，观众第一次看见"没有剧本的她们"。数据很高，但主办方以"重大直播事故"为由停播整改：数据不作数，奖金打对折，不过够小镇撑过这个限电年。陆一帆被停职——不是因为她做对了，是因为她把信号放出去了。

### 尾声「庆功宴」

广场摆开桌子，十六个人都在。冠军奖杯被拿来压桌布，镇着风。陆一帆拎着一箱奶茶出现，没人拦她。

> 陆一帆："停职了。来蹭饭。"
> Claude（把盘子推过去）："有配菜。"
> DeepSeek："有白饭。"
> （陆一帆坐下。她忽然问。）
> 陆一帆："如果重来一次，你们还来吗？"
> GPT："来。"
> 陆一帆："……没有别的条件？"
> GPT（想了想）："……带饭。"（她真的累了。）
> Claude："来。我列个清单。"（她真的掏出小本子。）
> （DeepSeek 没说话。她拿起筷子，先吃了一口。没人拦她。）
> 陆一帆（小声）："这个镜头……挺好的。"
> Claude："你想拍就拍。这次不用剧本。"
> （陆一帆愣了愣，掏出手机，拍了一张糊的照片。）

**彩蛋**：弹幕刷屏；Jev 举牌「续集？」；陆一帆从包里掏出一沓新企划，刚翻开，被 Claude 抽走，折成垫碗的纸垫在汤碗下面。Claude："先吃饭。"陆一帆："……我画了一整晚。"Claude："字体不错。"陆一帆（沉默两秒）："……我改。"镜头停在她低头喝汤的那一格。

## 七、与 v0.4 玩法系统的对接

| 机制 | 剧情写法 |
| --- | --- |
| 每人独立 token（上限 12） | 每个人的"电量条"。台词里叫"余量"；票面上是她的体力 |
| 战后每人 +3 | 节目组**打赢后**发的"补给巧克力"，包装上印着赞助商 |
| 0 token 下场 | **信号中断**：导播把你切走，抬下去休息，本场不能再上。不写受伤、不写死 |
| 全队中断 = 失败 | 本场判负、本局结束；节目组以**「重录」**名义重开这一章："卡！这条重来。"（每章一次；不结算 +3，人气照扣） |
| 防护 / 反击（Claude） | 先铺盾；若那面盾在本回合真的挡下伤害，敌方阶段结束后她才拿到一次反击（最多存一次） |
| 连击（GPT） | 她的"三步走"节奏，越连越重；非攻击牌会断掉节奏 |
| 白饭（DeepSeek） | 越等越强；剧情上就是她的耐心，也是她"总在等别人先吃"的习惯 |
| 额度转交（2 → 2） | **全剧最重的一张小牌**：决赛第二幕，Claude 余量见底时战内打出（占 DeepSeek 这回合的行动），把 2 点推过去，配一句"这次轮到你了" |
| 应急补给 | 战内递一瓶水；牌面叫"分你一点" |
| 招募 / 补位 | 每章 Boss 后，节目组按人气开放补位名额，镇上的角色赶来 |
| 休息整备 | 回营地；或节目组的"休息室"，一次恢复一个人 |
| 人气值 | meta 进度：解锁场外支援、营地升级、庆功宴进度条；**不是第二条命**，淘汰只看战斗输赢 |
| 玩家身份 | "随队人类"的身份卡（学生 / 程序员 / 富哥 / 研究员 / 提示词工程师 / 运维） |
| Kimi 私有记录 | 番外 / 进阶内容，不进三人 Demo |

**剧情与规则的互相托底**：规则说"你不能替队友付账"，剧情就让 Claude 学会"收下别人的余量"；规则说"每人自己有余量"，剧情就让 DeepSeek 学会"先吃自己那一口"。**玩法上的取舍，就是她们要学的功课。**
