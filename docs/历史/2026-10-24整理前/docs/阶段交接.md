## 2. 本阶段最重要的五个结论

1. **token 兼生命值不能按字面执行。** "支付到 0 即失败"会让单人局 3–5 费强力卡变成自杀按钮。建议改为断电模型（Q1 / D-01）：支付可以把 token 用到 0 并进入"断电"，**只有受伤把 token 打到 0 才判负**。
2. **"每战回满"与"休息回血"只能留一个有效。** 两者并存时休息节点永远是最差选项。建议保留每战回满（Q2 / D-02），休息改做**提升初始 token 上限 / 删卡 / 插件**，回答"要不要用今天换明天"。
3. **窗口不能同时当容量和负荷。** 原稿两种读法都会失效（载满即过载 / 单人永不触发）。建议拆成 **W（载入容量）与 L（本回合已执行张数）**（Q4 / D-04），费用 = 卡面 + max(0, L − 上场人数)。
4. **卡的结局必须一次说清。** 未用牌回卡组底、打出牌进缓存不可再打、缓存上限 4 溢出进遗忘区（Q5 / D-05）；遗忘区 ≠ 离线区，**遗忘不可回收**（D-07），这是"牌越用越少"的紧张感来源。
5. **角色稿不能反向改共享规则。** 68 条冲突里没有一条需要动 R-01/R-02/R-08/R-12；全部以"改角色表述"收口（X-12~X-19）。特别是 DeepSeek 的"插件不限量"与 Claude 的"窗口税"必须作废，否则共享资源会被单角色掏空。
