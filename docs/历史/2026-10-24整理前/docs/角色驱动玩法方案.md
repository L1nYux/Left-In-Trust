# 算力回廊角色驱动玩法方案

> **v0.3 历史方案，角色差异原则继续保留。** 当前规则见 [独立 token 与跨战斗玩法方案](独立Token与跨战斗玩法方案.md)。2026-10-24 用户明确改为个人 token 与跨战斗保留，因此本文的共享余额、共享防护、每战回满及休息不回血不再执行；各角色技能以新方案 §5 的个人版本为准。

版本 v0.3　日期 2026-10-23

**主玩法改为直观的小队回合制卡牌战斗，主要变化由角色提供。** 玩家先学会看敌人意图、出牌、攻击和防御；换一个角色，才学一种新的打法。缓存接力保留为 Kimi 的专属玩法，不再要求所有角色、卡牌和敌人围绕记录运行。

用户已明确提出“公共玩法简化、特色转向各角色不同玩法”的方向。下列具体角色分配、数值和规则是据此制定的试验默认，尚非平衡定稿。本文是当前制作入口，替代 v0.2 的全队记录方案；原 Word 与旧方案保留供溯源。

## 1 玩家最先学到什么

开局教学只讲四件事：

1. **token 是全队的生命，也是付费卡的费用。** 归零失败，支付后须至少留 1。
2. **每回合抽 5 张牌，每名上场角色行动一次。** 可以出一张可用牌，或免费基础攻击、防御。
3. **敌人的攻击提前显示。** 防御提供本回合防护，先抵挡伤害，剩余伤害扣 token。
4. **角色各有一种拿手玩法。** 先只学当前角色的一条能力。

一回合就是：**看意图 → 抽牌 → 安排每人一次行动 → 敌人行动**。

不再在开局教学里解释分析生成校验、缓存接力、压缩、检索、遗忘顺序、温度滑块、窗口负荷、离线调用或热插拔。未选择相应角色时，界面不显示该角色的专属状态。

## 2 公共战斗规则

### 2.1 保留与移出

| 项目 | v0.3 的处理 |
| --- | --- |
| 全队共享 token，角色无独立血条 | 保留 |
| 每角色每回合一次行动，最多三人上场 | 保留 |
| 共享手牌与通用卡、角色专属卡 | 保留 |
| 分支地图、战斗奖励、招募、升级与插件 | 保留，服务角色构筑 |
| 全队缓存、记录配方、压缩检索截断 | 移出公共战斗，记录玩法只由 Kimi 专属卡承担 |
| 窗口 W、负荷 L 与递增费用 | 首轮取消；“提示词窗口”只作为普通手牌区的主题称呼 |
| 全队调温 | 首轮取消；未来可成为风险型角色的独立机制，当前不另做该角色 |
| 全队离线调用、战斗中热插拔 | 首轮暂缓；只在战斗外编队 |
| 身份主动技能与身份成长 | 首轮暂缓，避免开局先学一套玩家技能；原设定保留 |
| 协议值、完整提示词链、进化 | 继续暂缓 |
| 公共测试题 | 不作为常规敌人的通用规则；Boss 用直观意图与阶段变化，不要求特定角色机制 |

这轮会改动此前“非传统抽弃循环”的方向，也会暂缓部分已列入范围的系统；这是对用户最新设计方向的显式调整，不继续把旧系统换个名字放进公共规则。

### 2.2 抽牌与出牌

- 使用常规的**抽牌堆 → 手牌 → 弃牌堆**循环。每回合自动抽 5 张；抽牌堆不足时洗入弃牌堆继续抽，没有牌则少抽，不弹出额外操作。
- 回合结束时未用手牌进入弃牌堆。普通牌打出后进入弃牌堆；只有卡面明写“消耗”或特定角色机制才会把卡移出本场循环。
- 任意未行动角色可先行动，行动顺序由玩家安排；暂不做角色速度排序。敌人在全员完成或玩家结束回合后行动。
- 通用卡由任意未行动角色使用；专属卡仅由绑定角色使用。出一张牌即用掉该角色一次行动，没有全队额外出牌次数。
- 战斗开始时，仅把通用牌和本场上场角色的专属牌放进抽牌堆，替补角色牌不参与抽取。战斗中不能换人。
- 已抽到但所属角色已经行动的牌可以保留到回合末，再正常弃置；基础攻防始终可用，不因缺少专属牌卡死。

### 2.3 token 与防护

试验初始 token 改为单人 12、双人 16、三人 20，每场开始回满。不再要求玩家理解“基础值加身份带入”的计算。这些是新的数值候选，覆盖旧 3/4/5 加身份的首轮参数，不代表队伍人数曲线已经平衡。

费用只看卡面与当前角色明确的费用修正，不再随负荷递增。先检查支付合法，再执行效果；同一张牌的回复不能用于预付自身费用。

队伍共享一个**本回合防护值**。敌方伤害先减防护，再扣 token；多段攻击逐段消耗同一份防护，不能每段重复抵挡全部数值。剩余防护在回合末清零，不跨回合积攒。防护是当回合效果，不是第二种出牌货币。

基础攻击免费造成 3 伤害，基础防御免费提供 3 防护，均消耗角色行动。首批公共卡数值用于建立清晰对照：

| 卡牌 | 费用 | 效果 |
| --- | --- | --- |
| 标准指令 | 1 | 对一名敌人造成 6 伤害 |
| 防护指令 | 0 | 获得 4 防护 |
| 强力指令 | 2 | 对一名敌人造成 10 伤害 |
| 额度回收 | 0 | 恢复 3 token，不超过本场上限 |

“攻击、防御、辅助”只是功能分类，帮助角色判断动作；不是所有玩家必须记忆的配方标签。基础动作与卡牌触发能力的范围在每名角色规则中明确。

### 2.4 敌人承担直观压力

普通敌人先用攻击、蓄力、护甲、召集等可直接预览的行为。只有卡面和意图明确写出的效果才结算，不暗查玩家是否完成某种记录配方。

验证敌人使用 22 生命：第 1–3 回合攻击 3，第 4–6 回合攻击 4，此后每 3 回合加 1。伤害变化提前显示，用已有回合计数，防止免费防御或回收一直拖延。其他敌人须各自验证，不照搬这一脚本便声称已平衡。

Boss 可以出现“下一回合重击 8”“护甲被打破后虚弱”等公开变化；每名开局角色都要能靠攻击、防御和自身机制处理。不设置“没有 Kimi 的记录就无法破盾”之类硬门槛。

## 3 三名首轮角色要玩出三种节奏

每名角色只保留一个核心被动及一处专属状态显示。其余卡牌和插件强化这条路线，不继续堆第二套计量条。下列能力覆盖旧规则基准 §4.3 的建议分配，角色性格与美术不改。

| 角色 | 一句话玩法 | 核心决策 | 显示内容 | 入门复杂度 |
| --- | --- | --- | --- | --- |
| GPT | 连续出攻击牌，越打越强 | 继续付费进攻，还是中断连击保命 | 连击 0–2 | 低 |
| Claude | 挡住攻击，再用反击还手 | 什么时候防御能把敌方攻势转为收益 | 反击就绪图标 | 低 |
| DeepSeek | 先运营几个回合，存满白饭打一轮重击 | 现在用强牌，还是等蓄力满再兑现 | 白饭 0–3 | 中 |

### 3.1 GPT 连续进攻

**标准答案：** 出攻击牌时，按已有连击层数，每层使本次对一名目标的一段直接伤害 +2；之后连击加 1，最多 2 层。打出非攻击牌、使用任意基础动作或未行动便结束回合时，连击归零。受到伤害本身不打断连击。

第一张攻击牌无加成，第二张 +2，第三张起 +4。基础攻击不吃连击，也不能免费续连击。

这名角色鼓励在 token 允许时压进攻，而不是交替使用三种记录。防御和回收牌是能救命但会断连的选择，奖励应让玩家取舍，不能把每张牌都改成“攻击并回复”来消除这一代价。

卡牌分支可以是“更省费用，便于持续攻击”与“单次重击更强”。插件先强化连击收益或降低续攻成本，不额外引入模式切换或记忆槽。

### 3.2 Claude 防守反击

**对齐反击：** 本回合 Claude 用防御牌或基础防御贡献了正数防护，且队伍防护实际抵挡过敌方伤害，则在敌方阶段结束后获得一次“反击就绪”。下次自己的攻击，包括基础攻击，对一名目标的一段直接伤害 +4，随后清除；最多存一次，不叠层。

只由队友防御、Claude 没参与时，不获得反击。敌人没有攻击，或者敌人已被提前击败，也不凭空获得反击。已有反击时再次防御可以保留它，不能存第二份。

她可以用基础防御和基础攻击完成核心循环，防止牌序卡住角色玩法。专属防御牌提高保护效率，攻击牌提供更好的反击兑现。

合作收益来自她保护共享 token，让队友放心输出。队友不需要执行“校验”配方，也不获得她的反击状态。

### 3.3 DeepSeek 蓄力爆发

**白饭：** 每个自己在场的回合结束时获得 1 层白饭，最多 3。满 3 层时，下一张卡面费用至少为 2 的攻击牌自动消耗全部白饭，使其对一名目标的一段直接伤害 +6。

低费牌和基础动作不消耗白饭。实际费用被减免也不改变卡面费用门槛。第一回合开始为 0，最快在第四回合出手时满层；战斗结束清零。

她前几回合可以用低费输出、防御或回收运营，也可以提前打强牌应急，代价是暂时用不到满层强化。专属牌确保每个初始牌组有足够的高费攻击来源，但抽不到时仍可正常作战；不能只靠白饭才能造成有效伤害。

与 Claude 的区别是，白饭不要求挡住攻击，也不要求先防御；与 GPT 的区别是，使用运营牌不会失去成长。女仆形态先实现，大肥鲸形态与额外插件槽规则继续留在后续范围。

## 4 Kimi 独有的缓存接力

### 4.1 为什么分给她

现有 Kimi 性格稿包含“读完再判断”“长文本梳理”“这一页我记得”等设定，把保留记录与后续调用交给她较为贴合。这是本轮机制分配建议，不是对现实模型能力的评价，也不覆盖原角色性格稿。

Kimi 定位为喜欢提前规划的进阶角色。她**不加入本轮三人 Demo 的制作数量**，先保留完整专属规则，作为之后单独验证的候选。不能为了安置旧机制，把三人范围自动扩成四人。

### 4.2 私有规则

核心被动名为“读完再答”。她有两个私有记录槽，每槽存放一张已经用过的 Kimi 专属普通卡。只有她的专属卡标有分析、生成或校验；通用牌与其他角色牌没有这些接力标签。

1. Kimi 打出自己的普通专属卡后，该实体卡进入自己的记录槽，而非公共弃牌堆。
2. 记录从下一回合起可用。她再次使用自己的专属卡时，可以消耗一个匹配记录强化当前行动；也可不消耗，按基础效果出牌。
3. 消耗记录时，旧实体卡进入本场消耗区，不能被普通洗牌或角色换阵恢复。当前专属普通卡成为新记录。
4. 两槽已满时，先消耗选中的旧记录，再放新卡；若仍满，则最旧记录回到公共弃牌堆，不免费复制，也不永久锁住卡。
5. 通用牌由 Kimi 使用时依然正常弃置，不产生或消耗记录。其他角色不能读取、生成或消耗她的记录。
6. 明写“消耗”的 Kimi 专属强力卡可以使用旧记录，但自身结算后进入消耗区，不生成新记录。
7. 记录、弃牌和消耗区互斥，同一张实体卡只存在于一个位置。每场开始记录槽为空，战斗结束恢复局内牌组。

这里沿用旧玩法的“提前准备、消耗旧记录、强化下一步”，同时把影响限制在她自己的专属卡。满槽溢出改为回弃牌，防止未主动接力时也不断损失她的整套牌。

### 4.3 专属配方

| 她消耗的旧记录 | 她当前的专属卡 | 额外效果 |
| --- | --- | --- |
| 分析 | 生成 | 对一名目标的一段直接伤害 +3 |
| 生成 | 校验 | 结算时恢复 1 token，上限内 |
| 校验 | 分析 | 当前牌费用 −1，最低为 0 |

接力减费与其他减费取较高一项，不相加；先根据合法记录算最终费用，检查支付后仍有 1 token，再提交支付与记录消耗。不能把生成→校验的回复当作预付费用。

例子：第一回合 Kimi 使用“通读”并留下一份分析记录。第二回合她的“落笔”原本伤害 6，选择消耗分析后打 9；队友仍只进行普通攻防。她也可以留下分析，先用其他牌应对敌方重击。

### 4.4 复杂度到此为止

本版 Kimi 只做记录，不同时增加个人电量、分身独立行动、排队、高峰期、读透层数和温度调节。这些可以保留在台词、表现和未来分支里，不能与记录一并成为首轮必学规则。

移除 Kimi 后，玩家界面只剩普通抽牌、token、防护与在场角色自己的状态。没有任何敌人、通用插件或常规奖励要求她在队。

## 5 角色搭配产生组合变化

搭配先通过易理解的结果发生，不设计跨角色专属配方表：

| 组合 | 为什么能配合 | 保留的取舍 |
| --- | --- | --- |
| GPT 与 Claude | Claude 挡伤害，GPT 更容易持续进攻 | 两人共享 token，GPT 的连击并非无限免费输出 |
| Claude 与 DeepSeek | Claude 争取回合，DeepSeek 等待满层重击 | 防守过久会遇到更强的敌方意图，需要决定爆发时机 |
| GPT 与 DeepSeek | GPT 提供前期压力，DeepSeek 在后期收尾 | 两人的付费输出会争夺 token，仍要留运营手段 |
| Kimi 与任意角色 | Kimi 自己准备记录，队友按本来玩法行动 | 队友提供防护或伤害即可，不必帮她凑分析生成校验 |

所有角色的技能只改变自己的行动或明确写出的共享结果，不暗中给队友加个人资源管理要求。不靠固定两人组才能启动任何角色的基本玩法。

## 6 肉鸽成长如何服务角色

### 6.1 开局与招募

先选一个开局角色并显示一句玩法介绍。默认从 GPT 开始，Claude 与 DeepSeek 按原招募方向逐步解锁。首轮不额外选择身份，也不先讲离线队员。

Boss 后保留招募或微调。招募新角色先提供两张基础专属卡，每张可以加入或一对一替换；其余进入后续奖励池。专属卡只随上场角色进入战斗牌库，不让替补卡造成无法使用的手牌。

跳过招募仍暂用升级两张现有卡，不承诺它与增加一个行动者等强。两者强度比较需流程试玩，不能用单人夹具代替。

### 6.2 奖励与升级

常规三选一卡牌允许跳过。先按当前在场阵容提供相关专属卡与通用卡，不发只能由不存在角色使用的卡，也不把 Kimi 的分析记录卡伪装成通用牌。

| 角色 | 一条升级方向 | 另一条升级方向 |
| --- | --- | --- |
| GPT | 提高连续输出效率 | 降低攻击卡费用，更易维持连击 |
| Claude | 提高单次防护 | 提高反击兑现的伤害 |
| DeepSeek | 增加满层爆发 | 提高低费运营牌的效率 |
| Kimi 后续 | 提高专属记录收益 | 提高不接力时的基础效果，减少对牌序依赖 |

首轮每张卡先只做普通升级；分支升级作为后续内容，不为每个角色同时做满两套分支。插件每人最多一个，沿同一核心能力变化，不发第二种独立玩法条。

休息用于升级、删卡或调整阵容；不做战间回血，因为下场本就回满。宝箱、商店、事件均复用原类型，先砍内容数量，不补回被移出的公共系统。

## 7 制作范围与验收

### 7.1 下一份原型

仍先做单人固定战斗，默认 GPT，不先接入 Kimi。随后在相同公共框架下替换成 Claude 与 DeepSeek，检查角色是否改变出牌节奏，再串三角色短章。三人 Demo、两短章等内容上限不扩大。

验证用小牌组只有前述四种通用卡，正式原型仍须补齐既定的 12–16 种卡牌内容；Kimi 的私有记录可以另做规则夹具，但不因此增加 Demo 角色数。

### 7.2 需要检查的结果

- 没有 Kimi 时，游戏不生成记录、不出现记录 UI，也不调用记录配方。
- 公共战斗在关闭所有角色被动时仍能用合理攻防序列获胜；无需依靠记录弥补整个公共数值预算。
- 三名角色分别有可复现的连攻、防反、运营后爆发序列，且都能单人进行基础战斗。
- Kimi 只能使用自己上回合及更早的专属记录，队友和通用牌不能读写；接力不额外行动，不复制实体卡。
- 防护逐段扣除并在回合末清空；费用、回复和失败按明确顺序结算；洗牌不会重置角色连击、反击或白饭。
- 无可用牌也能基础攻防；全防御、反复回收不能无限无损等待。

### 7.3 试玩要回答什么

真正要测的是“换角色后，我是否愿意换一种打法”，包括 GPT 什么时候断连、Claude 是否主动寻找反击窗口、DeepSeek 是否会规划满层强牌。胜率、回合数和陌生玩家理解程度均需试玩；不能因为三个角色都能通关就声称特色已经成立。

缓存接力是否有趣继续作为 Kimi 的专项问题，不再是全队主玩法必须通过的门槛。新夹具说明与验证边界见 `docs/角色玩法推演.md`；v0.2 的八组接力结果只证明旧方案中的局部数值，不适用于本版公共玩法。
