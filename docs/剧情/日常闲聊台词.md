# 日常闲聊台词（重复游玩版）

玩家第一次遇到某个剧情节点时，完整播放正式场景（见 `Demo剧情脚本.md`）。重开、换任务、换人生阶段再走同一节点时，正式场景不再重播，改由本文件的闲聊池抽一句顶上。

这些句子只负责「人在旅途里的日常」，不承担交代、不埋伏笔、不解释规则、不给知识、不改数值。它们让重复游玩仍然像在看这三个角色的日常，而不是对着同一张任务单干等。

## 播放规则（接入时按此实现）

1. **门槛**：某节点 + 某角色的正式文本已播放过（本地「已看」标记），下次到同一节点时该角色从闲聊池说话。
2. **抽取**：先抽该角色在当前节点语境（`context`）下、这一局还没说过的句子；抽完再从头循环。同一句在一局内不重复。
3. **人数**：只从在队角色里抽。未招募不抽；0 token 的角色不在队内，不参与闲聊。替补席上 token 为正的角色可以回应，但只从 `idle` 池取。
4. **句数**：一个节点最多 2 句（可以是两人各一句），战斗节点最多 1 句。闲聊说完即进入操作，不阻塞任务单、抽牌、存档与重试。
5. **不替换固定台词**：Boss 固定台词、胜负提示、结局三句收束、系统终端文字仍走正式文本；闲聊只补「场景重播」被省掉的那一段。
6. **跳过**：跳过只跳演出，闲聊不额外给东西；玩家开着「跳过已读」时，闲聊仍可显示（它是重复游玩的唯一新内容），也可以整段关掉。
7. **同伴互动**：`context: any` 的池在任何节点都可抽，优先在「同节点两人都在队且都已看过」时使用；队里没有对应 `target` 时不抽。

## 与正式剧情的关系

- 正式剧情唯一来源：`docs/Demo剧情脚本.md`（v1.0，117 个事件）。
- 本文件只服务重复游玩；不含任何事件头、不参与剧情覆盖校验。
- 角色声线与禁区沿用 `docs/剧情/00_创作基准.md` §8：只按「对方这个角色」说话，不预知私人暗线；不给事实、不推进剧情。

## 编写与维护

- 草稿源：`_build/chat_drafts/`（`GPT.md` / `Claude_pool.md` / `DeepSeek.md`），格式要求见 `_build/chat_drafts/00_闲聊格式与要求.md`。
- 改写草稿后重新拼装与校验：

```
node _build/assemble_chat.cjs
node _build/validate_chat.cjs 2>&1 | Tee-Object _build\chat_validation.log
node _build/assemble_chat.cjs
```

- 校验器同时导出运行时文件：`docs/剧情/日常闲聊台词.json`（`node _build/validate_chat.cjs --json docs/剧情/日常闲聊台词.json`）。
- 新增角色：在草稿目录加一份同名文件、在 `validate_chat.cjs` 的 `CHARACTERS` 与 `DEFAULT_FILES` 中登记，并补齐每个 `context` 的自白与同伴互动。
