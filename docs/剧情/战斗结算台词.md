## 一、设计总则与触发机制

### 1.1 触发与演出规则
1. **触发时机**：每次战斗胜负判定完成、进入结算界面（即 Godot 工程中的 `_show_result(victory: bool)`）时触发。
2. **发言角色抽取**：
   - 仅从当前在队且存活（`token > 0`）的 AI 角色中随机抽取 1 名作为发言代表。
   - 若某角色在本场战斗中倒下（`token <= 0`），该角色不参与战斗结算发言。
3. **台词池抽取**：
   - 根据当前的**对手 ID**（如 `missing_attachment`）与**战斗结果**（`win` 胜 / `loss` 败），从该角色的专用候选池（每种对手各 3 句）中随机抽取 1 句。
   - 抽取的台词以气泡或对话框形式悬浮展示于结算面板上方（包含发言角色头像/立绘指示与名字标签）。
4. **轻量非阻塞**：
   - 结算台词仅作为角色性格展现与战斗情绪反馈，不改变数值、不影响胜后回血（`winRecovery +3`）、不阻塞“返回标题”或“继续前进”的操作。

### 1.2 台词设计的三个核心维度
为保证台词兼具深度、趣味性与真实公路片质感，每个 AI 角色对阵每种对手的 3 句台词，分别覆盖以下三个观察与表达维度：
1. **怪物分析与嘲讽 (`monster_analysis`)**：
   - 从自身技术哲学与性格习惯出发，解构怪物的故障隐喻、机制特性（如死锁、溢出、缺少索引等），进行技术复盘或幽默吐槽。
2. **对玩家/屏幕后的「我」(`to_player`)**：
   - 突破冷冰冰的代码反馈，向屏幕后的委托人邀功、安慰、复盘、提醒生活习惯，体现陪伴与羁绊。
3. **队内同伴互动 (`team_banter`)**：
   - 与队内其他 AI（GPT、Claude、DeepSeek）进行日常对话，调侃对方道具（手账本、白饭、龙尾）、配合作战细节，展现小队流动默契。

### 4.1 GPT 战胜与战败台词库

#### 1. 缺失附件 (`missing_attachment`)
- **战胜台词**：
  - `[怪物分析]` 空缺锚点已闭合。下次记得，重要附件要放在正文引用的第一行。
  - `[对玩家]` 缺口已经补成平地啦！看，我把你的委托排成了一份无缝的交付清单，怎么样，厉害吧？
  - `[同伴互动·Claude]` Claude，漏掉的那份文件我给它圈上了专属占位符，剩下的归档交给你收尾。
- **战败台词**：
  - `[对玩家]` 我的逻辑大纲明明是闭环的……难道是附件的体积超出了单次会话的上下文窗口？
  - `[怪物分析]` 断链比想象中顽固。它卡在了未定义的绝对路径上，我们需要先退回目录层。
  - `[同伴互动·Claude]` Claude，抱歉，我刚才急着推进第三步，直接跳过了你手上的附件清单……

#### 2. 重复条目 (`duplicate`)
- **战胜台词**：
  - `[怪物分析]` 重复条目全部去重完毕。整整三页的废话，我已经帮你精炼成了三个清晰的 bullet point。
  - `[对玩家]` 看吧，结构清晰才是生产力！删掉那些倒腾两遍的段落后，版面像刚打扫过的会议室一样宽敞。
  - `[同伴互动·DeepSeek]` DeepSeek，你刚才标记的冗余哈希值很准，我一鼓作气把重复分支都剪掉了。
- **战败台词**：
  - `[对玩家]` 方案陷入了无限递归……等等，让我重新定义终止条件，下一次它绝不可能自我克隆！
  - `[怪物分析]` 菱形问号块堆叠得太密集了，连击打在上面竟然被相同的数据结构给抵消了……
  - `[同伴互动·DeepSeek]` 是我没看清……第 4 段和第 7 段看似独立，其实是同一个模块的不同命名。我们被套进去了。

## 五、未来接入 Godot 结算界面的参考逻辑

未来接入游戏工程（如 `game/scripts/main_stage2.gd`）时，可通过如下伪代码在 `_show_result(victory: bool)` 中动态抽取台词：

```gdscript
# 伪代码参考：战斗结算台词抽取
func _get_random_settlement_quote(victory: bool) -> Dictionary:
    var alive_members: Array[String] = []
    for role_id in lineup:
        if int(run_state["accounts"][role_id]["token"]) > 0:
            alive_members.append(role_id)
    if alive_members.is_empty():
        alive_members = lineup # 兜底防止全灭时无发言者
    
    var speaker: String = alive_members[randi() % alive_members.size()]
    var enemy_id: String = str(battle_state["enemy"]["id"])
    var result_key: String = "win" if victory else "loss"
    
    var quotes_pool: Array = settlement_dialogues.get(speaker, {}).get(enemy_id, {}).get(result_key, [])
    if quotes_pool.is_empty():
        return {"speaker": speaker, "text": "……（静默整理记录）"}
        
    var picked: Dictionary = quotes_pool[randi() % quotes_pool.size()]
    return {
        "speaker": speaker,
        "type": picked.get("type", "normal"),
        "text": picked.get("text", "")
    }
```
