# 《未尽之托》Demo 卡牌插画设计方案

版本：v4.0（角色色调区分版）  
日期：2026-10-27  
适用范围：基础 Demo 首批 12 张核心卡牌 + 2 张基础动作常驻卡  
上一版归档：[卡牌插画设计方案_v2_紧凑高密度版.md](归档/卡牌插画设计方案_v2_紧凑高密度版.md)

## 一、重构目标

v4 延续 v3 的“AI 处理问题小剧场”，进一步把角色专属牌的主色直接对齐角色立绘，让同一手牌中的角色归属不依赖卡名或角标也能辨认。

1. 一张牌只讲一个主要处理动作，主体控制在 3—5 个大形状内。
2. 先让玩家看懂“输入—处理—结果”，再补材质与气氛。
3. 普通攻击、保护、回复和转交不使用爆炸、撞击、风暴与武器式构图。
4. 只有 H、G2、S2 可以有明显冲击力，但冲击必须收束成一条动作线和一个目标。
5. 角色专属牌允许出现立绘的局部元素；不把角色整身硬塞进卡面。
6. 专属牌形成三套互不混淆的主色族：GPT 冷白淡紫、Claude 橙黑米白、DeepSeek 深蓝青白；暖琥珀只允许作为极小的环境点光，不再覆盖 GPT 或 DeepSeek 整张卡面。
7. C1、C2 的 v2 插画保留，作为 Claude 的暖橙色族与“具体动作、明确主体、材质可信”的质量参照。

## 二、画面密度与层级

- 画幅：4:3，项目交付 1024×768。
- 缩略阅读：在 138×109 下仍能一眼认出主物件和动作方向。
- 主体：1 个；辅助物件：2—4 个；粒子原则上不用，确有需要时只做少量点缀。
- 线条：避免满屏网格、刻度、细密排线、同心圆阵列和重复机械结构。
- 背景：允许存在安静区域。留白用于分层，不等于空洞。
- 光效：以宽光带、软边高光和单次状态变化为主，不使用粒子喷发填空间。
- 叙事：优先展示分类、排序、比较、过滤、校正、压缩、转交、积累与兑现。

## 三、角色视觉元素

| 角色 | 可进入卡面的立绘元素 | 使用边界 |

| GPT | 珍珠白、淡紫、柔蓝；白紫袖摆、浅色龙翼边缘、指尖蓝云 | 以手、袖、云朵参与处理流程；金橙只作不超过 3% 的点光，不必出现完整人物 |

## 五、生产提示词骨架

每张图使用以下统一约束，再叠加上表中的画面核心：

```text
Use case: stylized-concept
Asset type: final 4:3 in-game card illustration, 1024x768 delivery.
Primary request: show one concrete AI problem-solving operation with a clearly readable input, process, and result.
Style/medium: polished 2D anime game illustration, tactile materials, broad clean shapes, restrained science-fiction glow.
Composition/framing: one dominant action, 3-5 major shapes, moderate visual breathing room, readable at 138x109 thumbnail size.
Constraints: low line density; no micro-grid carpet, dense annotations, particle swarm, debris storm, repeated mechanical detail, UI frame, border, title, readable text, numbers, or watermark.
```

角色专属牌追加对应立绘为身份参考，并明确只继承服饰、手部、道具和色彩线索，不复制整张立绘构图。H、G2、S2 可追加 `strong but controlled`；其他牌追加 `problem-solving rather than combat`。

## 六、验收标准

- 14 张缩小后都能用一句话说清“AI 正在做什么”。
- 除 H、G2、C2、S2 外，不出现可被理解为爆炸、劈砍、冲撞或灾难的主动作。
- 任一卡图不依赖细密线条才能成立；关闭粒子与小装饰后，主体关系仍完整。
- G1/G2、S1/S2 能通过立绘局部元素识别所属角色；C1/C2 保持 Claude 的橙金书册体系。
- 将六张专属牌缩到同一手牌尺寸后，即使遮住卡名与右上角归属标记，也应能只凭色族区分：GPT 为冷白淡紫、Claude 为橙黑米白、DeepSeek 为深蓝青白。
- 卡面不内置卡名、数值、说明文字或 UI 边框。
- v2/v3 文件完整保留，游戏映射仅切换到验收后的 v4 角色色调文件；未改动的通用牌与 Claude 牌继续使用原版本。
