# Demo 地图与 Boss 接线

日期：2026-10-26。

## 目标

在不修改 v0.5 规则和数值的前提下，把已有战斗切片补成可理解的第一章 Demo 路线，并让三名角色、普通怪、Boss、战斗场景与战斗 UI 全部进入真实主流程。

## 已实现

- 常规委托流程改为：编队 → 路线图 → 普通战 → 路线图/可选休息 → Boss → 结算。
- 路线图使用正式纸页旷野背景，三个节点的可用/完成状态由运行时数据决定。
- 角色选择页改用 GPT、Claude、DeepSeek 正式透明主立绘。
- “本次提交版”接入正式透明 Boss 主立绘；“缺失附件”继续使用六层正式怪物资源。
- 地图流纳入真实存档校验；战前地图允许尚无 `battleState`，战后地图保留上一场完整状态。
- 自动流程、UI 流程、真实按钮点击和分层美术测试同步覆盖地图与 Boss 接线。

## 范围边界

本轮没有新增动作、音效、对白、角色互动、闲聊或结算台词；没有实现商店、招募、收藏、第二章和挑战入口。既有轻量动作控制器仅保留，不作为本轮新增交付。
