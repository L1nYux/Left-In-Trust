# UI 战斗界面阶段 B 记录

日期：2026-10-25。

## 本轮完成

- 将战斗画面从纵向状态面板改成固定 1280 × 720 的场景化对峙布局。
- 支持单人、双人和三人的场中站位；角色状态条贴近各自单位。
- 将所有可用卡牌放入唯一的共享手牌区，保留抽牌顺序，不按角色分组。
- 通用牌使用中性归属，沿用当前行动者；专属牌显示角色色和角色名，并在点击后自动选择所属角色。
- 点击场中角色时，未选牌状态选择行动者；已选友方牌状态优先选择合法目标。
- 新增轻攻击、重攻击、防护、支援和转交动作标签；执行后由对应角色进行短暂前移或抬升再回位。
- 卡牌从文字按钮改为包含费用、归属、程序绘制插画、牌名和主要效果的完整卡面。
- 新增纸页战场、缺失附件和本次提交版的占位 SVG；现有参考原图没有复制进游戏包。

## 规则边界

本轮只重构显示和交互，没有修改费用、伤害、防护、回复、抽弃牌、角色被动、敌人意图、结算、存档或随机数规则。

- `test_ui_clicks.gd`：重复 12 次真实按钮信号流程，覆盖选择两人、基础攻击、确认执行和结束回合。
