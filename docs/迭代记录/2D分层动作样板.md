# 2D 分层动作样板记录

日期：2026-10-25。

## 完成内容

- 以 GPT 建立可复用的 `LayeredActor2D` 母版；Claude 与 DeepSeek 使用轻量场景变体，不复制控制代码。
- 统一八层结构：`shadow / aura / back / body / head / prop / front / effect`。各层可独立位移、旋转、缩放和替换透明素材。
- 统一六类动作标签：`basic / light_attack / heavy_attack / guard / support / transfer`，直接承接现有卡牌 `motion_tag` 映射。
- 三名角色共用动作时序，但保留不同动作语言：GPT 为分段轨迹，Claude 为书页与书签护框，DeepSeek 为水纹与鲸尾弧。
- 待机、选中、已行动与下线状态均由组件自行响应；状态条和点击区域仍归战斗 UI 管理。

## 资源结构

- `game/scenes/actors/LayeredActor2D.tscn`：共享母版。
- `game/scenes/actors/GPTActor.tscn`：GPT 参考配置。
- `game/scenes/actors/ClaudeActor.tscn`、`DeepSeekActor.tscn`：共享母版的角色变体。
- `game/scripts/layered_actor_2d.gd`：动作控制器、角色参数与层级协议。
- `game/scripts/layered_actor_layer.gd`：当前程序占位层；正式美术接入时可逐层替换。

## 正式美术接入约束

正式角色图应按八层接口输出透明素材，所有层共享画布尺寸、地平线与原点。头部和道具的旋转轴需在导出前固定；动作差异继续由角色参数和特效层表达，不为同类卡牌复制整套动画。替换图形层时不得修改战斗规则、卡牌结算或状态条布局。
