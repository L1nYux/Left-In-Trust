# 战斗 UI 舞台化重构

日期：2026-10-26

## 目标

将战斗画面从面板式原型调整为横向对峙舞台：队伍与敌人首先被看见，战斗信息贴近对应对象，共享手牌成为底部主操作区。参考图仅用于构图、比例、层级和交互密度，不复制其人物、背景或品牌元素。

## 当前布局

- 顶部：54 px 半透明状态栏，左侧显示回合，中部为进度轨道，右侧保留轻量状态锚点。
- 中场左侧：1—3 名角色错落站位，取消常驻矩形人物框；点击热区仍完整保留。
- 角色脚边：姓名、token、防护与角色机制合并为紧凑状态牌。
- 中场右侧：敌方立绘放大，意图独立悬浮在上方，名称、数值和完整度条贴近脚边。
- 底部：基础行动固定在左侧；共享手牌以大插画卡重叠、轻微旋转排列；确认和结束回合独立放在右侧。
- 舞台色彩：左侧为冷青色队伍空间，右侧为红色威胁空间，中线用能量轨迹强化对峙关系。

## 保留的交互规则

- 共享手牌仍可混合三名角色的专属牌与通用牌。
- 点击专属牌仍自动切换到所属角色。
- 友方目标选择、确认执行、每名在线角色每回合一次行动的规则不变。
- 卡牌结算仍调用统一六类 2D 分层动作标签。

## 后续美术替换约束

正式角色立绘应在当前点击热区内保持脚底基线一致，可以向上和左右溢出，但不能遮挡顶部状态栏或底部卡牌标题。正式怪物应保留右侧意图与完整度条的安全区。卡牌插画需要在缩略状态下仍能靠主体轮廓和角色色识别，不依赖小字。
