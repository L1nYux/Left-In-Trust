# 未尽之托 / Left in Trust

带着一队各有脾气的 AI 少女，穿过由委托长成的世界；把有限的 token 花在出牌与承伤之间，从每次交付与失误中，拼出屏幕另一端的“我”。

2026-10-25 阶段二版。中文名为 **《未尽之托》**，英文名为 **Left in Trust**。`game/` 已包含 Godot 4.7.2 / GDScript 的 Windows 可玩切片，支持 1–2 人常规委托、三人独立测试场和带校验/备份恢复的真实文件存档。
