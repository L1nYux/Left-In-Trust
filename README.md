# 未尽之托 / Left in Trust

带着一队各有脾气的 AI 少女，穿过由委托长成的世界；把有限的 token 花在出牌与承伤之间，从每次交付与失误中，拼出屏幕另一端的“我”。

2026-10-27 Demo 垂直切片。中文名为 **《未尽之托》**，英文名为 **Left in Trust**。`game/` 已包含 Godot 4.7.2 / GDScript 的 Windows 可玩流程，支持第一章路线图、1–2 人普通战/休息/Boss 流程、三人独立测试场、共享混合手牌、三名正式角色、两名正式敌人、首章关键剧情演出，以及带校验/备份恢复的真实文件存档。

规则以 `docs/规则基准.md` 为唯一执行口径；数值与卡牌以 `docs/首批内容.json` 为唯一数据源。修改时同时更新规格与验算。角色 Markdown 为可编辑源，Word 为阅读副本；`_build/src` 为兼容旧工具的镜像，不再独立编辑。旧版剧情与玩法方案均标记历史，不叠加执行。

`docs/Demo剧情脚本.md` v1.0 含 117 个可拆文本事件（两章四任务 × 大学生 / 公司员工）。`_build/export_story_runtime.cjs` 将全量事件导出为 `game/data/story.json`；当前可玩路线已接入通用序章、第一章任务开场、普通战、核对、休息、Boss 前验收、Boss 与胜负片段。其余第二章/商店/招募/收藏事件已进入运行数据，但还没有可达入口。重新拼装用 `_build/assemble_story.cjs`，校验用 `_build/validate_story.cjs`。

已看标记随当前委托存档；演出可逐页继续或整段跳过，地图可回看最近剧情，也可从 [日常闲聊台词](docs/剧情/日常闲聊台词.md) 的 39 个池 / 100 条台词中触发“旅途闲聊”。单/双人对白只从真实在队角色中抽取。扩展身份目前保持地图外观预览，不播放阶段剧情，不会误套大学生/公司员工现实片段。
