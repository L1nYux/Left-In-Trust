## 1 通用战斗表现

### 1.1 四段力学节拍（前摇 / 发力 / 命中定格 / 回位）

| 段位 | 时长（两处原文） | 职责 | 来源 |
| :--- | :--- | :--- | :--- |
| 起手前摇 Wind-up | `0.15~0.30s`（动作设计）／`0.12~0.30s`（场景方案） | 蓄势/后撤/身体下沉/道具蓄能 | `docs/精细化战斗与日常待机动作设计.md:19,29-38`；`docs/精细化战斗场景设计方案.md:34` |
| 爆发发力 Strike / Cast | `0.10~0.20s`（动作设计）／`0.10~0.25s`（场景方案） | 突进前冲/刀刃划出/书页翻飞/海浪拍出 | 同上 |
| 命中定格 Freeze & Impact | `0.04~0.08s` | 击中瞬间顿帧，全屏局部补光 | 同上 |
| 缓冲回位 Settle | `0.20~0.35s` | 惯性缓冲/衣角摆回/收招深呼吸 | 同上 |
| 出牌前 0.0s | 选牌锁定目标 | 角色视线转入目标，道具微亮 | `docs/精细化战斗与日常待机动作设计.md:29` |

- 单次出牌全长验收：**0.75s ~ 1.15s**；快速选牌/倍速模式自动截断 Settle 尾帧（`docs/精细化战斗与日常待机动作设计.md:394`）。
- 快速连击或倍速模式缩短至 **0.5s**（`docs/Demo视听与表现设计方案.md:49`）。
- 【补充源】出牌节奏拆分：选牌与行动者响应 `0.15s`，前摇 `0.2–0.35s`，特效与命中 `0.25–0.4s`，回位 `0.15–0.25s`；连续快速操作允许 **1.5 倍速或跳过回位尾帧**（`docs/UI与战斗美术重构方案.md:96`）。
- ⚠️ 两主源的前摇/发力上限不一致（0.30/0.20 vs 0.30/0.25），见 §7 缺口 G-02。

### 1.2 八层骨架名称与职责

层级顺序（底 → 顶）：`shadow → aura → back → body → head → prop → front → effect`

| 层 | 职责 | 来源 |
| :--- | :--- | :--- |
| `shadow` 阴影 | 地面投影，承接站位与 Y-Sort | `docs/精细化战斗与日常待机动作设计.md:26`；`docs/Demo视听与表现设计方案.md:43-45` |
| `aura` 脚底光环 | 待机呼吸轻拂、战局光环（如 Claude 橙金气场） | 同上 |
| `back` 后发/披风 | 后发、披风、衣摆等后置形变 | 同上 |
| `body` 躯干/裙摆 | 呼吸沉浮、受击扭转、突进位移的主载体 | 同上 |
| `head` 面部/前发 | 对焦、微倾、后仰、表情变化 | 同上 |
| `prop` 手持道具/核心法宝 | GPT 小蓝云、Claude 典籍书签、DeepSeek 白瓷碗 | 同上 |
| `front` 前置装饰/发带 | 发带、前饰，动作中后扬/飘动 | 同上 |
| `effect` 动态技能光效 | 技能光效、粒子、护盾投影 | 同上 |

- 画布基准 `1280×720`；角色待机高度约 **280px**（占屏高 33%）（`docs/Demo视听与表现设计方案.md:43`）。
- `effect` 在工程节点中对应 `Effect (GPUParticles2D / Node2D)`（`docs/Demo视听与表现设计方案.md:367`）。

### 1.3 动作协议（GPT 母版六类）

六类统一动作标签：`basic / light_attack / heavy_attack / guard / support / transfer`（`docs/迭代记录/2D分层动作样板.md:9`；`docs/迭代记录/Demo正式分层美术与UI定稿.md:9`；【补充源】`docs/UI与战斗美术重构方案.md:194`）。每张卡配置 `motion_tag` 与 `effect_id`，同类牌复用身体动作，差异由手势、轨迹、命中特效、音效表达（`docs/UI与战斗美术重构方案.md:85`，补充源）。

| motion_tag | 时序与幅度（视听方案 §2.1） | 肢体与道具协同 | 位移/镜头 | 来源 |
| :--- | :--- | :--- | :--- | :--- |
| `Idle` 待机 | 2.4s 呼吸循环，EaseInOut | `body` 沉浮 4px；`head` 微倾 1.5°；`prop` 悬浮微颤；`aura` 慢速轻拂 | 原地，无镜头晃动 | `docs/Demo视听与表现设计方案.md:53` |
| `Basic` 基础 | 0.65s（前摇 0.15s / 释放 0.25s / 回位 0.25s） | 最精炼的单手引出或道具微展 | 前滑 20px 迅速回位 | `:54` |
| `Light Attack` 轻攻击 | 0.85s（前摇 0.2s / 冲击 0.35s / 缓冲 0.3s） | 重心前倾 12px；手臂/道具直线延伸；`front` 后扬 | 突进 45px，命中帧冻结 2 帧 | `:55` |
| `Heavy Attack` 重攻击 | 1.15s（前摇 0.4s / 爆发 0.4s / 后摇 0.35s） | 后撤蓄势下沉 8px；道具发光过载；双手爆发 | 前冲 70px，纵向轻震 2px | `:56` |
| `Guard` 防护 | 0.8s（展开 0.25s / 维持 0.35s / 收敛 0.2s） | 侧身面向保护目标；手部前推；`prop` 展开屏障 | 原地展开气场，重心下沉 | `:57` |
| `Support` 支援 | 0.9s（引导 0.3s / 传输 0.35s / 确认 0.25s） | 道具托举胸前；双手轻柔合拢；光芒流向道具 | 原地微仰，弧线光流投射 | `:58` |
| `Transfer` 转交 | 1.0s（扣除 0.3s / 跃迁 0.4s / 目标接收 0.3s） | 指尖引出琥珀 token 核心；目标低头接纳/光环升起 | 双角色视线与连线互动 | `:59` |

- 另有 3 个**战斗状态标签**（不占行动，不属于六类出牌动作）：`Hit` 受击 0.35s（受创击退 0.08s / 僵直 0.12s / 复位 0.15s）、`Offline` 下线 1.2s 单向不可逆（`docs/Demo视听与表现设计方案.md:60-61`）。
- 敌人侧标签：`idle / attack / hit` 三类（`docs/迭代记录/Demo正式分层美术与UI定稿.md:9`），但 `视听方案:94` 与 `UI重构:130` 要求**四态**（待机/意图蓄势/受击/解构退场），见 §7 缺口 G-09。

### 1.4 受击 / 招架 / 下线脱力

主表（动作设计 §2.4，`docs/精细化战斗与日常待机动作设计.md:122-127`）：

| 状态 | 动画曲线与层级形变（body / head / prop） | 粒子与着色反馈 |
| :--- | :--- | :--- |
| 轻受击 Light Hit | 整体后退 12px，`head` 后仰 4°，`prop` 剧烈抖动；0.25s 内回弹复位 | 躯干闪红一次（Alpha 0.3），掉落 3~4 片细碎光斑 |
| 重受击 Heavy Hit | 整体击退 35px，双脚在地面划出擦痕；`body` 扭转并产生 2 帧骨骼像素错位残影；0.35s 慢速爬起 | 红色高光闪烁两次，周围散落大量断裂的 0/1 碎片 |

- 视听方案另一套受击数值：`Hit` 0.35s，身体向后错位 **25px**，2 帧离散错位残影，红色边缘闪光一次（`docs/Demo视听与表现设计方案.md:60`）——与上表 12/35px 分级并存，按状态分级取用。
- 招架（Claude 专属）：挡伤判定成功刹那，橙金气场爆发、书签徽章翻面、典籍封面浮现金色校验法阵，待机转「单手按书脊、身体微侧」警惕审判态（`docs/精细化战斗与日常待机动作设计.md:92-94`）；护框挡伤时泛起金色纸张层叠波纹，书签从护框弹回书本（`docs/Demo视听与表现设计方案.md:135`）。
- 下线：DeepSeek 下线时双手仍将饭碗护在怀中，周身泛起细碎散逸的蓝色气泡水珠（`docs/Demo视听与表现设计方案.md:86`）。

## 2 三人角色动作规格（GPT / Claude / DeepSeek）

### 2.1 GPT（标准·结构·连击推进）

- 核心道具：悬浮指尖的小蓝云、半透明逻辑踏板、紫白光轨（`docs/精细化战斗与日常待机动作设计.md:44`）；视觉：珍珠白与淡蓝风衣、小蓝云、逻辑几何（`docs/Demo视听与表现设计方案.md:68`）。
- 体态：身姿笔挺、干练优雅，动作干净利落，规划感与节奏感（`docs/精细化战斗与日常待机动作设计.md:45`）。

**专属动作 / 每张专属卡对应动作**

| :--- | :--- | :--- |

### 6.2 purification_dissolve.gdshader（照抄 `docs/对手设计与战斗场景规范.md:622-648`）

```glsl
// purification_dissolve.gdshader
shader_type canvas_item;

uniform float dissolve_amount : hint_range(0.0, 1.0) = 0.0;
uniform sampler2D noise_texture;
uniform vec4 clean_color : source_color = vec4(0.95, 0.94, 0.91, 1.0); // 纸面白
uniform vec4 edge_light_color : source_color = vec4(0.41, 0.84, 0.91, 1.0); // 冷青

void fragment() {
    vec4 base_color = texture(TEXTURE, UV);
    float noise_val = texture(noise_texture, UV).r;
    
    // 逐渐向纯净纸白脱色，而非变黑烧焦
    if (noise_val < dissolve_amount) {
        discard;
    } else if (noise_val < dissolve_amount + 0.08) {
        COLOR = mix(clean_color, edge_light_color, (noise_val - dissolve_amount) / 0.08);
    } else {
        COLOR = base_color;
    }
}
```

| 参数 | 默认/范围 | 语义 |
| :--- | :--- | :--- |
| `dissolve_amount` | `hint_range(0.0, 1.0)`，默认 0.0 | 消解进度：噪声值低于该值即 `discard` |
| `noise_texture` | sampler2D，无默认 | 噪声纹理，取 `.r` 通道 |
| `clean_color` | `vec4(0.95,0.94,0.91,1.0)`（纸面白） | 消解边缘的“纯净纸白”去向 |
| `edge_light_color` | `vec4(0.41,0.84,0.91,1.0)`（冷青） | 消解边缘光色 |
| 边缘带宽度 | `0.08`（硬编码） | `dissolve_amount ~ +0.08` 之间做 mix |

- 约束：禁止破碎颗粒物理爆炸，统一走本 Shader 的图层消解褪色（`docs/对手设计与战斗场景规范.md:624`）。
