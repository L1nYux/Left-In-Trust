### 1.4 发光与非颜色强语义（硬规则）

- 发光面积原则上**不超过画面的 15%**，暗线除外。`docs/总体视觉风格.md:50`；`docs/Demo视听与表现设计方案.md:27`；`docs/UI与战斗美术重构方案.md:57`
- 特效主体高光落在发光通道，**柔光散开半径不超过 16px**。`docs/Demo视听与表现设计方案.md:108`
- 屏幕同一区域最多出现**一个任务主色、一个角色强调色和一个系统状态色**。`docs/总体视觉风格.md:50`
- 状态不能只靠色相：颜色、图形、位置、文字至少同时使用两种。`docs/总体视觉风格.md:250`
- 非颜色强语义：
  - 攻击类：向前断面的锐角三角形、推进式箭头、切割裂隙。`docs/Demo视听与表现设计方案.md:33`
  - 防护类：圆角双外框、层叠书页、向内收束包围弧。`docs/Demo视听与表现设计方案.md:34`
  - 回复/支援类：闭合回路、双向光弧、平缓流动的水纹。`docs/Demo视听与表现设计方案.md:35`
  - 已行动/下线：落下的书签/失活印记、离散虚线、连接点断开。`docs/Demo视听与表现设计方案.md:36`
- 敌人所有攻击预告同时具备**颜色、形状、方向和节奏**四种线索；单体用收束线指向明确槽位，多段用分节刻度，群体用横贯全队的宽框，休整用开放圆环和降低的环境脉冲。`docs/总体视觉风格.md:183`
- 图标必须同时靠轮廓区分：攻击向前断面尖形、防护包围轮廓、恢复闭合回路、已行动落下签片、下线断开连接点。`docs/总体视觉风格.md:221`
- 剪影对峙原则：友方以连续弧线/圆角为主；敌方以尖角、截断线、套框为主。`docs/精细化怪物外观设计方案.md:20`，`docs/总体视觉风格.md:29-30`
- 冗余剥离美学：受击不喷血爆裂，而是脱落冗杂草稿、校正错位、补齐空洞。`docs/精细化怪物外观设计方案.md:21`，`docs/总体视觉风格.md:110`

### 1.5 工业级 6 层 2D 骨骼切片规范

```text
[EnemyMasterNode (Node2D)]
├── layer_0_shadow : 地面柔和接触阴影（带 Y 轴缩放与呼吸淡出）
├── layer_1_back   : 背部结构（背向连接线缆、后置散热格栅、阴影纸片）
├── layer_2_body   : 主体框架（机身壳体、主文件夹外壳、核心机械臂）
├── layer_3_core   : 能量核心与故障焦点（红光空洞、发光齿轮、跳动发条、电离晶核）
├── layer_4_front  : 前景游标与活动部件（前景爪具、表层翻动便签、滑动游标、指针）
└── layer_5_effect : 前景粒子与光栅层（悬浮 01 碎屑、激光警戒线、全息扫描框）
```

来源：`docs/精细化怪物外观设计方案.md:64-72`。Godot 装配树节点同名：`Layer0Shadow` … `Layer5Effect`（`layer_5_effect` 为 `GPUParticles2D`）。`docs/精细化怪物外观设计方案.md:826-835`

交付物：主概念全景透明图（Master Sheet）+ 6 层分层独立切片；另有一套“至少三层拆分”（主体 / 前景纸片或粒子 / 地面影子）。`docs/精细化怪物外观设计方案.md:62`，`docs/UI与战斗美术重构方案.md:128`

### 1.7 四态微动与时间规范

- 四态：**待机循环 / 意图蓄势（预告） / 受击反馈 / 解构退场（消解）**。`docs/UI与战斗美术重构方案.md:130`
- 各文档命名不完全一致：
  - “待机姿态 / 蓄力预告 / 受击解构 / 击败消解”`docs/精细化怪物外观设计方案.md:107-110`
  - “待机 (Idle) / 意图预告 (Anticipate) / 受击 (Hit) / 击败解构 (Defeat/Break)”`docs/Demo视听与表现设计方案.md:94`
  - “待机循环 / 意图蓄势 / 受击反馈 / 解构退场”`docs/UI与战斗美术重构方案.md:130`
  （统一命名见 §6 缺口 G-2。）
- 功能说明：`play_idle()` 缓动呼吸（body/core 上下 3px 位移与 1.02 倍缩放）；`play_telegraph(intent_type)` core 提高发光亮度、front 活动构件锁定目标；`play_hit()` 瞬态后滑 8px + 纯白闪烁（Hit Flash）+ 散落纸屑；`play_purify_archive()` 调用 `purification_dissolve.gdshader`，从 0.0 过渡到 1.0，红光化为绿光后归档。`docs/精细化怪物外观设计方案.md:837-851`
- 单次演出全长 **0.75s ~ 1.15s**（快速/倍速缩短至 0.5s）。`docs/Demo视听与表现设计方案.md:49`
- 四段力学：起手前摇 `0.12~0.30s` → 爆发发力 `0.10~0.25s` → 命中定格 `0.04~0.08s` → 缓冲回位 `0.20~0.35s`。`docs/精细化战斗场景设计方案.md:34`
- 每个对手再加**一种独有环境动作**（例：附件空洞吸入纸片、重复条目沿网格复制、收件人连线穿过站台）。`docs/UI与战斗美术重构方案.md:130`

- 核心意象：虚空并轨重叠、退散的明线地平线、由 0/1 散点构成的普通办公转椅、屏幕前闪烁的打字光标。`docs/精细化战斗场景设计方案.md:209`
- **视差/分层**：Layer 0 纯黑虚空 / Layer 1 0/1 扫描线 / Layer 2 镜面水银地。`docs/精细化战斗场景设计方案.md:257`
- **色板**：暖琥珀 `#F2B85B`、冷青 `#69D7E7`、星点白 `#FFFFFF`。`docs/精细化战斗场景设计方案.md:257`
- **环境道具/空间**：明线纸页公路与暗线离散剧场第一次也是唯一一次彻底并轨重叠；多余草稿/轨道/长椅如潮水退去化地平线尽头微弱蓝光；脚下平静如镜的水银黑底地面倒映冷青与暖琥珀光点。`docs/精细化战斗场景设计方案.md:214-215`

- **演出结果**：转椅与背影绝不爆炸或消散；光标停顿三秒，Backspace 逐字删去“都行，你看着办”，屏幕敲出“收到。今天就到这里，谢谢你们。”；光点转椅留原地，警示红光退去化为暖琥珀光晕；行旅终端车滑行至转椅旁停下。`docs/精细化战斗场景设计方案.md:239-245`
- **声景**：房间空调底噪、椅子滑轮微摩擦声、单音钢琴持续音（战斗音乐彻底隐去）。`docs/精细化战斗场景设计方案.md:219,257`

### 5.5 场景通用规则补充
