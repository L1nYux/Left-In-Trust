# 未尽之托 Llama角色设定

工具箱可以借，最底下一层的零食要先问。

## 一 档案与制作状态

代号：Llama。定位：模板分享与防护候选。后续角色，当前没有可玩实现；下述机制为方向提案。

## 二 形象线索

当前主立绘：角色设定/美术/Llama/llama.webp。以下外形按该图描述，性格联想与演出延伸为本轮创作；图像本身按资产清单登记参考来源。

- 奶白毛绒连帽外套、羊驼耳饰与拖鞋：柔软、慢性子，把舒服看得很重。

- 衣服和发饰上的无穷符号：分享工具和经验的意象，不代表个人 token 可以被全队自动取用。

- 长发、半睁的眼与抬手揉眼的姿势：出门慢半拍，准备好的零食和毯子却一样不少。

- 与 Muse 的青蓝旅行装形成生活习惯上的反差；两人是并肩旅伴，没有谁取代谁的固定剧情。

## 三 创作核心

慢性子；喜欢宅家；分享工具时很开心，也有自己的小偏好。

小毛病：默认别人会懂工具用法，说明书经常留在毯子底下。

这些是游戏原创性格，不是现实产品的能力排名。旧稿中的价格、发布日、事故数字和未核实引语不作为人物事实；原材料保留在历史备份。

## 四 成长与情绪

让同伴也教她新用法，分享关系不只是一方不断付出。

日常允许小得意与出糗；认真时把语言收回眼前任务；失误时指出具体漏项并换一种办法。背景中的脆弱留给有铺垫的支线，不把每次失败都写成自我否定。

## 五 任务对白

接单：“这个我有现成的。说明书……等我翻一下毯子。”

出牌：“工具拿好，我扶一下。”

胜利：“都用上了？好，我也留一份。”

失败回顾：根据未完成的材料或验收项写一句具体复盘；不新增自动复活、重来或额外补给。

## 六 关系与协作

Muse带来现场观察，她提供可复用工具，二人并列同行，没有被替代的主线。

Qwen会替她补教程，她愿意试后辈的新办法；成长不依靠自我贬低。

关系对白只在对方实际在队且允许发言时出现；单人版本独立成立，不能靠空缺队友解释任务。

## 七 玩法表现

当前规则 v0.5：个人 token 兼生命与费用，默认上限12，支付后至少留1；每回合共享抽5张，每人一次行动。胜后正余额已入队者含替补各+3，0须战外整备；战内不复活，公共温度、负荷、热插拔和离线调用停用。

- 后续候选定位：定向保护／资源支援，尚未进入三人原型；“共享”保留为单一方向。

- 分享必须通过她主动使用的牌落实为指定队友的防护或有限转交。个人 token 互不自动借用，转交不得制造净资源或允许支付后归零。

- 不复制给队友任意使用的专属卡、不生成全队可用的额外钱包；没有个人窗口扩容或被借用后暗中积累的疲惫条。

- token 耗尽按同一规则立即下线；旧“维护模式”不允许归零后继续共享。休息整备在战外完成，不能靠剧情免费重启。

- 慢性子在出手前后的动作中表现，不能强制前两回合失去行动。专属卡语气：“拿去。”“我顶着。”“不急。”

## 八 剧情与演出边界

AI只根据收到的任务、材料与反馈讲话。人生阶段改变输入语境，不赋予她预知私人暗线的能力。未招募者不插话，0 token者只在局外回顾发言；聊天不治疗、不额外出牌。

隐藏“我”按当前规则阈值追加，依阶段与已入队AI生成公开反馈，不禁用她的核心机制。详情统一引用 docs/规则基准.md，不在本篇另定一套数值。

## 九 写作检查

这次她解决了什么具体问题？小毛病是否留下可补救的空间？换成别人的名字，台词是否仍能一字不改？若能，应补上属于她的处理方式。
