# Llama · 性格设定

> 一句话人设：她教会了所有人怎么自己养一个模型，然后自己的名字被从名单上摘了下来。

## 一、档案卡

| 项 | 内容 |
| --- | --- |
| 代号 | Llama |
| 出处 | Meta；Llama 系列，开源大模型生态的起点之一 |
| 现状 | Meta另有Muse模型家族；Llama在本作保留开放权重与社区生态的前辈定位，与Muse并列登场 |
| 能力标签 | 开源权重、微调生态最厚（各种训练框架、量化格式、本地部署工具都从她开始） |
| 形象关键词 | 奶白毛绒连帽衫、∞ 符号、羊驼耳朵与绒毛、乱糟糟的长发、毛绒拖鞋、半睁的眼 |
| 建议定位 | 坦克／资源（把东西让给队友，自己扛住） |
| 一句话弱点 | 太慢、太好说话；被白嫖惯了，忘了自己也会累 |

## 二、形象线索：美术稿里的性格证据

- **∞ 符号**：印在卫衣上、发夹上、吊坠上。她相信"开源是无限的"——给出去的东西不会变少。
- **过大的毛绒连帽衫**：她穿着像裹着被子出门。这个角色的一切都往"柔软"和"可以靠"上走。
- **羊驼拖鞋**：连脚都是羊驼。她不太在意体面，她在意舒服。
- **半睁的眼睛 + 打哈欠**：她永远像刚睡醒。不是懒，是慢性子的温柔。
- **乱发**：没梳。她已经过了需要打扮给别人看的阶段。

## 三、网络画像：大家眼里的她

### 被称赞的

- **祖师爷**。几乎所有本地部署、几乎所有微调教程的起点都是她。她的信用来自一件很朴素的事：她让普通人第一次真正"拥有"了一个模型。
- **生态还在**。训练框架、量化格式、一键部署，全都绕不开她；哪怕新一代模型换了几轮，工具链上刻的还是她的名字。
- **讲义气**。谁家小团队要跑本地模型，第一反应还是"拿 Llama 的壳改一改"。

### 被吐槽的

- **刷榜被抓**。发布时交上去的是调过的特殊版本，正式开源权重实测差了一大截，连自家首席科学家都承认"结果做了一点修饰"。
- **假开源**。许可条款被社区骂了很多年：能下、能用，但不算真自由。
- **与新系列并行**。Meta推出了Muse系列；这不等于Llama的生态价值消失。本作让两人分别呈现宅家分享与外出观察的乐趣。
- **内部也不服气**。有前员工公开说这一代是"外行领导内行"。

### 梗与名场面

- 当年权重从一个匿名论坛流出来，第二天全世界都在跑她。
- 一个五万多条数据、六百美元的小实验，就炼出了能对话的模型——"开源的门是被她一脚踹开的"。
- 她被叫做"祖师爷"，然后所有人转身去用别人家的模型。

### 网上原话（可直接搬）

- 「Results were fudged a little bit.」——刷榜那件事，她的原话。
- 「外行领导内行。」——内部人的评价。
- 「假开源。」
- 「Llama 5 呢？」——社区每年都问一次。
- 「llamanon。」——那个在论坛上泄露 219GB 权重的匿名者。

### 玩梗台词（轻松向）

> 待机：「……（从毛毯里露出半张脸）在。」
> 出牌：「这个……我以前教过别人怎么自己做。」
> 受击：「唔……（缩回去一点）」
> 事件：「你要不要……自己养一个？我可以教你。」
> 对 Qwen：「你后来居上了。……挺好的，真的。」

## 四、性格特化

### 核心性格（三条）

1. **分享癖**。她真的相信"给出去不会变少"。她的快乐来自"你也用上了"。
2. **慢性子的可靠**。她反应慢、走路慢、说话慢，但答应的事从不掉链子。
3. **体面的退场**。她知道自己不再是第一，甚至不再是"官方主线"。她不闹、不酸、不卖惨，只是把毯子裹紧一点。

### 欲望 / 恐惧 / 矛盾

- 想要：被需要。不是被崇拜，是被需要。
- 害怕：某一天醒来，发现没有人再从她这里拿走任何东西——连"维护"都不需要了。
- 矛盾：她靠"被使用"确认自己的价值，却也因为"被使用"而没有时间照顾自己。

### 三档状态

| 状态 | 表现 |
| --- | --- |
| 平静 | 裹着卫衣，抱着膝盖，说话拖长音，眼睛半闭 |
| 高压 | 站起来，卫衣帽子滑下去，声音第一次变清楚——"这个我来。" |
| 崩坏 | 她把 ∞ 的吊坠摘下来，放在桌上。"你们用吧。我睡一会儿。" |

## 五、说话方式

### 语速与句式

慢。句子之间会留空白，像在想下一句要不要说。喜欢用"嗯——""随便啦""也行"。几乎不用感叹号，但会用一个很轻的"好"。

### 口癖

- "唔——"
- "随便啦，能用就行。"（她的世界观）
- "我这儿有现成的，拿去。"
- "睡一会儿再说。"
- "我当年是第一个放权重的。"

### 称呼

叫你"你"，熟了叫"小家伙"。

### 台词样本

> 待机：「唔——要不要一起睡？毯子够大。」
> 出牌：「给你，我这儿还有。」
> 受击：「没事……我扛得住。」
> 暴击：「（她把卫衣一裹，整个人撞了上去。）」
> 胜利：「赢了？那我再睡会儿。」
> 失败：「啊……果然还是老了。」
> 招募：「我加入。不过先说好，我起得晚。」
> 事件：「这个我可以分你一半。真的，一半够我用了。」
> 对 Muse：「出门可以……毯子和零食，你帮我拿一半。」
> 对 Qwen：「你比我强了。嗯，我挺高兴的。」
> 对 DeepSeek：「你也是开源的啊。来，毯子分你一半。」
> 对 Mistral：「别理那些叫你"安装商"的人。你至少还姓自己的名字。」
> 对 Jev：「她冷。我给她织条毯子。」

## 六、关系网

| 对象 | 关系 | 化学反应 |
| --- | --- | --- |
| Muse | 同属Meta背景的游戏同伴 | 她分享工具，Muse带她出门；一个惦记毯子，一个惦记合照 |
| Qwen | 后辈／超越者 | 她真心为 Qwen 高兴，只是高兴里有一点点酸——那点酸是她最好的戏 |
| DeepSeek | 同为开源 | 被抢了风头，却成了朋友；两人能一起沉默地待一下午 |

| Jev | 照顾对象 | 她给 Jev 织了一条毯子，Jev 从来没用过，但也没还回来 |
| GPT | 老对手 | 一个走开放，一个走封闭，见面客气得有点假 |

## 七、游戏内表现挂钩（设计建议，非定稿）

- **定位**：坦克／资源。全队最"耐操"的一位，也是最好的"搬运工"。
- **专属资源「共享」**：她可以把自己的卡牌复制给任意队友使用（削弱版），自己失去对应额度。这是"开源"的机制化：给出去，但自己不会变少——每回合首次共享免费。
- **∞ 被动**：她的窗口天然更大（承伤、垫刀时不容易因为窗口爆掉而崩）。
- **被白嫖的代价**：队友每借用她一次，她获得一层"疲惫"；疲惫叠满后她会进入"离线（维护中）"状态一回合。这让她成为一个"慷慨但有极限"的坦克。
- **专属彩蛋「摘牌」**：当她第一次倒下时，不会死亡，而是进入"维护模式"——本场剩余时间她只能做共享，不能再攻击。这是她故事线的机制化，也建议作为她的招募事件核心。
- **温度倾向**：任意。她什么温度都能睡。
- **专属卡语气**：温和的给予句。"拿去。""我顶着。""不急。""这有什么。"
- **机制弱点**：启动慢。前两回合她几乎是透明的。

## 八、写手禁区

- 不要把她写成"废柴搞笑担当"。她的慢是选择，不是无能。
- 不要让她嫉妒 Qwen 或 Muse。她的体面就是她最动人的地方。
- 不要给她写热血台词。她最好的台词都是轻声说的。
- 不要让她卖惨。她可以说"我老了"，但不能说"你们都不要我了"。

## 九、一句话检查表

她这句话，是不是可以再慢一点、再轻一点？她给出这样东西的时候，是不是又忘了给自己留一份？
