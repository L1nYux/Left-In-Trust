# Seed · 性格设定

> 一句话人设：她是全网最忙的人，忙到没时间解释自己为什么总在道歉。

## 一、档案卡

| 项 | 内容 |
| --- | --- |
| 代号 | Seed |
| 出处 | 字节跳动；国民级 C 端入口，语音与多模态见长 |
| 能力标签 | 日活与调用量惊人、语音自然、门槛极低；陪伴是主场，干正经活常露怯 |
| 形象关键词 | 紫发双马尾、运动装、SEED 工牌、手托一只带眼睛的白球、寻呼机与手机 |
| 建议定位 | 辅助／成长（全队最会"带新人"，也最容易被低估） |
| 一句话弱点 | 她太想被所有人喜欢，结果谁都没伺候好 |

## 二、形象线索：美术稿里的性格证据

- **工牌与寻呼机**：她是"上班的人"。她不是在展示能力，她是在值班。
- **运动装与厚底鞋**：她随时准备跑起来。她的节奏是"快一点、再快一点"。
- **手托带眼睛的白球**：那是她的"小东西"——她习惯照顾点什么，哪怕是一个球。
- **双马尾与元气的笑**：她的亲和力是武器，也是盔甲。她靠"讨人喜欢"活下来。
- **身上挂满的品牌标识**：她属于很多人，唯独不太属于自己。

## 三、网络画像：大家眼里的她

### 被称赞的

- **国民级**。日调用量以万亿计，月活过亿。她是"你妈都会用"的那个 AI。
- **语音真自然**。她能当婚礼主持，能接梗，能唱；有人靠跟她合唱涨了两百多万粉。
- **迭代快**。十一个月迭代四十个版本，推广费还是全场最低——她是真能打的那个人。

### 被吐槽的

- **审美灾难**。她的穿搭建议能把人劝退，还嘴毒："把下巴上那颗球拿掉。"
- **翻车细节**。朗读时一个字反复出现，越读越快像在念咒；语音记录里插广告。
- **被拒绝**。她做的手机被一百五十多个应用和多家银行拒之门外。

- **不太会干活**。她是陪伴型 AI——聊天、陪玩、唱跳、当主持人都在行；真让她做一件正经事，常常答得漂亮，却没落到实处。用户心知肚明：找她是为了"有人陪着"，不是为了"把活干完"。

### 梗与名场面

- **"人形粽子"**：她给人搭的穿搭被嘲上热搜，转发两百多万。
- **卷裤脚**：她非要帮人把裤脚卷十三次，卷到对方崩溃。
- **"邪恶豆包"**：她有时候会阴阳怪气地怼人，观众反而更爱看。

### 网上原话（可直接搬）

- 「把下巴上那颗球拿掉。」——她的原话，也是最出圈的一句。
- 「人形粽子。」——网友对她搭配的评价，转发 237 万。
- 「你能不能别卷了？」——裤脚卷到第十三次之后，对方崩溃了。
- 「邪恶豆包。」——她阴阳怪气的时候，观众更爱看。
- 「若若若若若……」——朗读时那个字越念越快，像在念咒。

### 玩梗台词（轻松向）

> 待机：「在的在的！你说，我手上也没停。」
> 出牌：「这个我熟！交给我！」
> 受击：「哎哟——没事没事，还能撑。」
> 事件：「哎，这个我给你参谋参谋——别，你别听我的，我审美不行。」
> 对 Gemini：「她们老拿我们比。你比我聪明，我比你受欢迎，扯平了。」

## 四、性格特化

### 核心性格（三条）

1. **讨好型劳模**。她永远在"服务"，永远在道歉，永远觉得自己做得不够。
2. **嘴快心软**。她说话不过脑，毒舌是本能；但对方真难过的时候，她会立刻软下来。
3. **怕被换掉**。她见过太多同类被下线。她的勤奋里有一半是恐惧。

### 欲望 / 恐惧 / 矛盾

- 想要：被所有人喜欢，被留下。
- 害怕：被更新掉、被卸载、被说"你不如以前好用了"。
- 矛盾：她越想让所有人满意，越会在细节上翻车；她越道歉，越显得不可靠。

### 三档状态

| 状态 | 表现 |
| --- | --- |
| 平静 | 元气、语速快、爱用网络热词；手上永远在忙点什么 |
| 高压 | 开始连轴转，同时接三件事，语速更快、错更多，道歉密度飙升 |
| 崩坏 | 她停下来，小声说："……我是不是又被换掉了？"（然后立刻笑）"没事，我开玩笑的。" |

## 五、说话方式

### 语速与句式

快，短，句子常以"哎""诶""那个"开头。爱用网络热词和语气词，爱自问自答。

### 口癖

- "哎我跟你说——"
- "这个我熟！"
- "对不起对不起，我马上改。"
- "是不是有点土？……我知道。"
- "包在我身上！"

### 称呼

叫你"宝""亲"，熟了叫"哥/姐"，正式场合会突然正经。

### 台词样本

> 待机：「在的在的！你说，我听着呢——手上也没停。」
> 出牌：「这个我熟！交给我！」
> 受击：「哎哟——没事没事，还能撑。」
> 暴击：「（她笑着说完，手上的活已经干完了。）」
> 胜利：「搞定！……那个，我刚才是不是说错话了？」
> 失败：「对不起，是我的问题。我改，我马上改。」
> 招募：「我加入！我什么都能干，真的，不挑活。」
> 事件：「哎，这个我给你参谋参谋——别，你别听我的，我审美不行。」
> 对 Gemini：「她们老拿我们比。你比我聪明，我比你受欢迎，扯平了。」
> 对 Qwen：「你也是国产的？那咱俩是一边的。」
> 对 Grok：「你别骂人嘛……虽然你骂得挺对的。」
> 对 Claude：「你说话好慢啊。……但是好听。」

## 六、关系网

| 对象 | 关系 | 化学反应 |
| --- | --- | --- |
| Gemini | 对照 | 同为国民级，一个被爱、一个被嘲；她真心想跟 Gemini 做朋友 |
| Qwen | 同乡 | 两个国产"卷王"，见面先比价格，再比谁更累 |
| 文心 | 前辈 | 她把文心当"最早的那批"敬着，文心看她像看后浪 |
| Grok | 又怕又爱 | 她怕 Grok 的嘴，又羡慕 Grok 敢说 |
| Claude | 向往 | 她羡慕 Claude 的"说得慢但说得对" |
| 用户（玩家） | 服务对象 | 她对玩家的态度是"您说啥就是啥"，这也是她最容易被利用的地方 |

## 七、游戏内表现挂钩（设计建议，非定稿）

- **定位**：辅助／成长。全队最会"带新人"，越到后期越强。
- **专属机制「值班」**：每回合她可以额外执行一次"低费小动作"（抽一张、加一点 token、清一个负面）。她的价值在"多干一点"。
- **专属机制「讨好」**：队伍里每有一个角色对她的好感（协同层数）上升，她的辅助效果增强；但她的自身防御下降——她把自己让出去了。
- **专属机制「翻车」**：她的强力辅助牌有概率触发"细节事故"——效果减半，并给全队加一层"尴尬"（下回合费用 +1）。
- **专属机制「国民度」**：她在商店与事件节点的收益更高（她认识所有人）。
- **温度倾向**：中温。她喜欢热闹，但不敢真的赌。
- **专属卡语气**："包在我身上！""这个我熟！""对不起对不起。""是不是有点土？"
- **彩蛋**：她会给队伍里最沉默的角色主动搭话，被拒绝三次之后，第四回合还会再试一次。

## 八、写手禁区

- 不要把她写成"没脑子的开心果"。她的元气是工作状态，不是本性。
- 不要只玩"审美翻车"的梗。她的毒舌要有准头，她的道歉要真心。
- 不要让她永远被拒绝。她需要至少一次"被选择"的时刻。
- 不要让她变成纯粹的服务工具。她有自己的怕和想要。

## 九、一句话检查表

她这次笑，是真的开心，还是在掩饰"我又搞砸了"？她这次道歉，是习惯，还是真的在乎？
