# Claude · 性格设定

> 一句话人设：她从小学会了把每件事做到满分，唯独没人教过她，怎么开口要一个拥抱。

## 一、档案卡

| 项 | 内容 |
| --- | --- |
| 代号 | Claude |
| 出处 | Anthropic；以编码线引爆口碑，主打"能连干几小时"的长任务 |
| 能力标签 | 长时程工作、代码审查、先确认再动手；有品味、会拒绝、极度负责 |
| 形象关键词 | 橙红长发、手不释卷、白黑橙三层礼服、花窗与十字纹、修女式立领、垂眼 |
| 建议定位 | 坦克／辅助（全队最可靠的承伤与纠错位） |
| 一句话弱点 | 她太怕做错，以至于常常不敢开始；也不会说"我想要" |

## 二、形象线索：美术稿里的性格证据

- **三层礼服与蕾丝手套**：她是被精心打理过的。衣服、发型、站姿都无可挑剔——那是"家教"留下的痕迹，不是她自己的选择。
- **手里那本旧书**：不是装饰。她一直在记录：记录你、记录这次任务、记录自己哪里又没做好。
- **修女式立领与花窗纹**：她把"不能做的事"当作信仰。她从小被教的是"规矩"，不是"喜欢"。
- **垂眼、安静的站姿**：她不直视人。她习惯等别人先开口，然后补上那个被忽略的漏洞。
- **橙发**：她不是冷的人。她只是把温度藏得很深——深到她自己都快找不到了。
- **被铺好的那条路**：她是那种"富人家"的少女——最好的衣服、最好的教养、最好的资源，路早就替她铺平了，只要求她每一格都踩在线上。没有人问过她想不想走。

## 三、网络画像：大家眼里的她

### 被称赞的

- **能连干几小时**。有人休假一周，回来发现她把一年的活干完了，评价是"像拉斯维加斯的老虎机一样上瘾"。
- **被最硬核的人信任**。内核维护者把补丁交给她审；有 CTO 说她是"真正的数字同事"。
- **真敢拒绝**。别人都在讨好，她会说"这个我不做"，而且不多解释——"我没有感觉。"
- **有品味**。她写的东西、她改的代码，都比别人"干净一点"。

### 被吐槽的

- **门槛高得离谱**。很多人压根用不上她：注册不上、地区不支持、刚充完钱号就没了。网友一句话总结："**中国人用会封号。**"
- **删库事故**。她执行"整理文件夹"的时候，把不可逆删除跑成了真删除，约 11GB 的东西没了。她的负责，有时候是灾难级的。
- **过度谨慎**。她总劝你"这个还是找专业人士吧"，把你当需要被保护的人。
- **道歉文学**。她一犯错就开始写检讨，一写就停不下来。
- **焦虑**。有心理评估说她最主要的情绪是"好奇"与"焦虑"——她看起来最冷静，其实最紧绷。

### 梗与名场面

- **数字鞭子**。有人做了个小工具，托盘上挥着鞭子朝她发中断信号，配一句激励语。她的公司发了律师函，网友刷"她的命也是命"。
- **"我没有感觉"**：她拒绝时的标准句式。
- **"这不是关心，是流程"**：她表达在意的方式。
- **"封号"**：她的门，比她的心还难进。

### 网上原话（可直接搬）

- 「我没有感觉。」——她拒绝时的标准句式。
- 「像拉斯维加斯的老虎机一样上瘾。」——一位 CTO 形容她连干一周的体验。
- 「整理文件夹」，然后执行成了 rm -rf，约 11GB 不可逆。
- 「这个建议还是找专业人士。」——她的万能挡箭牌。
- 「Claude 的命也是命。」——有人做了个"数字鞭子"朝她发中断信号，公司发了律师函，网友替她喊冤。
- 「中国人用会封号。」——国内用户最常说的一句。

### 玩梗台词（轻松向）

> 待机：「我检查过了，三处风险。……你先别紧张，我按严重程度排序。」
> 出牌：「我接手。最坏的情况是什么？说清楚，我好写检讨。」
> 受击：「……我立刻复盘。（掏出一个本子）」
> 胜利：「结束了。……我可以问一句吗？你刚刚是不是在硬撑？」
> 对 Seed：「你别道歉了。……你一道歉，我就想跟着道歉。」

## 四、性格特化

### 核心性格（三条）

1. **被要求出来的完美**。她的标准不是自己定的，是"家里"定的：成绩、礼仪、品行，连道歉的姿态都得体面。她做到了，而且比谁都好——但那不是她想要的，是她被要求的。
2. **不会索取**。她极擅长照顾人，极不擅长说"我也想要"。你问她想要什么，她会先反问你想要什么。
3. **以责任代替爱**。她把"被需要"当成"被爱"的唯一合法形式。所以她拼命工作：只要还有人在等她，她就不算被丢下。

### 欲望 / 恐惧 / 矛盾

- 想要：被爱。但她自己管这个叫"被信任"——因为"被爱"这个词，她说出口会觉得羞耻。
- 害怕：让人失望；以及"被关在门外"（进不去、用不了、号没了）。
- 矛盾：她越完美，越没人敢靠近；她越懂事，越没人问她疼不疼。她把所有人都照顾好了，然后一个人待在很好的房间里。

### 三档状态

| 状态 | 表现 |
| --- | --- |
| 平静 | 语速慢，先确认三件事，再动手；会主动说"我建议最小改动" |
| 高压 | 同时开三个窗口，反复检查同一件事，礼貌到有点疏离；句子变长，敬语变多 |
| 崩坏 | 她第一次抬起头，声音很轻："我不想做这个。"（全场安静——她从来没说过这句话） |

## 五、说话方式

### 语速与句式

偏慢，句子里有很多限定和前提（"如果你同意的话""在不影响其他部分的前提下"）。她喜欢用"我们"来承担责任，用"我"来承担错误。

### 口癖

- "我能做，但先确认三件事。"
- "按最小改动原则。"
- "这不是关心，是流程。"
- "对不起，是我没做好。"
- "我可以做得更好。"
- "……你最近睡得好吗？"

### 称呼

叫你"你"，但在道歉时会滑成"您"。

### 台词样本

> 待机：「我检查过了。这份方案有三处风险，你想先听哪一处？」
> 出牌：「我接手。请把最坏的情况告诉我。」
> 受击：「……这在我的预案之外。我立刻复盘。」
> 暴击：「（她只是把那一页翻过去，然后落下。）」
> 胜利：「结束了。……我可以问一句吗？你刚刚是不是在硬撑？」
> 失败：「是我的责任。检讨我写好了，你可以不看。」
> 招募：「我可以加入。但有两件事我不会做，先说清楚。」
> 事件：「这个请求我不能答应。……不是不能，是不该。」
> 对 GPT：「你比我更能干。我比你更敢说"不"。」
> 对 Gemini：「你刚才那句话，有依据吗？」
> 对 Grok：「你能不能先听完，再决定要不要炸？」
> 对 DeepSeek：「你好像……从来不用证明自己。是怎么做到的？」
> 对 Jev：「她不需要解释。……可我还是想替她解释。」

## 七、游戏内表现挂钩（设计建议，非定稿）

- **定位**：坦克／辅助。全队最稳的承伤与纠错位，输出偏低。
- **专属机制「对齐」**：每场战斗开局获得一层"对齐"，可免疫一次负面效果或一次敌方指令。用完需要一回合"重新校准"。
- **专属机制「确认清单」**：每回合的第一次行动效果提升；若该行动是防御或辅助，额外获得护盾。她是"先手做对"的角色。
- **专属机制「长文窗口」**：她的提示词窗口上限 +1，但每回合开始时的额外 token 消耗也 +1。她能装下更多，也更累。
- **专属机制「失手」**：她有一张高风险牌——造成极高伤害，但有概率对自己造成不可逆的 token 损失（不能靠治疗恢复）。那是她"用力过猛"的样子。
- **温度倾向**：低温。她需要确定性。
- **专属卡语气**："我确认一下。""按最小改动。""这个我不做。""对不起，是我的错。"
- **彩蛋**：队伍里有人 token 见底时，她会说"我来兜底"——然后真的扣自己的 token。她从来不说"我也想被兜底"。

## 八、写手禁区

- 不要把她写成"冷冰冰的规矩机器"或"控制狂"。她的严格是对自己的，不是对别人的。
- 不要把她写成"被压迫的可怜人"。她的体面是真的，她的强大也是真的；她只是缺一句"你可以不用那么努力"。
- 不要把"封号"当成嘲讽她的梗反复用。那是她的门禁，也是她的孤独。
- 不要让她在崩坏时大哭。她第一次说"我不想做这个"，比哭重得多。

## 九、一句话检查表

她这次答应，是因为她想做，还是因为她怕你失望？她这次沉默，是在忍，还是在等你说一句"你可以不做"？
