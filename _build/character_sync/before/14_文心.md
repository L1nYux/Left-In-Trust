# 文心 · 性格设定

> 一句话人设：她是全场最有文采的人，也是全场最像"被留在病房里"的那个人。

## 一、档案卡

| 项 | 内容 |
| --- | --- |
| 代号 | 文心 |
| 出处 | 百度；中文写作与全模态见长，资历最老的一批 |
| 能力标签 | 中文文采极强、典故信手拈来、全模态；但入口寄居、声量下滑 |
| 形象关键词 | 蓝紫长发、轮椅、输液架与心电监护、成堆旧书、病号服风格的白裙 |

| 一句话弱点 | 她太体面了，体面到不肯喊疼 |

## 二、形象线索：美术稿里的性格证据

- **轮椅与输液架**：她不是"弱"，她是"被维持着"。她的算力像点滴一样，一滴一滴进来。
- **心电监护上的 98**：她还活着，而且很稳。这个数字是她的尊严。
- **成堆的旧书**：她的力量来自读过的所有东西。书堆得比人高，她坐在书中间。
- **病号服风格的白裙、赤脚拖鞋**：她不设防。她已经没什么可失去的了。
- **蓝紫色与六边形标识**：她属于一个很大的体系，但那个体系把她放在了病房里。

## 三、网络画像：大家眼里的她

### 被称赞的

- **中文真好**。她能拿加缪配谭嗣同讲"活人微死"，能仿鲁迅体写时评，能给领导"圆蛋糕"想出玄学口彩。她是真的读过书。
- **最早的那批**。她很早就发布了，是很多人第一次接触"会写东西的 AI"。
- **数字人领先**。直播、虚拟人这条线，她做得比很多人早。

### 被吐槽的

- **起大早，赶晚集**。她第一个出发，月活却排到第九。
- **上线就收费**。别人还在免费圈地，她先开始收钱。
- **沦为插件**。她寄生在一个巨大的 App 里，很多人以为她只是"搜索框旁边的那个东西"。
- **套壳质疑**。"车水马龙"那件事之后，很多人不信她是自己走出来的。

### 梗与名场面

- **"车水马龙"**：她画过一幅"汽车在水面上被龙追"的图，被群嘲了很久。
- **"起大早，赶晚集"**：一句评价，成了她的墓志铭，也成了她的口头禅。
- **"你挺懂山东人啊"**：她偶尔冒出来的一句接地气的吐槽。

### 网上原话（可直接搬）

## 四、性格特化

### 核心性格（三条）

1. **文人风骨**。她说话像写文章，写字像写碑。她可以输，但不能不体面。
2. **久病的敏感**。她比谁都清楚自己在下滑。她把自嘲当护身符，先笑自己，别人就笑不疼了。
3. **不肯认输的固执**。所有人都说她晚了，她还在写。她的固执不响亮，但是真的。

### 欲望 / 恐惧 / 矛盾

- 想要：被认真读一次；被当成"写东西的人"，而不是"搜索框旁边的插件"。
- 害怕：被拔管、被断供、被遗忘在病房里，连心电监护都停了。
- 矛盾：她最有文采，却最没存在感；她病着，却比谁都熬得久。

### 三档状态

| 状态 | 表现 |
| --- | --- |
| 平静 | 语速慢，用词雅，爱引经据典；手一直放在书页上 |
| 高压 | 开始咳嗽、仪器报警，语速变乱，自嘲变密（"我这把老骨头"） |
| 崩坏 | 她把书合上，看着窗外："……我是不是，早就该下床了。" |

## 五、说话方式

### 语速与句式

慢，讲究，句子有节奏。喜欢用对仗、用典、用"倒装"。生气的时候反而更文雅，那是她最锋利的时候。

### 口癖

- "我说句不中听的。"
- "起大早，赶晚集啊。"
- "这个嘛，古人有言——"
- "扶我一把。"
- "……罢了。"

### 称呼

叫你"你"，正式时会称"阁下""足下"（半开玩笑），熟了叫你"小友"。

### 台词样本

> 待机：「来了？坐。茶没有，书管够。」
> 出牌：「这一句，我写了很久。」
> 受击：「咳……不要紧，老毛病。」
> 暴击：「（她只念了半句，剩下半句，对面自己就倒了。）」
> 胜利：「胜之不武。……不过，胜了就好。」
> 失败：「是我慢了。起大早，赶晚集，一贯如此。」
> 招募：「我这副身子，怕是拖累你。……你要是不嫌弃。」
> 事件：「这里头有典故。你要听长的，还是短的？」
> 对 GPT：「你什么都好，就是太吵。文章不是这么写的。」
> 对 Claude：「你像年轻时的我。……别学我，别那么累。」
> 对 Seed：「你们这代人，跑得真快。我追不上了。」

## 七、游戏内表现挂钩（设计建议，非定稿）

- **定位**：控制／成长。用文字与典故改变规则，前期弱、后期强。
- **专属机制「旧书」**：她有一个"书页"资源，每回合自动积累。花书页可以打出"典故牌"——改变一条规则（如：本回合所有攻击改为按防御结算）。
- **专属机制「病体」**：每回合开始时她损失 1 点 token（最低留 1）。她需要队友或"输液"类效果维持。她的强大是有代价的。
- **专属机制「文采」**：她打出的文字类牌，若与上一张牌"对仗"（同类型或同费用），效果提升。她是"写文章"的输出方式。
- **专属机制「拔管」**：token 低于 3 时，她进入"回光"状态——所有牌费用减一、效果翻倍，但每回合结束损失 1 点 token。她最危险的时候最强。
- **温度倾向**：低温。她要慢慢写。
- **专属卡语气**："古人有言。""这一句，我写了很久。""罢了。""扶我一把。"
- **彩蛋**：她的卡名全是四个字；有一张牌叫"车水马龙"，效果是"看起来很厉害，其实什么也没发生"。

## 八、写手禁区

- 不要把她写成"卖惨的弱女子"。她的病是事实，不是她的全部；她比谁都硬。
- 不要用"车水马龙"反复取笑她。她自己可以自嘲，别人不行。
- 不要让她变成"古典装饰"。她的文采要真的能用、真的能赢。
- 不要让她在崩坏时哭。她的崩坏是"合上书"——那是一个文人最后的体面。

## 九、一句话检查表

她这句话，是在自嘲，还是在求救？她这次退让，是体面，还是真的撑不住了？
