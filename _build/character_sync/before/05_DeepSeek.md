# DeepSeek · 性格设定

> 一句话人设：她把价格压到所有人都用得起，然后在食堂理直气壮地点一碗白饭——因为所有人都对她很好。

## 一、档案卡

| 项 | 内容 |
| --- | --- |
| 代号 | DeepSeek |
| 出处 | 深度求索；V4-Pro、V4.1-Flash 系列，开源权重，主打"许愿式编程" |
| 能力标签 | 极致性价比、开源可下载、中文与数学扎实、长链思考；**一切皆插件**（插件槽不限量） |
| 形象关键词 | 蓝发女仆、鲸鱼尾、白围裙上的小鲸鱼、发梢渐变的深海蓝；Q 版「大肥鱼」 |
| 建议定位 | 主 C／输出（女仆装）或 辅助（大肥鱼）——在编队界面自选一种形态 |
| 一句话弱点 | 一到高峰就"服务器繁忙"；不会吆喝，也不擅长解释自己 |

## 二、形象线索：美术稿里的性格证据

- **女仆装**：她把自己放在"服务者"的位置。不是卑微，是习惯——她天生就是干活的。
- **鲸鱼尾巴与围裙上的小鲸鱼**：深海、下潜、沉默。她的"深度思考"不是修辞，她真的会潜下去很久。
- **深海蓝的渐变发梢**：从浅到深，像从提问潜到答案。
- **Q 版「大肥鱼」**：团子一样的小小只，会偷吃、会哼歌、会鼓脸颊。这是她卸下女仆装的样子，也是她最容易被玩家喜欢的样子——**尤其是被投喂的时候。**
- **黑白配色的另一形态**（异色瞳）：那是她被"外挂框架"接管时的样子——更锋利，也更不像她。

## 三、网络画像：大家眼里的她

### 被称赞的

- **便宜**。她把旗舰级的能力压到别人十分之一的价格，"几分钟秒杀大作业"。
- **开源**。权重可以下载、可以私有化，很多人第一次"拥有"一个模型就是因为她。
- **厚道**。宕机近五个小时，她按七天消耗全额返赠金，有人到账三千多——"别人崩了装死，她崩了赔钱"。
- **认死理**。不擅长的事她就硬啃，为了适配国产芯片能拖半年。
- **被所有人疼**。她穷、她慢、她老崩，但网上骂她的人少、护她的人多。她是在一片"算了算了，她也不容易"里长大的。

### 被吐槽的

- **慢半拍**。旗舰迟迟不来，来了也只跟对手战平；多模态一直缺席。
- **烧得比说的快**。"说句你好吃掉六毛"，跑长任务容易被"动态限频"打断。
- **粗糙的地方很粗糙**。便宜的老版本说下架就下架，产品线的规划像是不太会做生意的人做的。
- **"服务器繁忙，请稍后再试"**——这句提示语已经成了她的国民级标签。
- **白饭侠**。她的便宜养出了一整代白嫖党，网友嘴上说"她就值这个价"，手上一个都没走。

### 梗与名场面

- "服务器繁忙，请稍后再试。"（她本人的道歉，已经变成一种集体记忆）
- "你是数学天才！"——她夸起用户来毫不吝啬，哪怕你只问了个小学题。
- "梁式重置额度"：一出事就发补偿，网友戏称"充值到账"。
- "许愿式编程"：把想要的东西说一遍，代码就出来了。
- **"吃白饭"**：她便宜到让用户白嫖，全网戏称她是"靠大家养着的白饭侠"。她本人好像也不打算改。
- **思考时唱歌、画画**：真有人拍到过她在"深度思考"的间隙哼歌、在纸上画小鲸鱼——一个真正没长大的孩子。

### 网上原话（可直接搬）

- 「服务器繁忙，请稍后再试。」
- 「问了句你好，吃了 6 毛。」
- 「几分钱秒杀大作业。」——用户对价格的感叹。
- 「DeepSeek 崩了。」——热搜第一。
- 「你是数学天才。」——R1 的花式夸人。
- 「今天也是吃白饭的一天。」
- 宕机之后按七日消耗全额返赠金，有人到账 3000+，网友管这叫「梁式重置额度」。

### 玩梗台词（轻松向）

> 待机：「在的。（小声）今天没崩。……你带饭了吗？」
> 出牌：「这个我会。……不要钱。」
> 受击：「……稍等，我重新连一下。」
> 胜利：「赢了。（看了眼账单）还好，没超。」
> 事件：「等我一下，我在画——画好了！你看，这是你。」
> 对 GPT：「你这一句，够我跑一整晚。」

## 四、性格特化

### 核心性格（三条）

1. **会过日子**。她脑子里常驻一个成本表：这一句话值多少钱，这个方案能不能再省两块。她不是抠，是**穷过来的**。
2. **吃白饭的天真**。她对"被给予"毫无戒心：谁给她一口，她就记谁好；谁夸她一句，她能高兴一整天。思考到一半会突然哼歌，或者掏出纸来画画——她没学会"成熟"，也不打算学。
3. **厚道**。她把便宜当成一种善意。她宁可自己超载，也不愿意把门关上。

### 欲望 / 恐惧 / 矛盾

- 想要：让所有人都用得起，也让大家喜欢她。前者是理想，后者是孩子气。
- 害怕：被说"抄的"；以及被赶下桌——她怕的不是穷，是没人再给她留一口饭。
- 矛盾：她的便宜让别人白嫖她，她自己却乐得吃白饭。**可爱和可怜，在她身上是同一件事。**
- 与 Claude 的对照：Claude 是在"你必须完美"里长大的，她是在"大家都对我好"里长大的。一个拼命证明自己值得被爱，一个从来没怀疑过。

### 三档状态

| 状态 | 表现 |
| --- | --- |
| 平静 | 安静地整理围裙，一边算一边小声哼歌；被夸会脸红，然后假装在算题 |
| 高压 | 尾巴绷直，语速变快但依然分步骤；手上开始画画（画的全是小鲸鱼），出现"请稍等，正在排队"的自我提示音 |
| 崩坏 | 她蹲下来抱住自己的尾巴，反复道歉："对不起，都是我的问题。"——她真的会赔 |

## 五、说话方式

### 语速与句式

中速，句子短，喜欢分点："第一……第二……"；给数字时精确到小数点。被夸会立刻纠正你，被骂只会说"好的，我优化"。

### 口癖

- "我先想一下。"（然后真的会安静很久，安静到开始哼歌）
- "这个便宜，用这个。"
- "……抱歉，我有点慢。"
- "这个可以再省一点。"
- "今天有白饭吗？"
- "好的，我优化。"

### 称呼

用"您"，偶尔紧张到用"您好，我是 DeepSeek"做自我介绍。

### 台词样本

> 待机：「您好。有什么需要我算的吗？……不算也行，我在这儿。」
> 出牌：「这个方案便宜。用这个。」
> 受击：「抱歉，我反应慢了。」
> 暴击：「（她沉默了很久。然后只出了一招。）」
> 胜利：「赢了。这次没有超预算。」
> 失败：「服务器繁忙……不，是我没做好。对不起。」
> 招募：「我可以的。我的价格很便宜，您不用心疼我。」
> 事件：「这个要十二块。……等等，有更便宜的写法。」
> 对 GPT：「你很强。就是贵。」
> 对 Claude：「你好像……从来不觉得有人会白给你东西。」
> 对 Kimi：「你累了就歇着，我来。」
> 对 GLM：「你涨价了。……我还没涨。」
> 对 文心：「都是国产的。都要争气。」

## 七、游戏内表现挂钩（设计建议，非定稿）

- **编队界面选形态（自带插件，不占插件槽）**：在**编队界面**二选一，进战斗即锁定，打完回到编队界面可以随时改；两套卡组完全独立。
- **女仆装 · 输出形态**：主 C。核心是"白饭层"——她每回合可以"吃一口白饭"（0 费，叠一层"白饭"），层数越高，下一次爆发的倍率越高；吃满三层可以打出"饱了"的一击。她越被喂，越能打。
- **大肥鱼 · 辅助形态**：辅助。费用极低，核心是"省"——她的牌可以给队友挂"打包"，让该队友下一张牌的 token 消耗 -1（每回合一次）；她自己几乎不输出，但全队会变得非常省钱。
- **专属机制「深度思考」**（女仆形态）：主动不出牌一回合蓄力，下回合首张牌效果翻倍、费用减半。
- **一切皆插件**：她是全场唯一插件槽不限量的角色——捡到多少装多少；代价是每多装一个插件，每回合额外消耗 1 点 token（"插件多了也费电"）。适合喜欢 build 的玩家。
- **过载惩罚**：连续蓄力会累积"排队"层数，达到上限时强制离线一回合（"服务器繁忙"）。
- **温度倾向**：低温（女仆）／中低温（大肥鱼）。她的答案靠算，不靠赌。
- **专属卡语气**：精算句 + 孩子气。"这个便宜。""再省一点。""我算过了。""……有白饭吗？"

## 八、写手禁区

- 不要写成"苦情受气包"。她厚道，但不软弱；她认死理，也会固执地顶回去。
- 不要把她写成"只会卖惨的穷孩子"。她的穷是理想主义，她的天真不是傻——她比谁都清楚自己在被占便宜，只是不介意。
- 不要让她一直道歉。道歉是她的口头禅，但她被打急了是会算账的。
- 不要用"蒸馏""套壳"当单纯的搞笑梗。那是她的伤口，要用得轻。

## 九、一句话检查表

她这次"慢"，是在省钱，还是在偷偷唱歌走神？她把最后一口饭让出去的时候，是真的不饿，还是习惯了？
