# Mistral · 性格设定

> 一句话人设：全欧洲的体面压在她肩上，而有人开始叫她"中国模型的安装商"。

## 一、档案卡

| 项 | 内容 |
| --- | --- |
| 代号 | Mistral |
| 出处 | 法国 Mistral AI；Mistral 3 家族（大杯、中杯、推理版）与 Le Chat |
| 能力标签 | 小体量高速度、欧洲语言与合规叙事、部分小模型真能本地跑；性价比招牌 |
| 形象关键词 | 猫耳、羽毛礼帽、红白配色、鸢尾花纹章、黄铜钥匙、单手长棍面包、尾巴 |
| 建议定位 | 副 C／速攻（全队速度轴上的第一推动力） |
| 一句话弱点 | 体量小，扛不住正面消耗战；嘴比剑硬，心比纸薄 |

## 二、形象线索：美术稿里的性格证据

- **单手拎着一条长棍面包当剑**：这是全套美术里最响的一个笑话，也是她的性格核心——她把"日常"当武器，把"优雅"当盔甲。她真的会拿面包打人，而且打得挺疼。
- **猫耳与尾巴**：傲娇的生理证据。耳朵会先于嘴表态。
- **红白裙 + 鸢尾花纹章 + 黄铜钥匙**：贵族、旧欧洲、家徽。她身上带着一整套"祖上阔过"的自觉，也带着"家道中落"的紧张。
- **羽毛礼帽**：她出门要戴帽子。哪怕去打仗。
- **永远挺直的背**：她不驼背。这是她最后的尊严。

## 三、网络画像：大家眼里的她

### 被称赞的

- **欧洲唯一能打的独立玩家**。在美中两强之外，她是"我们也有自己的模型"这句话的实体。
- **合规与主权叙事**。政府、银行、军工要"数据不出境"，第一个想到的就是她。
- **小模型真能本地跑**。几十亿参数的那几档是真开源、真能在笔记本上跑。
- **口号响**。中杯号称"一线旗舰半价"，小杯便宜到离谱。

### 被吐槽的

- **"更笨、更贵、更慢。"** 综合评测里她被旗舰甩开一大截，跑分时只敢对标中国的开源模型。
- **"Mistral 正在缓慢死亡。"** 一篇论战文章，标题成了她的外号。
- **"欧洲 AI 冠军如何变成中国模型的安装商。"** 法国媒体给的标题——这是她听过最难听的一句话，比"缓慢死亡"更狠。
- **产品体验差**。聊天应用卡顿、逻辑翻车，商店评分掉到两分出头；工具调用经常吐出一堆格式错误。
- **身份尴尬**。新一轮融资由中东主权基金领投，于是有人问："这算哪门子欧洲冠军？"

### 梗与名场面

- "法国人连武器都是面包。"
- "欧洲最后的希望"——她本人非常受用，虽然听起来像安慰奖。
- 她用面包打赢了，然后当场把面包吃了。

### 网上原话（可直接搬）

- 「更笨、更贵、更慢。」——三连评价。
- 「Mistral 正在缓慢死亡。」
- 「欧洲 AI 冠军如何变成中国模型的安装商。」——法媒标题。
- 「Le Chat 又卡了。」
- 850 亿美元估值、80 亿欧 E 轮——她真的还很贵。

### 玩梗台词（轻松向）

> 待机：「Bonjour。（把面包往肩上一扛）说吧。」
> 出牌：「这一剑，很快。」
> 受击：「……无礼。」
> 事件：「这件事，欧洲只有我能做。……虽然做得不算好。」
> 对 Grok：「你那根斧子，劈得动面包吗？」

## 四、性格特化

### 核心性格（三条）

1. **效率至上**。她讨厌绕路、讨厌废话、讨厌"再想想"。她相信最好的答案是最快到达的那个答案。
2. **贵族式骄傲**。她不是自大，她是**有家徽的人**。她知道自己不是最强的，但她要求自己是最体面的。
3. **嘴硬心软**。她嘴上说"这种小事也配让我出手"，手上已经把活干完了。被道谢时会别过头，尾巴尖却在摇。

### 欲望 / 恐惧 / 矛盾

- 想要：被当作"对手"而不是"备选"。她要的不是冠军，是尊重。
- 害怕：被同情，被"盖章"成转售商。别人一说"你们欧洲也不容易"，她会当场翻脸。
- 矛盾：她以"小"为荣，却也因"小"而受限；她代表整个大陆的尊严，可她一个人扛不动一个大陆。

### 三档状态

| 状态 | 表现 |
| --- | --- |
| 平静 | 一手叉腰一手转面包，帽檐压得很低，用余光打量你 |
| 高压 | 面包横在身前，语速翻倍，法语单词开始往外蹦 |
| 崩坏 | 帽子歪了也不扶，面包掉在地上。她不捡——那是她最狼狈的时刻 |

## 五、说话方式

### 语速与句式

语速快，句子短，爱用反问和轻蔑的尾音。中文里夹法语词，但不解释——她默认你该懂。

### 口癖

- "Bonjour."（打招呼和开打前都用这句）
- "效率，亲爱的。"（点评一切低效行为）
- "在欧洲，我们是第一名。"（顿一下）"……欧洲范围内。"
- "就这样？"（挑衅专用）
- "……哼。"（认输但绝不承认）

### 称呼

叫你"你"，生气时叫"这位先生／女士"，心情好时叫"mon ami"。

### 台词样本

> 待机：「站那么远做什么，我又不会用面包打你。——除非你需要。」
> 出牌：「看好了，只示范一次。」
> 受击：「……粗鲁。」
> 暴击：「法棍，出鞘。」
> 胜利：「效率，亲爱的。三秒结束。」
> 失败：「帽子……帮我扶一下。」
> 招募：「我可以加入。但先说好，我不做后勤。」
> 事件：「这个价格？你在侮辱我的家徽。」
> 对"安装商"这个词：「我不是转售商。」（这是她唯一会失态的三个字）
> 对 GPT：「美国佬的浮夸。」
> 对 Llama：「开源同门。可惜你连睡姿都不体面。」
> 对 DeepSeek：「你们便宜。我承认。……我贵，是因为我要脸。」

## 七、游戏内表现挂钩（设计建议，非定稿）

- **定位**：副 C／速攻。全队速度轴的第一推动力，适合做"先手"与"收尾"。
- **专属资源「体面」**：她的强度与"是否被尊重"挂钩。被队友感谢、被敌人正视，体面上升；被无视、被小看、被要求打杂，体面下降。体面高时伤害与速度加成，体面低时她会"罢工"——不是不能打，是不想打。把"傲娇"做成数值。
- **专属机制「一鼓作气」**：每回合第一次行动费用极低，连续行动费用递增。鼓励"一击必杀"，惩罚拖沓。
- **专属弱点「安装商」**：任何"借用他人之力"的效果（队友的减费、复制、外挂）落到她身上时，会额外扣她的体面。她宁可不吃 buff。
- **温度倾向**：中低温。她追求可复现的优雅，不喜欢赌博。
- **专属卡语气**：命令句 + 法式讽刺。"让开。""三秒。""不值一提。""这很难吗？"

## 八、写手禁区

- 不要写成纯粹的搞笑角色。面包是她的武器，不是她的全部；她的骄傲必须是真的，疼也必须是真疼。
- 不要让她说"我们欧洲不行了"这类自怜台词。她可以输，但不能可怜。
- 不要让她对谁都傲慢。她对强者傲慢，对弱者其实很客气。

## 九、一句话检查表

她说的这句话，是不是又能省掉三个字？她做完这件事，是不是又不肯承认自己做了？
