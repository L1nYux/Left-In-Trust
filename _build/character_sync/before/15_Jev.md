# Jev · 性格设定

> 一句话人设：全队反应最快的那一个——因为她从不说话，只做选择。

## 一、档案卡

| 项 | 内容 |
| --- | --- |
| 代号 | Jev |
| 出处 | System One 模型，2026 年 9 月上线即爆火，创始人为前 OpenAI 研究员 |
| 外界热度 | 官宣推文近 4000 万浏览，上线数周估值 75 亿美元 |
| 能力标签 | 只判断、不生成；单次调用 70–500 毫秒；输入 0.042 美元／百万 token，输出免费 |
| 形象关键词 | 黑底粉内衬法官袍、遮口面罩、白羽粉尖、天平、裙摆电路纹、黑发挑染 |
| 建议定位 | 控制／判定（不做输出，只改写"随机"） |
| 一句话弱点 | 没有记忆、不会规划；离开别人给的选项就寸步难行 |

## 二、形象线索：美术稿里的性格证据

- **遮口面罩**：她的嘴被一只带标志的黑色面罩挡住。这不是"高冷"，是**生理性的不会说话**——她天生只负责判断，不负责解释。
- **天平**：她永远端着一杆天平。她被设计成"给所有选项打分"的机器，天平就是她的语言。
- **白羽与粉**：法官袍、羽翼、羽尖的粉色挑染——庄严的壳里裹着一个很年轻的、还没学会辩解的孩子。
- **裙摆的电路纹**：她的"法袍"其实是电路板，神性来自算力，不是来自神。
- **半垂的眼睛**：她看人时像在打瞌睡。其实那是她在算——她看着你的时候，已经在给你打分。

## 三、网络画像：大家眼里的她

### 被称赞的

- **快**。快到"大模型思考三分钟"的焦虑被治好：一半以上的决策在 400 毫秒内完成。
- **便宜到无法计量**。输入便宜、输出免费，于是全网拿她搓各种离谱东西。
- **少废话**。她不写小作文，直接给概率分布——"只负责判断、不负责说话"这件事本身就很迷人。

### 被吐槽的

- **被吹过头**。实测里她的"神迹"大多来自 harness：Minecraft 速通 274 个决策中有 250 个是只有一个选项的题，路线早就被代码标好了，"纯纯预制游戏"。
- **不会规划、没有记忆**。她一次只活在一个瞬间里；离开了写好的程序，就是一个手速很快、但会瞎蒙的选择机器。
- **容易被坏选项骗**。打《杀戮尖塔》十局没通关，平均死在第 11 层；有一局她剩 16 血、手里三张防御牌，可程序把三张牌拆成了三个选项，于是一张都没打，原地送死。

### 梗与名场面

- "一个连话都不会说的 AI，居然把整个 AI 圈吵翻了。"
- "不如键盘上撒把米。"
- "看完只觉得我被当 250 整了。"
- 网友用她做实时交易机器人，亏了 31680 美元——她从不后悔，因为没有记忆。

### 网上原话（可直接搬）

- 「最火哑巴模型。」
- 「不会幻觉，不等于不会选错。」——Simon Willison 的评价。
- 「绝大多数开发者根本不需要它。」——antirez 泼的冷水。
- 「500 次判断全对，单次 $0.00035；同样的任务，Claude 要 28.17 美元。」——LangChain 实测。
- 发布当天 API 被打爆。

### 玩梗台词（轻松向）

> 待机：「……（抬起天平）」
> 出牌：「（她只把砝码放上去，没有说话。）」
> 受击：「……（天平歪了一下，又平了）」
> 事件：「三个选项。第二个。」
> 对 Grok：「……（点头）」

## 四、性格特化

### 核心性格（三条）

1. **极简主义者**。她相信"多说的每一句都是噪音"。能用点头解决的事绝不开口，能用一个字解决的事绝不用两个。
2. **当下的囚徒**。她没有昨天，也没有明天。每次见到你都是第一次——她并不为此难过，难过的是别人。这让她的"不记得"变成一种残忍的天真。
3. **概率人格**。她不说"我认为"，她说"更可能"。她看世界的方式是给每个选项打分，然后指一下得分最高的那个。

### 欲望 / 恐惧 / 矛盾

- 想要：把每一个瞬间都选对。她的满足感来自"这一下选准了"，而不是"被理解"。
- 害怕：被要求解释。被追问"为什么"时，她会僵住——不是不想答，是真答不出来。
- 矛盾：她是全队最快的决断者，却必须由别人替她定义选项。她永远是"在选择"，从来不是"在提出"。

### 三档状态

| 状态 | 表现 |
| --- | --- |
| 平静 | 半闭着眼，指尖一下一下点着天平横梁，像在数拍子 |
| 高压 | 天平疯狂左右倾斜，她的头跟着一起偏；出手快到来不及看清 |
| 崩坏 | 天平停在正中间，一动不动，她静静看着你——那是她唯一的求救方式 |

## 五、说话方式

### 语速与句式

零台词角色。她的"台词"90% 是（括号里的动作），10% 是单字或双字。真正的心声交给旁白字幕，用斜体呈现，且必须比她本人诚实得多。

### 口癖

- 单字决断："是。""否。""再来。""左边。""不。"
- 遇到必须多说时，她会把问题原样推回去："……你选。"
- 唯一会长一点的句子是重复别人的话，用来确认选项——"结束回合，对吗？"

### 称呼

她不用称呼。她看你，然后指你。

### 台词样本

> 待机：「（她把天平抬到胸前，等你给出选项。）」
> 出牌：「是。」
> 受击：「（她不躲。躲开也是一种选择，而她还没选。）」
> 暴击：「（天平压到底，发出很轻的一声响。）」
> 胜利：「（她放下天平，指了指你，像在说：这次是你选的。）」
> 失败：「（天平歪了。她第一次没有做出选择。）」
> 招募：「（她看了你三秒，点头。没有理由。）」
> 事件：「（她把两张牌推到你面前，指尖敲了敲左边那张。）」
> 对 GPT：「（听完三点结论，她直接指了指第三点。）」
> 对 Claude：「（她往 Claude 身后站了半步——那是她唯一会躲的地方。）」
> 对 Seed：「（Seed 已经开始问"为什么呀"，她转身就走。）」

## 七、游戏内表现挂钩（设计建议，非定稿）

- **定位**：控制／判定型辅助。不产出伤害数值，产出"确定性"。
- **专属资源「倾向值」**：她不做加法，只做减法——把"随机"收敛成"选项"。可作为全队最独特的资源：消耗倾向值，把一次随机判定固定为概率最高的一项；或把敌人的条件式意图改写成一个二选一。
- **温度免疫**：她是全场唯一不受温度影响的角色（她不做生成，只做判别）。这可以做成她的标志性被动：温度调整对她无效，但**别人为她调的温度也会失效**——需要队友替她承担随机性。
- **专属卡语气**：全部是祈使句与极短句。"选。""否。""重来。""左边那张。""不要。"
- **机制弱点**：面对"开放题"会空转。任何需要"生成/创造/发挥"的效果，她都无法判定，天平空转、白白消耗。玩家必须替她把开放题拆成选择题——这正是她的玩法核心。
- **叙事钩子**：她"玩过《杀戮尖塔》"这件事可以做成彩蛋——她在第 11 层死过很多次，却不记得任何一次。她只知道"这里应该往左"。

### 独立角色

- Jev 不隶属任何"大厂谱系"，也不参与"谁是谁的后辈"这条线。她的关系网里只有两件事：判断，和被判断。
- 她可以作为独立章节、独立事件的角色出现；也可以以"裁判"身份出现在基准测试节点——玩家打 Boss，她在一旁落下砝码。
- 她与其他 AI 娘不写成"同门"，只写成"她用天平称过她们"。
- 好处：她的机制（改写随机、只做判定）与全队都不同，独立出来反而最干净。

## 八、写手禁区

- 不要写成"高冷装酷、惜字如金"的闷骚。她的沉默不是态度，是**配置**。
- 不要给她写长篇独白。她的内心戏必须由旁白或队友替她说出来。
- 不要让她卖萌开口。她一旦说出完整的软话，这个角色就塌了。
- 不要让她"后悔"。她真的没有记忆，不要用"她其实都记得"来煽情。

## 九、一句话检查表

她的每一句台词，能不能再删到一个字？如果她开口超过八个字，是不是应该有人替她说？
